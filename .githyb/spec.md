# .github spec

## PR의 Spec ↔ Code 확인

- 기준: 루트 `AGENTS.md`의 작업 순서·리뷰 규칙과 `.agents/skills/pr-review/SKILL.md`.
- PR 작성자는 적용 스펙과 변경 여부, 요구사항별 구현 위치, 검증 근거를 PR 본문에 기록한다.
- 스펙을 수정하지 않았다면 적용한 기존 스펙과 수정이 필요 없는 이유를 기록한다.
- 문서·작업 절차 변경처럼 제품 구현이 없는 경우에는 해당 항목을 `해당 없음`으로 적고 이유와 변경 문서 경로를 기록한다.
- 사람 리뷰어는 실제 확인 후 이름, 검토 커밋, 결과와 리뷰 링크를 기록한다.
- 미해결 불일치가 있으면 승인 전에 코드 또는 합의된 스펙을 수정하고 다시 확인한다.
- PR 템플릿은 이 확인 내용을 빠짐없이 기록하도록 안내한다.
