## DEV-221 Mock 테스트 고정 포트로 병렬 worktree에서 간헐 실패

- 이슈: [DEV-221](https://linear.app/sswp6/issue/DEV-221)
- 브랜치: `nemodleo/dev-221-mock-dynamic-ports`
- 기능·인수 조건: 제품 동작 변경 없음. 테스트 이름의 AC-12-1/2/3/5/6/7/9, AC-12-14/15, AC-01-12~15, AC-01-20은 그대로
- 상태: 리뷰 요청 전

### 목표
worktree 여러 곳에서 `npm run test:mock`을 동시에 돌려도 Mock 서버를 띄우는 테스트가 고정 포트(18083·18093·18084·18085)로 부딪혀 "Mock server exited"로 실패하지 않게 한다. 기동에 실패하면 원인(포트·종료 코드·stderr)이 메시지에 보이게 한다.

### 범위 (수정 허용 경로)
- `scripts/mock-server.mjs`(포트 0일 때 실제 포트로 주소 정하기)
- `scripts/test-news-rooms.mjs`, `scripts/test-onboarding.mjs`, `scripts/test-withdrawal.mjs`(띄우는 코드)
- `tasks/DEV-221.md`(이 파일)

### 비범위 (건드리지 않음)
- `scripts/local.mjs`(기본 8083 동작 그대로), `scripts/ci/integration-map.json`, `package.json`
- 앱·서버·`packages/api` Mock 로직
- 에이전트 sandbox의 `listen EPERM`(포트를 바꿔도 풀리지 않음. 이번에는 메시지에 원인이 찍히는 것까지만)

### 결정 사항
- 11/05 PM 승인안(제안서 A안): `FARMCLUB_MOCK_PORT=0`이면 Mock 서버가 빈 포트를 잡고, 열린 뒤 `server.address().port`로 주소를 정해 첫 줄(`Shared Mock: http://127.0.0.1:<port>`)에 알린다. 테스트는 그 줄에서 주소를 읽는다. 0이 아니면 지금과 같다.
- 11/05 띄우는 코드는 공용 헬퍼 파일 없이 세 파일에 직접 둔다(CI 분류표를 건드리지 않기 위해).
- 11/05 Mock 서버의 "Local host only" 검사(`Host` 헤더 비교)도 요청한 포트가 아니라 실제로 연 포트(`server.address().port`)와 비교한다. 제안서 근거 목록에는 없던 곳으로, 포트 0일 때 모든 요청이 403이 되어 처음 돌린 `test:mock`이 4개 실패해 찾았다. 고정 포트일 때는 두 값이 같아 동작이 같다.
- 11/05 소식방 테스트의 재시작 확인은 다시 켤 때 포트가 바뀌므로 주소를 새로 읽고, 재시작 전에 받은 사진 주소는 경로만 새 주소에 붙여 같은 파일이 남았는지 본다(검사 내용은 같다).
