## DEV-206 생산자 Android 앱 첫 화면: 도움말 투어가 레이아웃을 반으로 밀고 카드가 내비 바 아래로 숨음

- 이슈: [DEV-206](https://linear.app/sswp6/issue/DEV-206) · GitHub #385
- 브랜치: `nemodleo/dev-206-native-tour-overlay`
- 기능·인수 조건: DEV-109 도움말 투어(`docs/spec/screens.md` "공통: 도움말"), AC-34-5. 웹 동작 변경 없음
- 상태: 리뷰 중

### 목표
Galaxy(Android 16) APK에서 강영수로 로그인하면 자동 시작한 투어가 화면 아래 절반을 차지해 탭 바가 화면 중간에 그려지고, 카드 "1 / 13"이 내비 바 아래로 밀려 ×·다음을 못 누른다(HE P1). 근거: `docs/evaluation/he-2026-11-04/he-claude-phone-2026-11-03.md` P1.

### 결정 사항
- 11/05 원인: 겹치기 레이어가 `position: "fixed"`인데 React Native에는 fixed가 없어 relative로 처리됐다. 오버레이가 Stack 옆 형제로 레이아웃 높이를 차지해 본문이 반으로 밀렸다. 앱은 `position: "absolute"`(앱 루트 기준), 웹은 fixed 그대로(`fixed` 상수 하나로 묶음).
- 11/05 카드 위치를 앱에서는 상태 표시줄·하단 내비 바 안쪽으로 제한한다(`useSafeAreaInsets`, 위·아래 16 + 인셋). 웹은 인셋 0이라 계산이 그대로다.
- 11/05 앱에서 대상 위치를 재는 코드(`findTarget`)는 DOM 전용이라, 기존 코드는 앱에서 대상 단계마다 버튼 없는 카드에서 멈췄다(3초 뒤 '다음'을 띄우는 타이머가 웹 분기 안에 있음 — 에뮬레이터에서 2/13에 갇힘 확인). 앱은 대상 단계에 들어오자마자 가운데 카드 + '다음'으로 두고, "찾지 못했어요" 대신 단계 설명을 보여 준다. 자동 시작은 그대로 둔다(이슈의 임시안 '자동 시작 끄기'는 쓰지 않음 — 겹치기가 고쳐져 끝까지 진행·닫기가 된다).
- 11/05 앱 스포트라이트(`measureInWindow`로 testID 대상 재기)는 이번 범위 밖. 필요하면 후속 이슈로.
