- 11/08 `scripts/test-native-config.mjs`가 `if (evaluatorBuild) return true;` 줄을 검사해서 그 줄은 그대로 둔다.
- 11/08 설명 문단의 개인정보 문장을 버튼 아래 13 글로 옮김(문구 동일). 목록 위 '생산자 테스트 계정을 골라 주세요', 아래 '소비자는 소비자 앱에서 따로 로그인해요.'(SCR-05와 짝). '처음이세요? 농가로 가입 신청 ›'은 그대로. 버튼 아래 약관 동의 안내는 넣지 않음.
