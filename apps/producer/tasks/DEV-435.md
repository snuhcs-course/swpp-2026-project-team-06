## DEV-435 스토어 심사 전 네이티브 설정 정리

- 이슈: [DEV-435](https://linear.app/sswp6/issue/DEV-435) · GitHub #763
- 브랜치: `nemodleo/dev-435-trim-native-config`
- 상태: 리뷰 중

생산자 앱 `app.json`에도 소비자 앱과 같은 값을 넣는다: `ios.supportsTablet: false`, `android.blockedPermissions` 5개(`SYSTEM_ALERT_WINDOW`·`VIBRATE`·`USE_BIOMETRIC`·`USE_FINGERPRINT`·`BIND_GET_INSTALL_REFERRER_SERVICE`). 범위·결정·권한 표·검사는 소비자 쪽 기록(`apps/consumer/tasks/DEV-435.md`)과 같다.

### 작업
- [x] `apps/producer/app.json` `ios.supportsTablet: false`, `android.blockedPermissions`
- [x] prebuild 확인: `TARGETED_DEVICE_FAMILY = "1"`, 네 권한 `tools:node="remove"`, iOS 아이콘 1024 RGB·모서리 `#56652A`
- [x] 원본 자료·사진 첨부(`lib/pick.native.ts`, `lib/sourceFiles.native.ts`)는 `launchImageLibraryAsync` 전에 `requestMediaLibraryPermissionsAsync`를 부른다. Android 12 이하에서 저장소 권한을 요청하므로 남긴다(11/24 리뷰에서 바로잡음)

### 기록
- 11/22 빌드 6 AAB 권한은 소비자 앱과 같은 10개. fingerprint는 iOS·Android 둘 다 바뀐다(새 빌드 필요).
- 11/24 AI 1차 리뷰 반영: install referrer 권한도 막는다(소비자 쪽 기록과 같음). fingerprint는 다시 바뀐다.
