### 왜
DEV-344로 서버는 품절 상품의 한도 저장을 막지 않지만, 화면이 다음 행동을 알려 주지 않았다(390×844에서 재현).
- 판매 설정: 저장 오류가 페이지 맨 아래(저장 버튼에서 약 435px 아래)에 나와 보이지 않았다. 품절이어도 요약 카드에 안내가 없었다.
- 기간·가격: 저장에 성공하면 항상 뒤로 가서, 박스를 늘려도 판매 한도(kg)를 다 써서 여전히 품절인 상태를 알 수 없었다. 저장 오류는 화면 맨 위에만 나왔다.

### 결정 사항
- 11/16 품절 판정은 서버 `availability`를 그대로 쓴다. 박스 소진은 지금 판매 기간(`currentStageId`)의 모든 옵션이 `quantity ≤ reservedCount`인지로 본다(서버 `item.remaining(cur, o) <= 0`과 같은 기준).
- 11/16 승인 물량 > 판매 한도면 ‘판매 한도를 늘릴 수 있어요’, 같으면 ‘물량 추가 신청’으로 안내한다. 남은 kg이 가장 작은 옵션보다 작아 품절인 경우도 같은 문구다(서버 판정을 따름).
- 11/16 오류·성공 안내는 한 자리에만 보인다(`at`: save·pause·request·page). 신청·철회 결과는 ‘물량 추가 신청’ 영역 끝, 불러오기 실패만 맨 아래. 웹에서는 `scrollIntoView({block:"nearest"})`로 보이게 한다. 네이티브는 스크롤하지 않는다(`FieldFeedback.tsx`와 같은 방식).
- 11/16 기간·가격 저장 뒤 상품 다시 읽기에 실패하면 예전처럼 돌아간다(저장 자체는 성공).
- 11/16 (사전 스캔 반영) 품절 안내와 기간·가격 ‘저장 뒤 머묾’은 판매 중(`PUBLISHED`) 상품에만 적용한다. 승인 전 상품(작성 중·심사 중·반려)은 판매 한도가 0이라 지금 기간이 있으면 서버가 `TOTAL_SOLD_OUT`을 주지만, 판매 설정은 ‘공급 물량 승인 요청’ 화면이고 기간 저장 뒤에는 예전처럼 돌아간다. 상태 줄은 안내가 실제로 보일 때만 숨긴다.
- 11/16 (사전 스캔 반영) 서버는 지금 기간에 박스를 정한 옵션이 하나도 없어도 `TOTAL_SOLD_OUT`을 준다(`service.py` `sales_state`의 `not options`). 판매 중 상품도 주문 없는 옵션을 모두 바꾸면(`_replace_options`가 옛 옵션의 기간 박스를 지움) 생길 수 있다. 이때는 kg이 남아 있으므로 ‘판매 한도를 모두 채웠어요’ 대신 이번 기간 안내(‘이번 기간 품절’ + 기간·가격 버튼)를 쓴다.
- 11/16 (사전 스캔 반영) 판매 설정 → ‘기간·가격에서 박스 늘리기’는 `?from=sales`로 열고, 기간·가격의 ‘판매 한도 늘리기’는 그때 `router.back()`으로 돌아간다(스택이 판매 설정→기간→판매 설정으로 쌓여 뒤로가 맴돌던 문제). 돌아온 판매 설정이 최신 상태를 보이도록 불러오기를 `useEffect`에서 `useFocusEffect`로 옮겼다(처음 열 때도 같은 곳에서 읽음). 그 밖의 진입은 예전처럼 push.
- 11/17 (PR #635 AI 1차 리뷰 반영) 판매 설정에 다시 들어올 때(`useFocusEffect`) 지난 결과 안내(`error`·`note`·`at`·`capExceeded`)를 지우고, 판매 한도·한 주문 최대 칸은 마지막으로 불러온 값과 같을 때만 덮는다(기간·가격에 다녀와도 고친 입력 보존). 저장·중지 등 성공 뒤와 ‘최신 상태 확인’은 예전처럼 서버 값으로 덮는다.
- 11/17 (리뷰 반영) 심사 중인 신청이 있으면 신청 칸이 없으므로 `APPROVED_CAP_EXCEEDED` 아래 ‘물량 추가 신청하기’를 보이지 않는다.
- 11/17 (리뷰 반영) 기간·가격 저장 뒤 안내 제목을 ‘기간·가격을 저장했어요.’로 바꾼다(가격·날짜도 함께 저장되므로). 기간을 다시 고치거나 추가·삭제하면 안내를 지운다.
- 11/17 (리뷰 반영) `soldOutGuide`를 `lib/soldOutGuide.ts` 순수 함수로 옮기고 Mock 단위 테스트로 분기(승인 > 한도 박스 남음·소진, 승인 = 한도·심사 중, 이번 기간, 박스 없는 전체 품절, 승인 전·다른 상태 null)를 본다. 승인 = 한도는 API로 만들 수 없어(승인량을 줄이는 길이 없음) e2e 대신 단위 테스트로 본다. 오래 남을 구현 결정은 `apps/producer/spec.md` DEV-345 절로 옮겼다.
