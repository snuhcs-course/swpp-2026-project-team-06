### 왜
- 11/15 실제 농가가 소비자 페이지(farmclub.kr)에 어떻게 들어가는지 몰랐다. 링크는 설정 › 농가 프로필·공유 링크의 '소비자 앱에서 내 농가 보기'에만 있었다.
- PM 제안: 생산자 앱 메인 상단에 farmclub.kr 안내.

### 결정 사항
- 11/15 PM: 처음 시안(면색 카드 + 문구에 farmclub.kr)보다 예쁘게. 시안 A/B/C → A2/B2(도메인은 버튼에만) → C2 → **C3** 확정: 연주황 면(#FDECE2, 생산자 기준표 accent 옅은 배경)·테두리(#F6D9C4, Figma C3) 카드, 위 줄 라벨 ‘소비자가 보는 내 농가’(accentPressed) + 닫기 X, 아래 줄 농가 사진 56(kind farm)·농가명·지역 + 오른쪽 주황 버튼 ‘farmclub.kr’(복사 아이콘). 아래쪽 버튼 줄은 없애고, 복사는 오른쪽 버튼으로 옮겼다. 문구에 도메인을 쓰지 않는다. 팔로워 수는 넣으면 잘려서 지역만.
- 11/15 PM: 오른쪽 버튼은 페이지를 열지 않고 복사만 한다(아이콘 복사). 누르면 설정 화면 '복사'와 같은 공유 링크 `farm.shareUrl`(서버 `with_share_url`이 절대 주소로 줌, 카카오톡 미리보기 `/s/farms/:id`)을 `copyText`(expo-clipboard)로 복사하고 토스트 '링크를 복사했어요'(실패하면 '복사하지 못했어요'). 승인 농가만 값이 있고, 없으면(설정 화면처럼) 버튼을 두지 않는다. 페이지 열기는 설정 화면의 기존 버튼. (처음에 shareUrl을 상대 경로로 잘못 보고 소비자 앱 주소를 복사했으나 재스캔 지적으로 바로잡음)
- 11/15 버튼 이름(화면 읽기)은 보이는 글자로 시작하는 ‘farmclub.kr 내 농가 링크 복사’(WCAG 2.5.3).
- 11/15 승인된 농가(`farms.mine().status === "APPROVED"`)만 보인다. 정지 농가는 현황에 오지 않는다.
- 11/15 닫기는 농가별 키 `consumer-page-card-closed:<farmId>`로 기억한다. AI 1차 리뷰(should) 반영으로 공용 `readStore`/`writeStore`(웹 localStorage, 앱 SecureStore, 앱 이름공간)를 써서 앱에서도 유지된다(처음엔 localStorage + 실행 중 Set으로 직접 구현).
- 11/15 공용 `Notice`는 `accessibilityRole="alert"`라 상시 안내에 맞지 않아, 생산자 앱 안에 카드 컴포넌트를 따로 만든다(공용 패키지는 안 바꿈).
- 11/15 AI 1차 리뷰(must) 반영: FEAT-14 목적·정상 흐름에 카드를 적었다(새 AC는 만들지 않음, 화면 명세 SCR-22가 세부).
- 11/15 재스캔 반영: 닫기(X)는 공용 `IconButton`(48×48)으로 바꿨다. react-native-web Pressable은 `hitSlop`을 처리하지 않아 웹에서 20px이었다.
- 11/15 scan-before-merge 반영: 복사 버튼 누르는 영역 48(`tokens.touchTarget.min`), 사진 alt '농가 사진'(농가명 중복 읽기 방지), ia.md 변경 이력 줄, `apps/producer/spec.md`에 구현 결정. screens.md·ia.md 변경 이력은 DEV-324·327과 같은 자리라 뒤에 머지하는 쪽이 충돌을 푼다(두 줄 모두 남김).
- 11/15 scan 지적 반영: e2e는 `/api/farms/me` 응답을 기다린 뒤 '다시 안 뜬다'를 확인하고, 위치는 늘 그려지는 '주문' 제목과 비교한다. 주소 상수는 설정 화면과 같은 한 줄이라 공용 함수로 빼지 않았다(범위 최소).
