## DEV-322 Show a default product photo when the main photo is empty

- 이슈: [DEV-322](https://linear.app/sswp6/issue/DEV-322) · 공용 변경은 `packages/ui/tasks/DEV-322.md`

### 왜
- 생산자 '구매자 화면 미리보기'가 소비자 화면과 다르게 그려진다: 대표 사진이 없으면 사진 자리가 사라지고, 사진이 여러 장이면 비공개 사진 주소를 바꾸지 않아 갤러리가 깨질 수 있다.

### 범위 (수정 허용 경로)
- `apps/producer/src/app/(tabs)/farm/index.tsx`(농가 대표 사진 `productFallback={false}`만), `apps/producer/src/lib/BuyerPreview.tsx`, `ProductPageEditor.tsx`(미리보기 대표 사진만), `PageCanvas.tsx`(미리보기 대표 사진만), `NewProductComposer.tsx`(구매자 미리보기 대표 사진만)

### 결정 사항
- 11/15 미리보기에서는 대표 사진이 없어도 `Photo`를 그려 소비자 화면처럼 기본 사진을 보인다. 편집 모양(사진 고르기 칸)은 그대로. `PageCanvas` 미리보기를 쓰는 자료 작업실(SourceWorkspace)의 구매자 미리보기도 같은 규칙이다(대상 상품마다).
- 11/15 `BuyerPreview`는 `photos`도 주소를 바꾸고, 아직 못 받은 비공개 사진(빈 문자열)은 빼서 기본 사진이 대신한다.
- 11/15 재스캔 CRITICAL 반영: 기존 `media()`는 `/`로 시작하는 모든 주소에 API 주소를 붙여, 시드 사진(`/photos/…`, 앱 public 폴더)이 404 → 기본 사진이 됐다. 상품 사진 변환은 `ProductPageEditor`와 같은 규칙(비공개 → blob, `/api/` → API 주소, 나머지 그대로)의 `photoUrl`로 따로 둔다. 판매페이지 모듈 사진(`mediaUrl={media}`)은 손대지 않는다. e2e '시드 사진 그대로' 추가.
- 11/15 비공개 대표 사진을 받는 동안에는 미리보기에 기본 사진이 잠깐 보인다(예전에는 작은 로고·빈칸). 받으면 실제 사진으로 바뀐다.
