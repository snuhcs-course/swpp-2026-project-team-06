# farmclub Android 앱 설치 안내 (테스트 참여자용)

farmclub 앱은 Play 스토어가 아니라 파일(APK)로 설치해요. 설치에 2~3분 걸려요.

## 설치
1. 안드로이드 휴대폰의 **Chrome**에서 받은 다운로드 링크를 열고 `farmclub-consumer-<버전>.apk`를 눌러 내려받아요.
   - "이 유형의 파일은 기기를 손상시킬 수 있습니다" 안내가 나오면 **다운로드**를 눌러요.
2. 다운로드가 끝나면 알림이나 Chrome의 **열기**를 눌러요.
3. "출처를 알 수 없는 앱" 설치를 묻는 화면이 나오면 **설정** → **이 출처 허용**(Chrome)을 켜고 뒤로 돌아와요.
   - 삼성: 설정 → 애플리케이션 → 메뉴(⋮) → 특별한 접근 → 출처를 알 수 없는 앱 설치 → Chrome 허용
4. **설치**를 눌러요.
   - **Play 프로텍트** 경고("앱을 검사하지 않았음", "안전하지 않은 앱 차단됨")가 나오면 **세부정보 더보기** → **무시하고 설치**를 눌러요. Play 스토어에 올리지 않은 테스트 앱이라 나오는 안내예요.
   - "앱 검사를 위해 보내시겠습니까?"는 **보내지 않음**이어도 괜찮아요.
5. 홈 화면의 **farmclub** 아이콘으로 열어요.

## 쓰는 법
- 앱은 휴대폰의 Chrome으로 farmclub.kr을 여는 방식이라 **Chrome이 설치·업데이트**되어 있어야 해요.
- 카카오 로그인은 카카오톡 앱 또는 카카오 계정 화면으로 이동했다가 앱으로 돌아와요.
- 첫 실행 때 화면 위에 주소창이 잠깐 보이거나 계속 보여도 쓰는 데는 문제없어요. 알려 주시면 고칠게요.

## 설치가 안 될 때
- 안드로이드 7.0 이상에서 설치돼요.
- "앱이 설치되지 않았습니다": 예전 테스트 앱이 있으면 지우고 다시 설치해요.
- 그래도 안 되면 **Chrome에서 https://farmclub.kr 에 접속**해서 똑같이 쓸 수 있어요. 메뉴(⋮) → **홈 화면에 추가**를 누르면 앱처럼 아이콘이 생겨요.
- iPhone은 Safari에서 https://farmclub.kr → 공유 → **홈 화면에 추가**로 써 주세요.

## 지우기
홈 화면의 farmclub 아이콘을 길게 눌러 **삭제**해요. 주문·채팅 기록은 계정에 남아 있어요.
