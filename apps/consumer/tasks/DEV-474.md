## DEV-474 소비자 앱 우편번호 찾기 빈 화면

- 이슈: [DEV-474](https://linear.app/sswp6/issue/DEV-474)
- 브랜치: `nemodleo/dev-474-fix-postcode-native-resolution`
- 기능·인수 조건: FEAT-08 / AC-08-4(도서산간), AC-08-5(저장 배송지) 배송지 입력의 '우편번호 찾기'(DEV-314). 동작·규칙 변경 없음
- 상태: 리뷰 중

### 목표
DEV-471(원스토어 반려) 에뮬레이터 점검에서 소비자 Android 앱의 주문서 → 받는 곳 변경 → 새 주소 입력 → '우편번호 찾기'가 빈 화면이 되는 것을 찾았다. 앱에서 DEV-314의 앱 구현(전체 화면 웹뷰)이 열리게 한다.

### 원인
- 웹 구현은 `src/lib/postcodeSearch.ts`, 앱 구현은 `src/lib/postcodeSearch.native.tsx`로 확장자가 달랐다.
- Metro는 확장자(`ts` → `tsx` → …)마다 `.android` → `.native` → 접미사 없음 순으로 찾는다(`metro-resolver/src/resolve.js` `resolveSourceFile`·`resolveSourceFileForAllExts`). `ts` 단계에서 `postcodeSearch.ts`(웹)가 먼저 잡혀 앱 번들에 웹 구현이 들어갔다. 제출 APK와 같은 코드의 Mock 번들에 앱 구현의 `postcode.map.kakao.com` 문자열이 없다.
- 웹 구현이 `document`를 쓰므로 버튼을 누르면 `ReferenceError: Property 'document' doesn't exist`, ErrorBoundary가 없어 화면 전체가 지워졌다.
- tsc는 `.native`를 모르고 `postcodeSearch.ts`만 보므로 타입 검사로는 드러나지 않았다.

### 범위 (수정 허용 경로)

- 이 파일을 가리키는 주석·문서·테스트 경로: `apps/consumer/src/lib/AddressForm.tsx`, `apps/consumer/src/lib/postcode.ts`, `apps/consumer/src/lib/postcodeSearch.native.tsx`(첫 줄 주석), `apps/consumer/spec.md`, `scripts/test-postcode.mjs`

- `docs/design/proposals/DEV-474/`(전후 캡처), `apps/consumer/tasks/DEV-474.md`

### 비범위 (건드리지 않음)

- `apps/consumer/tasks/DEV-314.md`(지난 작업 기록)의 옛 파일 이름: 고치지 않는다.

### 결정 사항
- 11/24 웹 파일을 `.tsx`로 바꾼다. 앱 파일은 JSX가 있어 `.ts`로 바꿀 수 없다. 웹 파일에는 JSX가 없지만 `.tsx`여도 tsc·Metro 동작은 같다.
- 11/24 검사는 독립 파일 `scripts/test-native-pairs.mjs`로 둔다. DEV-471의 `scripts/test-app-web-globals.mjs`가 아직 main에 없어서다.
- 11/24 (리뷰 반영) 검사는 확장자 문자열 비교가 아니라 Metro 해석 순서를 흉내 낸다. sourceExts(`ts,tsx,mjs,js,jsx,json,cjs,scss,sass,css`, 앱 metro 설정과 같은지 테스트가 확인)마다 `.<플랫폼>` → `.native`(웹 제외) → 접미사 없음. 모듈마다 android·ios·web이 잡는 파일을 계산해, 그 플랫폼 전용 파일(`.android`/`.ios`/`.web`, 앱은 `.native`도)이 있는데 덜 구체적인 파일을 잡으면 실패. `x.ts`+`x.android.tsx`, `x.ts`+`x.web.tsx`, `x.ts`+`x.tsx`+`x.native.tsx`, `.js`/`.jsx` 짝을 검사 자체 테스트에 넣었다.
- 11/24 `react-native-webview`(13.16.1)는 제출 APK(versionCode 기준 2026-11-21 빌드)에 들어 있다(`classes3.dex`에 `RNCWebView` 클래스). JS만 바뀌어 fingerprint는 제출 APK와 같다(`0a6df1df8d452d2003b7f04236ae7ef13de1572a`). 새 네이티브 빌드 없이 preview 채널 OTA로도 닿는다.
