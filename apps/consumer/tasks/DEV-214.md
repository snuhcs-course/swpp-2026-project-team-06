### 왜
- 농가 목록에서 목록이 있는 채 새 검색이 실패하면 검색 전 목록과 머리줄('마감 임박순 · 농가 4곳')이 그대로 남아 검색 결과처럼 보이고, 안내가 없다. 실패 신호는 마지막 카드 아래 글자 버튼 '다시 시도' 하나다.
- 그 '다시 시도'가 `load(false)`(덧붙이기)를 불러 결과가 기존 목록 뒤에 붙는다. 같은 농가가 두 번, '농가 5곳', 콘솔 React 키 중복 경고.
- 원인: `apps/consumer/src/app/(tabs)/farms/index.tsx` FarmList — 오류 화면이 `error && !items`일 때만, 재시도는 실패 종류와 상관없이 `load(false)`.
