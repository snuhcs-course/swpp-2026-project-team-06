## DEV-314 배송지 입력에 카카오(다음) 우편번호 찾기 연결

- 이슈: [DEV-314](https://linear.app/sswp6/issue/DEV-314) · GitHub #584

### 목표
실사용자 파일럿 전에 주소 오타를 줄이고 입력을 쉽게 한다. 배송지 입력(주문서·내 배송지)에 ‘우편번호 찾기’를 단다.

- `apps/consumer/src/app/checkout/[productId]/index.tsx` (도서산간 판정 함수를 `lib/postcode.ts`로 옮겨 같이 씀, 규칙은 그대로)
- `apps/consumer/spec.md`, `apps/consumer/tasks/DEV-314.md`
- `packages/ui/src/Input.tsx` (`inputRef` 추가, `packages/ui/tasks/DEV-314.md`)
- `docs/spec/screens.md`, `docs/spec/ia.md`, `docs/spec/functional/FEAT-08-reservation-order.md`, `docs/spec/tasks/DEV-314.md`, `docs/wiki/Requirements-and-Specifications.md`
- `scripts/test-postcode.mjs`, `scripts/e2e/postcode-search.spec.ts`, 배송지 입력을 쓰는 e2e 5개와 `scripts/i3-preorder/run.mjs`의 우편번호 locator(`exact: true`)

### 비범위 (건드리지 않음)
- 서버 주문·도서산간 규칙(`server/app/orders/**`, 고위험) — 값 형식이 같아 바꿀 것 없음
- `apps/consumer/vercel.json`(고위험) — CSP 헤더가 없어 바꿀 것 없음
- 생산자 앱: 주소 입력 화면이 없다(출하 화면은 주문의 주소를 보기만 함). 범위 밖
- 앱(iOS·Android) 안 우편번호 찾기: 웹뷰 의존성이 없어 이번엔 버튼을 숨김(후속 필요 시 별도 이슈)

### 결정 사항
- 11/12 스크립트는 공식 `https://t1.kakaocdn.net/mapjsapi/bundle/postcode/prod/postcode.v2.js`(키 없음). 옛 `daumcdn` 주소는 같은 파일이며 스크립트가 legacy로 표시한다. 전역은 `kakao.Postcode`(`daum`과 같은 객체)라 둘 다 받는다. 질의 문자열을 붙이지 않는다(서비스가 잘못된 호출로 봄).
- 11/12 팝업(`open()`) 대신 화면 위 레이어에 `embed()`: 팝업 차단과 웹뷰의 `window.open` 미지원을 피한다(서비스 안내). 레이어는 DOM으로 직접 만든다(머리 ‘우편번호 찾기’·‘닫기’, Esc·바깥 누르면 닫힘, 가로 최대 480).
- 11/12 스크립트는 배송지 입력 화면이 열릴 때 한 번만 불러온다(앱 전체 첫 로딩에는 넣지 않음). 실패하거나 10초 안에 안 오면 우편번호 칸 아래 안내 후 직접 입력. 다음에 누르면 다시 시도.
- 11/12 주소는 도로명 → 서비스가 채운 도로명(`autoRoadAddress`) → 지번 → `autoJibunAddress` 순. 우편번호가 5자리 숫자가 아니거나 주소가 비면 칸을 바꾸지 않는다. 건물명 덧붙임은 하지 않는다(서버 도서산간 판정·주문 사본 형식 그대로).
- 11/12 안내는 둘로 나눈다: 스크립트를 못 불러오면 ‘우편번호 찾기를 열지 못했어요…’, 고른 값에 5자리 우편번호·주소가 없으면 ‘고른 주소를 채우지 못했어요…’(커밋 전 점검 INFO 반영). 레이어를 열면 ‘닫기’에 초점.
- 11/12 앱(.native.ts)은 버튼 없이 기존 직접 입력. 새 의존성(웹뷰)은 넣지 않는다.
- 11/12 ‘우편번호 찾기’ 버튼의 접근성 이름이 ‘우편번호’를 포함해 e2e `getByLabel("우편번호")`(부분 일치)가 두 개를 잡는다 → 기존 e2e locator를 `exact: true`로.
- 11/12 도서산간 판정(`isRemoteArea`)을 주문서 파일에서 `lib/postcode.ts`로 옮겨 테스트가 서버 규칙과 같은지 본다. 규칙 자체는 그대로.
