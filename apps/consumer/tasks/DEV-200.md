## DEV-200 [I3] Show evaluator test accounts in native internal builds for HE
- 이슈: https://linear.app/sswp6/issue/DEV-200 · 관련 DEV-198(웹 평가 주소), DEV-41(기기 확인)
- 브랜치: `zahra/dev-200-native-evaluator-login`
- 범위: 두 앱 `src/app/login.tsx`, `packages/api/src/{client.ts,index.ts}`, `scripts/e2e/evaluator-login.spec.ts`, `scripts/test-native-config.mjs`, `README.md`(EAS 절 한 줄), 두 앱 `tasks.md`, 평가 안내 `docs/evaluation/he-2026-11-04/README.md`
- 결정
  - 11/3 11/4 수업 HE 평가자는 팀 기기의 internal APK를 쓴다. 앱에는 주소창·sessionStorage가 없어 `?evaluator=1`(DEV-198)을 줄 수 없으므로, 빌드 변수 `EXPO_PUBLIC_EVALUATOR_LOGIN=1`이면 `evaluatorMode()`가 항상 참이다.
  - 변수는 EAS `preview` 환경에만 등록한다(internal APK가 따라가는 채널). `eas.json`·웹 배포에는 넣지 않는다(`test-native-config.mjs`가 검사). production 채널·운영 웹은 그대로 카카오만.
  - 서버 `MOCK_LOGIN_ENABLED`는 바꾸지 않는다(DEV-198과 같음).
- 검증(11/3, 로컬 실서버 `farmclub_i3`): `npm run typecheck` 통과 · `npm run test:mock` 63/63 · `run-integration.mjs evaluator-login.spec.ts` 플래그 없이 4 passed/2 skipped, `EXPO_PUBLIC_EVALUATOR_LOGIN=1`로 2 passed/4 skipped.
- 평가 뒤 할 일(사람): EAS `preview` 환경에서 `EXPO_PUBLIC_EVALUATOR_LOGIN` 삭제 → `eas update --channel preview --environment preview`로 일반 업데이트.
- 기록(11/04, 평가 뒤 정리, 브랜치 `nemodleo/dev-200-he-eas-cleanup`): 두 앱 폴더에서 아래를 실행했다(Expo snu-omm, CLI 로그인 상태).
  - `npx eas-cli@latest env:list --environment preview|production|development` → `EXPO_PUBLIC_EVALUATOR_LOGIN`은 두 프로젝트 모두 `preview`에만 있었다.
  - `npx eas-cli@latest env:delete preview --variable-name EXPO_PUBLIC_EVALUATOR_LOGIN --variable-environment preview --scope project --non-interactive` → 삭제. 다시 `env:list --environment preview` → `EXPO_PUBLIC_API_MOCK`·`API_URL`·`CONSUMER_URL`·`PRODUCER_URL` 네 개만 남음.
  - `npx expo-updates runtimeversion:resolve --platform android` → 소비자 `3a006b6a…`, 생산자 `405e3732…`로 APK(28528091·db07a7db) runtime과 같음을 먼저 확인.
  - `npx eas-cli@latest update --channel preview --environment preview --platform android --message "main 231faa9: after HE 11/4, evaluator login off (DEV-200)" --non-interactive` (main `231faa9`). 소비자 그룹 `2bbd031c-22d1-4ce6-bada-dcff8a33a139`(Android `01a1a683-3842-7229-a1bf-d9b0255373ac`, runtime `3a006b6a0ebbf1f12ffea1380f1f9677d8d0acf9`), 생산자 그룹 `337c065c-c932-4427-b8a8-ec5476f8d162`(Android `01a1a683-d882-72c1-9fe6-3f6860f8e8bb`, runtime `405e3732dcb072f835ac35bb1a01a0307e69fa10`).
  - `npx eas-cli@latest update:list --branch preview --limit 3` → 두 앱 모두 맨 위가 새 그룹, 그 아래가 HE 업데이트(소비자 `9b5610a6`, 생산자 `2a06c9d1`).
  - `production` 환경·채널과 네이티브 빌드는 건드리지 않았다. 기기에서 두 번 실행해 목록이 사라졌는지는 사람이 확인한다. 나머지 운영 정리(오미숙·HE 테스트 소식·강씨네 숨기기·`MOCK_LOGIN_ENABLED`)는 `docs/evaluation/he-2026-11-04/README.md` ‘평가 뒤’에 명령과 확인 방법을 적었다.
