## DEV-377 설치된 앱 이름을 farmclub / farmclub 농가로

- 이슈: [DEV-377](https://linear.app/sswp6/issue/DEV-377) · GitHub #699
- 브랜치: `nemodleo/dev-377-installed-app-name`
- 기능·인수 조건: 해당 FEAT 없음(스토어 제출 정보, DEV-131 관련). 앱 설정 ADR 0013
- 상태: 리뷰 중

### 목표
원스토어 APK를 설치하면 홈 화면 이름이 `farmclub-consumer` / `farmclub-producer`로 보인다. 스토어 제목(`farmclub` / `farmclub 농가`)과 맞춘다.

### 범위 (수정 허용 경로)
- `apps/{consumer,producer}/app.json`의 `expo.name`만
- `scripts/test-brand-meta.mjs`(DEV-377 검사 추가)
- `apps/{consumer,producer}/spec.md` DEV-33 절 한 줄, `docs/spec/tech-design/adr/0013-eas-native-builds.md`, `docs/spec/tech-design/stack.md` 2장 ‘앱 빌드’ 줄·변경 이력, `docs/wiki/Design-Documentation.md` ADR 0013 줄, `README.md` EAS 절
- 이 파일, `apps/producer/tasks/DEV-377.md`

### 비범위 (건드리지 않음)
- `slug`·`android.package`·`ios.bundleIdentifier`·`extra.eas.projectId`·`scheme`·`owner`·`updates.url`
- `**/eas.json`, `.github/workflows/**`, `server/**`, `public/index.html`·`manifest.webmanifest`
- APK 재빌드·원스토어 교체(DEV-131, 머지 뒤 사람이)

### 결정 사항
- 11/21 `expo.name`만 바꾼다. Android `app_name`·iOS `CFBundleDisplayName`이 이 값에서 나온다. iOS도 같은 이름이 맞아 따로 두지 않는다.
- 11/21 웹 탭 제목·PWA 이름은 `public/index.html`·`manifest.webmanifest`가 정한다. 바꾸기 전후 `expo export -p web` 결과(dist 전체)가 같았다. 막을 것이 없다.
- 11/21 `runtimeVersion` 정책이 `fingerprint`라 이름을 바꾸면 런타임 버전이 바뀐다(로컬 `expo-updates fingerprint:generate` 전후 비교, 바뀐 항목은 `expoConfig`뿐). 지금 깔린 빌드는 이 PR 뒤 `eas update`를 받지 못하므로 새 빌드로 갈아타야 한다.
- 11/21 Android `settings.gradle`의 `rootProject.name`도 `farmclub 농가`가 된다(prebuild 확인). Gradle 9.5에서 공백·한글 이름으로 `projects`가 통과했다. 실제 EAS 빌드에서 다시 확인한다.
