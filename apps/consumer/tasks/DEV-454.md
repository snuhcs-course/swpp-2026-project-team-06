### 결정 사항
- 11/24 기준 SHA 356528984fa6eec838729781fea8fd50b5b03ab8. 기존 작업 폴더는 보존하고 새 worktree에서 구현한다.
- 가격/기간/상자 무게 변경 409는 입력을 유지하며 모달로 전후 정보와 현재 총 입금액을 보여 준다. 돌아가기/Esc는 주문 없이 닫고, 재시도 버튼은 모달을 다시 연다. 모달의 명시적 예약 확인만 기존 서버 검증 경로로 진행한다. 품절 모달과 기존 입금 복구를 유지한다.
- 기존 상품에서 넘어온 가격 안내는 정보성 안내로 유지한다. 서버가 검증한 변경의 명시적 예약 확인과 구분한다.
- 자동 전달된 OPEN 질문에 서버가 replyRequested를 제공한다. 생산자는 원래 소비자 질문 말풍선 하단에 붙은 작은 답장 요청을 누르면 인용 입력창을 바로 연다. 기존 전달 큐와 인용 전송을 재사용하며 성공한 대상 요청만 닫는다.

- 조건 변경 뒤 최신 상품 재조회가 실패하면 현재 총액을 숨기고 예약 확인을 막는다. 모달 안 작은 다시 확인하기 버튼으로 읽기만 재시도하며, 성공 후 최신 총액을 확인한다.

- 전달 질문이 과거 페이지에 있어도 인용 답장 성공이 확인되면 로드된 원질문의 요청 표시를 즉시 내린다. 최신 페이지만 재조회하는 기존 폴링에 의존하지 않는다.

- 11/24 추가 검수: 답장 요청은 ChatBubble footer에서 해당 메시지에 붙는 작은 글자 액션으로 표시한다. 원래 질문·요청 액션을 같은 말풍선 열에 두고 기존 인용/포커스 동작을 유지한다.
