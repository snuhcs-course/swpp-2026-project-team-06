## DEV-473 원스토어 재심사 대비: 오류 안내 화면 (소비자 앱)

- 이슈: [DEV-473](https://linear.app/sswp6/issue/DEV-473)
- 브랜치: `nemodleo/dev-473-screen-error-boundary`
- 기능·인수 조건: screens.md 3장 ‘화면 오류’. 범위·결정 전체는 `packages/ui/tasks/DEV-473.md`
- 상태: 리뷰 중

### 목표
소비자 앱 화면이 그리다 죽으면 빈 화면 대신 `ScreenError`를 보이고, 탭 안이면 탭 바를 남긴다.

### 범위 (수정 허용 경로)
- `src/lib/ScreenBoundary.tsx`(새 파일), `src/app/_layout.tsx`, `src/app/(tabs)/_layout.tsx`(Tabs prop 한 줄), `src/app/(tabs)/{chats,farms,me,news,orders,products}/_layout.tsx`, `spec.md`, `tasks/DEV-473.md`

### 비범위 (건드리지 않음)
- 채팅방·주문서·약관 화면 본문(다른 브랜치)

### 결정 사항
- 11/24 경계 파일 8개: 루트 `_layout.tsx`(`unstable_screenErrorBoundary={StackScreenBoundary}` + `export { RootBoundary as ErrorBoundary }`), `(tabs)/_layout.tsx` Tabs(`TabScreenBoundary`, 홈처럼 레이아웃 없는 탭 화면과 앞으로 더할 탭 화면), 탭 폴더 6곳(`TabScreenBoundary`). 홈 화면 파일의 `export ErrorBoundary`는 리뷰 반영으로 Tabs prop으로 옮겼다.
- 11/24 죽은 화면이 운영팀 방(`/chats/support`) 자신이면 ‘운영팀에 알리기’를 숨긴다.
- 11/24 홈 `/`, 운영팀 `/chats/support`. 비로그인은 다른 채팅 탭 진입처럼 관문 시트(`requireLogin("tab", "/chats/support")`). 마지막 그물은 세션이 없어 토큰 유무로 `/chats/support` 또는 `/login?next=/chats/support`, 웹은 주소를 바꿔 써서 앱을 새로 띄운다.
