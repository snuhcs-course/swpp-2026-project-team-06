# Meeting Logs spec

## 역할
This folder stores the team's English meeting and standup records for the GitHub Wiki.

## 구조
- Dated Markdown files contain one meeting or standup record each.
- `_template.md` defines the established format.
- `tasks/` stores issue-specific work records.

## 계약
- Filenames use `YYYY-MM-DD-short-english-slug.md`.
- Records use only supported project facts and omit private credentials or personal data.
