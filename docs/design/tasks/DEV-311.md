### 결정 사항
- 11/11 현재 로고는 팀 승인 작업이므로 안마다 유지 / 다듬기 / 교체를 밝히고, A는 원본 그대로 두고 접점을 로고 쪽으로 맞추는 안으로 했다.
- 11/11 차별화는 색이 아니라 메커니즘으로 나눴다: A 팬클럽(관계: 팬 n명, n번째 예약), B 수확 시계(시간: 수확 D-n, 단계 가격 계단), C 산지 서명(사람: 농가 서명·첫 사진·한 문장).
- 11/11 B의 평면 로고는 승인 원본 PNG의 알파를 그대로 쓰고 색만 채운 시안이다(새로 그리지 않음). C의 글자형은 Pretendard 800 실제 활자, 후보 2개만 크기별로 렌더했다.
- 11/11 Easel(easel-canvas 0.1.1)은 `screens/` 아래만 캔버스에 올리므로, `screens/proposal-boards/`에 원본 보드를 iframe으로 부르는 틀을 두고 board.json에 등록했다. 틀 폴더 이름을 `proposals`로 하면 Easel이 `/proposals/...` 요청을 틀 자신으로 돌려보내 무한 중첩되므로 `proposal-boards`로 했다.
- 11/11 현재 화면 캡처에서 사업자 정보 푸터는 잘라 냈다(실제 값이 레포에 들어가지 않게). 홈·상품 캡처는 운영 상품이 0개라 2026-11-10 캡처(상품 있음, 푸터 없음)를 썼다.
- 11/11 추천은 A(근거는 방향 보드 마지막 절).
