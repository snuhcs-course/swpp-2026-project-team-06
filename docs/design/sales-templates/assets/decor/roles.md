# 역할별 ImageGen 구획선

사용자 요청으로 현재 본문은 CSS 선으로 원복했다. 아래 파일은 비교 기록용이다.

2026-10-14 내장 ImageGen으로 세 파일을 각각 생성했다. 원본 투명 PNG를 수정 없이 보존하고 CSS에서는 100% auto로 비율을 유지한다. 기존 section-divider.png는 이전 버전으로 보존한다.

## divider-short.png
제목 옆 최대120px 짧은 선.

최종 프롬프트:
Use case: stylized-concept. Generate one single handmade gouache stroke UI divider on a truly transparent canvas, quiet matte paper grain, slightly irregular edges and naturally tapered ends, muted sage grey #9b9e85. Only one horizontal stroke, centered exactly at 50% height. No objects, no letters, no ornaments, no shadows, no background. Preserve recognizable fine tactile paper grain, no glossy 3D, no digital gradients. Square 1:1 canvas. A SHORT pencil-like horizontal stroke extends from x=8% to92%. Thickness 3% of canvas height. Used as a compact 120px title-side accent, not stretched across a page. Gentle local width variation.
