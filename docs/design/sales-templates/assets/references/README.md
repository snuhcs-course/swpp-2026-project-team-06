# 비교 전용 원본 구획 캡처

2026-10-14 브라우저에서 렌더한 판매자 상세 구획. 레이아웃 분석/비교 패널 전용이며 팜클럽 상품 사진·문구·품질 증빙이 아니다. 판매 본문 renderer에서 사용하지 않는다. 원본 사이트의 고정 내비게이션/구매 UI는 캡처할 때만 숨겨 해당 구획을 가리지 않게 했다. 원본 콘텐츠는 수정하지 않았다.

- `kurly-excerpt.jpg`: [컬리 깐 마](https://www.kurly.com/goods/5035520)의 `.goods_intro` 상품 소개 구획.
- `kurly-points.jpg`: 같은 상품의 `.goods_point` 체크 포인트 구획.
- `ssari-excerpt.jpg`: [싸리재 옛날 미숫가루 스틱](https://m.ssarijai.com/product/detail.html?product_no=134)의 상품 정보 section. 사진 로드 후 캡처.

권리는 각 판매자/원저작자에게 있다. 나머지 비교 자료는 원본 공개 이미지 URL로 로드하고 실패 시 출처 링크를 표시한다.
