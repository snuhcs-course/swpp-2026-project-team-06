# 상세페이지 구성 · 단일 템플릿

현재 진입점은 **[상세페이지 구성](all-sections.html)**이다. 하나의 템플릿에서 18개 요소를 켜고 끄며 구성 선택은 이 브라우저에 유지된다. 기본은 자료가 있는 11개 요소다. 상품 게시 기능은 아직 연결하지 않았다.

## 보존된 이전 입력 작업실
산지 상점 / 산지 화보 / 농가 이야기를 같은 자료로 비교한다. 실제 판매 저장 기능과 AI 추출 연결 전 단계다. **빈 상태가 기본이다. 예시 보기 또는 `?demo=1`에서만 기존 가상 농가 자료를 채운다.**

## 실행
이 폴더에서 `python -m http.server 8284 --bind 127.0.0.1`을 실행하고 http://127.0.0.1:8284/ 를 연다. npm 설치나 API 키가 필요 없다.

## 사용
1. 구성 선택 → 로컬 사진 추가(최대 6장) → 직접 작성한 문구 입력.
2. 사진 설명·순서를 바꾸고 3종 비교 또는 선택한 시안에서 확인.
3. 너비 선택 360/390/430px. 브라우저가 좁으면 그 안으로 축소한다.
4. 편집안 내려받기는 텍스트·템플릿 ID·사진 파일명/설명만 JSON으로 저장한다. 사진 원본은 별도 보관한다. JSON 재불러오기와 서버 저장은 이번 범위가 아니다.

사진은 브라우저 메모리에서만 처리하며 네트워크로 전송하지 않는다. 탭을 닫거나 새로고침하면 입력이 사라진다. 새 품질 수치·가격·인증·광고 문구·생성 사진은 만들지 않는다. 예시 문구는 기존 디자인 원문을 재사용한다. 입력 문구의 사실 여부는 사용자가 확인한다.

## 구성
- `templates.mjs`: 필드와 사진을 받는 공통 데이터 모델, 서로 다른 3개 판매 본문 렌더. 사용자 문자열은 textContent로만 처리.
- `studio.mjs`: 편집·비교·검증·로컬 파일·JSON 내보내기.
- `studio.css`: 반응형 작업실과 레이아웃. Pretendard / Do Hyeon / Gowun Batang 사용.
- `assets/`: 검수한 추상 장식, 원본 폰트, 라이선스. `assets/README.md` 참조.

## 채워진 예시
`http://127.0.0.1:8284/?demo=1` 또는 **예시 자료 채워보기**. 기존 입력은 확인 후 대체하며 실패하면 유지한다. **비우기**로 빈 상태로 돌아간다. 예시로 채운 JSON은 `demo: true`와 출처 안내를 포함한다. 사진·문구 출처는 `assets/README.md` 참조.

## 현재 세 구성의 차이
- 산지 상점: 감귤빛의 큰 도현 제목과 사진 표지, 번호를 붙인 설명 장면, 강한 색 대비.
- 산지 화보: 깊은 초록의 표지, 고운바탕 Bold, 너비를 채우는 사진과 가운데 정렬 설명.
- 농가 이야기: 사진 우선 표지, 종이색과 명조 본문, 문단별로 이어지는 농가 이야기.
- 모두 상품 표지 → 원산지/품종/중량 → 문단별 설명과 추가 사진 → 입력한 구성/농가 소식 → 입력한 포장/보관/배송 안내로 구성한다. 글은 빈 줄로 나눈 원문, 사진은 사용자가 정한 순서다. 첫 번째 사진은 표지, 두 번째부터 이야기 문단·구성 안내·농가 소식 순으로 대응하며 남는 글/사진도 생략하지 않는다. 농가 소식 장면에서는 대응 사진이 먼저 나온다. 편집기에서 글과 사진 순서를 맞춘다.

## 쿠팡 상세 이미지 재검토
- [쿠팡 황금향 상품의 판매자 상세](https://www.coupang.com/vp/products/9752922352?itemId=29205427307&vendorItemId=96123339466): 브라우저에서 첫 장, 중간 설명 장면, 구매 안내 이미지를 직접 확인(2026-10-14). 큰 제목과 큰 상품 사진을 한 표지로 묶는 방식, 한 장면에 한 설명, 하단 구매 안내의 구획을 참고했다.
- 기존 해외 브랜드/매거진 참고보다 국내 판매 상세 구성에 우선순위를 둔다. 판매자의 합성 이미지, 카피, 인증 배지, 후기, 품질 수치와 정책은 가져오지 않는다. 사진은 기존 레포 데모 또는 사용자가 제공한 원본만 사용한다.

## 여러 상품 비교 후 긴 구성 보강
[조사 기록](coupang-research.md)에 쿠팡 1개와 오아시스·롯데·남도장터·달콤트리·새농·토마로우 6곳의 상세 이미지 확인 범위를 구분했다. 추가 쿠팡 상품은 403으로 시각 검토하지 못했다. 원문 이야기와 상품 구성·농가 소식의 구획을 나누고, 긴 문단은 17px 본문으로 표현한다. 예시는 기존 자료의 사진 6장과 원문만으로 확장했으며 포장·보관·배송처럼 없는 자료는 만들지 않는다.

## 상품 정보 내용 분석 후 반영
[내용 분석](content-analysis.md)은 원본 상세 이미지의 문구·규격표·주의사항을 구매자 질문별로 읽은 결과다. 상품 요약 직후 맛·식감/크기·편차/품질 기록·인증/수확·출하를 입력한 만큼 표시한다. 하단은 구매 전 확인, 포장과 배송, 받은 뒤 안내로 나눈다. 편집기의 추가 정보 목록에서 빈 항목으로 이동할 수 있다. 이 목록은 입력 유무만 나타내며 상품 검증이나 게시 조건이 아니다. 기존 가상 원문이 없는 품질 기록·규격·보관법·정책은 데모에 채우지 않는다.


## 현재 구성 화면과 보존본
- `all-sections.html`: 단일 템플릿, 개별/구역 토글, 전체 켜기/모두 끄기/기본 구성 복구. 선택만 로컬에 저장하며 자료 없는 항목을 켜면 구성 예시 표시와 함께 해당 정보/사진 자리를 보여 준다.
- `all-sections-six.html`: 이전 여섯 시안 비교 보존본. 과거 template URL은 이 보존본에서 사용한다.
- `all-sections-v1.html`: 최초 12장면 보존본.
- `index.html`: 이전 입력 작업실. 필드 편집/사진/JSON 계약은 그대로 유지한다.

현재 구성은 상품명을 고정하고 11개 정보 항목 + 7개 보조 요소를 선택한다. 참조 패널은 기본 닫힘이며 9개 원본과 출처를 그대로 제공한다. 기존 가상 농가 자료만 판매 미리보기에 사용한다. 세부 규칙은 spec.md의 AC-TPL-10~12를 따른다.
