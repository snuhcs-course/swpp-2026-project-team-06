# 판매페이지 작업실 · 3종

산지 상점 / 농가 매거진 / 농가의 편지을 같은 자료로 비교한다. 실제 판매 저장 기능과 AI 추출 연결 전 단계다. **빈 상태가 기본이다. 예시 보기 또는 `?demo=1`에서만 기존 가상 농가 자료를 채운다.**

## 실행
이 폴더에서 `python -m http.server 8284 --bind 127.0.0.1`을 실행하고 http://127.0.0.1:8284/ 를 연다. npm 설치나 API 키가 필요 없다.

## 사용
1. 구성 선택 → 로컬 사진 추가(최대 6장) → 직접 작성한 문구 입력.
2. 사진 설명·순서를 바꾸고 3종 비교 또는 선택한 시안에서 확인.
3. 너비 선택 360/390/430px. 브라우저가 좁으면 그 안으로 축소한다.
4. 편집안 내려받기는 텍스트·템플릿 ID·사진 파일명/설명만 JSON으로 저장한다. 사진 원본은 별도 보관한다. JSON 재불러오기와 서버 저장은 이번 범위가 아니다.

사진은 브라우저 메모리에서만 처리하며 네트워크로 전송하지 않는다. 탭을 닫거나 새로고침하면 입력이 사라진다. 새 품질 수치·가격·인증·광고 문구·생성 사진은 만들지 않는다. 예시 문구는 기존 디자인 원문을 재사용한다. 입력 문구의 사실 여부는 사용자가 확인한다.

## 구성
- `templates.mjs`: 필드와 사진을 받는 공통 데이터 모델, 서로 다른 3개 판매 본문 렌더. 사용자 문자열은 textContent로만 처리.
- `studio.mjs`: 편집·비교·검증·로컬 파일·JSON 내보내기.
- `studio.css`: 반응형 작업실과 레이아웃. Pretendard / Do Hyeon / Gowun Batang 사용.
- `assets/`: 검수한 추상 장식, 원본 폰트, 라이선스. `assets/README.md` 참조.

- [Brightland 상품 페이지](https://brightland.co/products/the-duo): 사진과 짧은 소개·핵심 정보 위계 → 매거진형의 제목/사진/설명 리듬. 브랜드 자산과 카피는 사용하지 않음.
- [CrowdFarming 농가 기록](https://www.crowdfarming.com/en/what-the-field/field-notes/your-farmers-voice-hort-de-bitem-y-xerta-august2020/): 농가가 직접 전하는 글·사진 → 농가 편지형. 날짜·재배·품질 사실을 가져오지 않음.

세 시안은 원문을 요약하거나 확장하지 않는다. AI 필드 추출/확인·실제 상세 저장·모바일 앱 통합은 후속 DEV 작업에서 구현한다.

## 채워진 예시
`http://127.0.0.1:8284/?demo=1` 또는 **예시 자료 채워보기**. 기존 입력은 확인 후 대체하며 실패하면 유지한다. **비우기**로 빈 상태로 돌아간다. 예시로 채운 JSON은 `demo: true`와 출처 안내를 포함한다. 사진·문구 출처는 `assets/README.md` 참조.

## 세 구성의 차이
- 산지 상점: 도현 제목 → 원본 비율 상품 사진 → 산지/품종/구성 → 이야기. 선명한 주황과 크림.
- 농가 매거진: 사진 → 고운바탕 Bold 제목 → 이야기 → 크기를 달리한 사진 기록. 따뜻한 종이색과 적갈색.
- 농가의 편지: 고운바탕 제목 → 명조 본문의 편지 → 사진 → 상품 정보. 여백, 초록 잉크, 사전 제작한 종이 장식.
