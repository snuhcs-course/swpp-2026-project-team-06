# 판매페이지 템플릿 작업실

DEV-52 · FEAT-03/04/07 · M-11/12 · 디자인 검토용 독립 프로토타입.

## 구현 결정
- plain HTML/CSS/ES module로 3개 레이아웃과 공통 데이터 모델을 구성한다. 앱·서버·공개 상세 데이터는 변경하지 않는다.
- 기본 상품형, 매거진형, 농가 편지형. 동일한 입력으로 전환하며 글·사진은 유지한다.
- 사진은 사용자 로컬 업로드만 사용한다. 기본 상태의 빈 사진 영역은 자리 표시임을 명시하며 예시 상품 사진을 제공하지 않는다. 사용자가 넣지 않은 품질·인증·배송 문구를 만들지 않는다.
- 사진은 원본 파일을 표시하고 object-fit: contain을 사용한다. 생성·합성·보정은 없다.
- imagegen은 템플릿 제작 시 추상 종이 배경 한 장만 제작한다. 앱 실행 중 AI 호출은 없다. 농장/과일/인물/문자는 생성하지 않는다.
- Pretendard 1.3.9 원본 웹폰트와 OFL 라이선스를 함께 포함한다. 한 가지 폰트의 굵기·여백·구조로 차별화한다.
- 빈 선택 항목은 본문에서 숨긴다. 편집기에만 누락을 안내한다. 가격·품질 수치는 기본값을 주지 않는다.
- 미리보기는 긴 판매 본문만 다룬다. 구매·주문 동작과 게시 저장은 제공하지 않는다. JSON 내보내기에는 텍스트·템플릿 ID·사진 파일명만 포함하며 사진 파일은 포함하지 않는다.
- 업로드 파일은 브라우저 메모리에서만 처리하고 외부 전송하지 않는다. 새로고침하면 작업이 지워진다는 안내와 떠나기 확인을 제공한다.

## 인수 조건
- AC-TPL-1: 세 가지 템플릿 전환 후 입력 글·사진 보존.
- AC-TPL-2: 사진 0/1/3장, 긴 제목/본문, 빈 필드에서도 허구의 사진/사실 없이 표현.
- AC-TPL-3: 사용자 텍스트를 HTML로 실행하지 않는다. 잘못된/큰 업로드는 오류를 표시하고 기존 자료 보존.
- AC-TPL-4: 360/390/430px 미리보기와 모바일 작업실에서 가로 넘침·글자 잘림 없음. 키보드 선택 가능.
- AC-TPL-5: font license와 생성 장식의 출처 기록. AI/판매 API 요청 없음.
