## 이전 입력 작업실의 구현 결정
- plain HTML/CSS/ES module로 3개 레이아웃과 공통 데이터 모델을 구성한다. 앱·서버·공개 상세 데이터는 변경하지 않는다.
- 산지 상점(큰 제목과 감귤빛), 산지 화보(초록과 사진), 농가 이야기(사진 우선과 종이색). 동일한 입력으로 전환하며 글·사진은 유지한다.
- 기본 사진은 사용자 로컬 업로드를 사용한다. 빈 상태로 시작하고, 사용자가 예시 보기 또는 ?demo=1 링크를 선택했을 때만 레포 기존 가상 농가 자료를 채운다. 작업실에 디자인 예시임을 명시하고 JSON에도 demo 표시와 안내를 남긴다. 기존 입력 대체와 비우기는 확인 후 실행한다. 사용자가 넣지 않은 품질·인증·배송 문구를 만들지 않는다.
- 사진은 원본 비율을 보존한다. 생성·합성·보정은 없다.
- imagegen은 템플릿 제작 시 추상 종이 배경 한 장만 제작한다. 앱 실행 중 AI 호출은 없다. 농장/과일/인물/문자는 생성하지 않는다.
- Pretendard 1.3.9를 작업실과 정보 본문에, Do Hyeon을 산지 상점 제목에, Gowun Batang 400/700을 농가 이야기/산지 화보에 사용한다. 공식 배포 폰트와 OFL을 동봉한다. 추가 폰트는 글리프·이름을 바꾸지 않고 WOFF2로 컨테이너를 변환한다.
- 빈 선택 정보는 본문에서 숨긴다. 빈 상품명·대표 사진은 자리 표시로 안내하고, 빈 한 줄 소개는 숨긴다. 가격·품질 수치는 기본값을 주지 않는다.
- 미리보기는 긴 판매 본문만 다룬다. 구매·주문 동작과 게시 저장은 제공하지 않는다. JSON 내보내기에는 텍스트·템플릿 ID·사진 파일명만 포함하며 사진 파일은 포함하지 않는다.
- 업로드 파일은 브라우저 메모리에서만 처리하고 외부 전송하지 않는다. 새로고침하면 작업이 지워진다는 안내와 떠나기 확인을 제공한다.

- 쿠팡 상세 이미지의 표지·설명 장면·구매 안내 구획을 참고한다. 모든 시안에서 상품 사진을 초반에 배치하고 원산지/품종/중량은 한 곳에 요약한다. 소개는 빈 줄 단위로 분리해 원문을 그대로 표시하며, 추가 사진은 순서대로 한 장씩 배치한다. 사진의 의미를 추론하거나 글을 요약하지 않는다. 남는 사진/문단도 모두 표시한다. 이야기 뒤에 구성 안내(composition)·농가 소식(updates)를 입력한 경우 별도 제목의 장면으로 배치한다. 사진은 이야기 문단 → 구성 → 소식 순서로 대응하며 소식 장면은 사진이 먼저 나온다. 구성 장면에 입력한 중량을 표시한다. 포장(packing)/보관/배송은 입력된 항목만 하단 안내에 표시한다. 120자 초과 문단은 17px 본문으로 전환하고 원문은 그대로 유지한다.

- 상세 이미지 비교의 확인 범위와 적용 근거는 [조사 기록](coupang-research.md)에 구분한다. 쿠팡 1개와 타 판매처 6곳의 공개 이미지 전체/부분을 참고했으며 추가 쿠팡 상품은 접근 제한으로 시각 검토하지 못했다.

- 상품 질문 분석(content-analysis.md)에 따라 flavor/size/quality/harvest를 요약 다음의 17px 설명 목록으로 표시한다. 원문만 표시하며 측정/인증 배지·규격 수치를 추론하지 않는다.
- 하단은 notice/support(구매 전), packing/delivery(포장·배송), storage/usage(수령 후)로 묶고 빈 그룹은 생략한다. 모든 입력은 textContent로 렌더하고 JSON에 원문을 보존한다.
- 편집기의 추가 정보 목록은 10개 상품 선택 항목 중 빈 항목으로 이동한다. details를 열고 입력란에 초점을 주며 입력/비우기/예시 대체 후 즉시 갱신한다. 입력 유무 외 사실 검증·게시 조건은 평가하지 않는다.

## 현재 상세페이지 구성 — 구매자 중심 단일 템플릿
`all-sections.html`은 중량/상품 선택 후 읽는 상세를 구성하는 독립 프로토타입이다. 이전 작업실과 `all-sections-six.*`, `all-sections-v1.*`는 보존한다. 앱/API/JSON 계약은 변경하지 않는다.

- 총 18개 요소: 정보 11개(1/2/3/5/6/9/10/11/13/15/18), 대표 사진·상품 요약·농가 글·농가 사진·농가 소식·배송·문의 안내 7개. 가공/조리/다른 옵션 추천/혼합/중복 품종 비교를 현재 선택 목록에서 제거한다.
- 구매자 순서: 상품 소개 → 받으실 구성·개수 → 맛과 크기 → 품질과 생산 과정 → 포장과 배송 → 보관 → 구매 전 확인 → 선택적 농가 이야기·소식. 산지/품종은 상품 요약에서 한 번 표시한다.
- 선택 상품의 구성은 기존 원문으로 표시한다. 5kg/10kg 비교표·막대와 박스 중량의 별도 강조는 없다. 개수/범위는 농가가 확인한 값만 사용하고 중량에서 계산하지 않는다.
- 크기 구역은 기존 가상 농가 예시 사진 또는 ImageGen 손 위 감귤 일러스트 소/중/대3종 중 생산자가 선택한다. 그림에는 ‘크기 설명용 일러스트 · 실제 규격 아님’을 표시하며 치수/무게를 추정하지 않는다. 최초 기본값은 기존 사진이고 선택은 별도 로컬 저장한다. 선택하면 크기 요소가 켜지며 구성 기본 복구는 요소 목록만 복구하고 그림 선택은 유지한다. 생산 과정에서 중복하지 않는다. 실제 상품 규격은 별도 실측 자료로 확인한다.
- 기본 11개 요소: 1/2/3/6/9/10 + 대표 사진/상품 요약/농가 글/농가 사진/농가 소식. 기존 가상 농가 자료임을 명시한다. 품질 근거·개수·실판매 크기 증빙·보관·배송·문제 접수 자료는 현재 없다.
- 디자인 검토 중에는 자료 없는 요소도 선택하면 사진/개수/기록/배송/보관/FAQ/문의 형식의 자리 표시를 보여 준다. 각 구역에 구성 예시·자료 입력 전임을 명시한다. 실제 수치·조건·사진은 생성하지 않는다. 목차는 선택한 구역을 반영한다. 전부 끄면 상품명만 남는다.
- 제작 중 요소 선택만 로컬에 저장하며 실제 상품 게시/저장/업로드/텍스트 입력은 연결 전이다. 같은 storage 키의 version 2 payload를 사용한다. 현재 version 2만 읽으며 허용된 항목만 복원한다. 저장 실패 시 세션에서 계속 사용한다.
- 그래픽 보기 버튼과 graphics 쿼리 모드는 제거한다. 상품 요약과 수확→선별→출하 도식은 내장 imagegen에서 제작한 투명 PNG 아이콘을 사용한다. 사진 자리 아이콘도 PNG로 표시하며 현재 본문에 SVG 아이콘을 남기지 않는다. Pretendard 17px/행간1.6, 기본390px 및360/430px를 지원한다. 9개 원본은 선택적 비교 패널에서만 쓴다.
- AC-TPL-10(수정): 18개 요소 선택/구역 선택이 즉시 반영된다. 전체 켜기에서 18개 요소와 7개 자료 입력 전 구역이 모두 보인다. 빈 목차/구역은 없다.
- AC-TPL-11: 전체 해제/기본 복구/구역 부분 선택과 재로딩 유지, 저장 실패 시 조작을 지원한다.
- AC-TPL-12: 360/390/430px에 가로 넘침이 없고 이전 작업실·보존본·API/JSON 계약은 유지한다.
- AC-TPL-13(수정): 기본·전체 켜기·v1 복구·graphics URL에서도 동전 도식과 중량 비교가 없고, 개수를 추정하지 않는다. 전체 켜기에서도 자료를 지어내지 않고 형식별 자리 표시로 구분한다.

- 2026-10-14 사용자 요청에 따른 생성 범위 추가: 원산지·품종·수확·선별·배송·사진 자리의 상징 아이콘 6개. 실제 상품/농장/사람 사진이나 판매 문구는 생성하지 않는다. assets/icons/README.md에 내장 도구·최종 프롬프트·원본 경로를 기록한다. 원본 알파를 보존하고 라벨은 HTML, 아이콘은 장식 이미지로 접근성 중복을 방지한다. 이전 작업실/보존본은 변경하지 않는다.
- 2026-10-14 사용자 요청으로 모든 생성 구획선을 기존 CSS 1px 선으로 원복했다. 제목 옆 선은 남은 폭을 채우며 상품 요약/공정은 기본 상단 테두리를 사용한다. 생성 선은 기록용 assets/decor/roles.md에만 보존한다.
- 사진 6장 바깥의 ImageGen 종이 테두리 14px는 유지한다. 원본 사진 비율을 보존하고 중앙을 채우거나 사진 위에 덮지 않는다. 아이콘·제어 패널은 유지한다.
- 손 위 일러스트는 사진 프레임 없이 투명 PNG 원본 비율로 표시한다. 원본과 내장 ImageGen 최종 프롬프트는 assets/size-guide/README.md에 보존한다. 기존 사진 선택 시 6장, 일러스트 선택 시 기존 사진5장과 그림1장이 표시된다. 이번 생성 허용은 상징 일러스트이며 실제 상품 사진/판매 사실 생성이 아니다.
- 현재 소/중/대는 손 채색·피부 주름 없이 회갈색 윤곽선만 사용하고 감귤은 기존 fruit.png의 평면 종이 질감으로 맞췄다. outline-*.png를 사용하며 이전 hand-*.png는 보존본이다.
- 일러스트 옆에는 ‘기준 손 길이18cm / 손끝~손목 / 비교용 가정’ 텍스트만 표시한다. 자 아이콘은 사용자 요청으로 제거했다. 세 크기 모두 같은 기준이며 예시 사진에는 붙이지 않는다. 감귤 치수를 계산하지 않는다. 원본/프롬프트는 assets/size-guide의 outline-prompts.md에 기록하고 ruler-prompt.md와 자 이미지는 이전 기록으로 보존한다.
- 현재 본문의 소제목7개(구성/맛과 크기/생산/포장과 배송/보관/구매 전 확인/농가 이야기) 앞에는 새 ImageGen 종이 질감 아이콘36px를 표시한다. 제목은 HTML로 유지하고 장식 이미지는 빈 alt를 사용한다. 기존 얇은 CSS 구획선은 유지하며 제목이 길면 단어 단위로 줄바꿈한다. 원본/최종 프롬프트는 assets/headings/README.md에 기록한다.
