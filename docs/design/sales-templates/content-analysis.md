## 분석에서 드러난 차이

1. **농가 이야기만으로는 상품 선택에 필요한 정보를 대신할 수 없다.** 농가 역사·재배 철학과 별도로 맛, 낱개 크기, 선택 옵션, 출하, 수령 후 처리에 대한 답이 있어야 한다.
2. **총중량과 크기는 별개다.** 현재 데모의 5kg은 총중량만 말한다. 기존 원문에 크기 편차 문장은 있지만 실제 등급·지름·과수량은 없다. 이를 2S/S 등 다른 판매자의 규격으로 보완하면 허위 정보가 된다.
3. **사진의 목적도 달라야 한다.** 분위기 사진, 단면/과육, 실물 크기 비교, 선택 옵션의 실제 포장, 선별 과정은 서로 다른 질문에 답한다. 현재 사진 6장은 디자인 예시이며 해당 농가의 공정·규격 증거가 아니다. 없는 단면/비교/포장 사진을 생성해서 채우지 않는다.
4. **원산지 설명과 품질 증거는 별개다.** 산지나 물을 아껴 키웠다는 설명만으로 당도 수치·인증·등급을 만들지 않는다. 광고에 수치가 있어도 측정 대상/시점과 실측/예상 구분을 확인해야 한다.
5. **받은 뒤 안내는 상품별로 다르다.** 새농은 냉장 보관의 장점을 설명하고, 토마로우는 향을 이유로 냉장을 권하지 않는다고 적는다. 두 판매자의 서로 다른 상품 안내를 하나의 기본 토마토 보관법으로 합치지 않는다. 감귤의 후숙 기간도 판매처마다 달라 기본값으로 쓰지 않는다.
6. **주의 문구를 공통 반품 정책으로 복사하면 안 된다.** 특정 판매자의 크기/외관 제한을 팜클럽 정책처럼 가져오지 않는다. 이 프로토타입은 생산자가 제공한 유의사항/문의 절차를 표시할 뿐 기존 거래·환불 정책을 바꾸지 않는다.

## 템플릿 반영

- 표지 → 기본 정보 → **상품을 더 자세히(맛·식감 / 크기·편차 / 품질 기록·인증 / 수확·출하)** → 기존 농가 이야기·구성·소식 → **구매 전 확인 / 포장과 배송 / 받은 뒤에는**.
- 7개 선택 필드 추가: flavor, size, quality, harvest, notice, usage, support. 기존 packing/storage/delivery를 하단 그룹으로 재배치한다.
- 편집기의 추가 정보 목록은 빈 선택 항목으로 이동하는 기능이다. 입력 유무만 표시하며 사실 검증·완성도 점수·게시 가능 판정이 아니다. 빈 항목은 소비자용 본문에 표시하지 않는다.
- 가상 데모에는 기존 문장만 배치한다. 정보가 없는데 화면을 채우기 위해 공통 보관법·인증·당도·날짜·정책을 생성하지 않는다.
- 향후 AI 추출 연결 시에는 값과 함께 원문 위치·사진 출처를 제시하고 실측/예상·총중량/낱개 규격·확정/예정일을 구분해 생산자가 확인해야 한다. 자동 추출 자체는 이번 프로토타입에 구현하지 않는다.
