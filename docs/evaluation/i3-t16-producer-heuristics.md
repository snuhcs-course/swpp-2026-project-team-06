# I3-T16 생산자 휴리스틱 점검 시트 (DEV-176)

점검자: 장진우 · 점검 대상: 생산자 앱의 자료 분석(업로드 → 근거 검토 → 편집 → 비공개 저장·반영)과 주문 처리 흐름.
이 시트는 개인 점검 기록이다. 발견한 결함은 T21([DEV-179](https://linear.app/sswp6/issue/DEV-179))에서 우선순위를 정해 고친다.

## 0-1. 점검 방법 (공개)

- 점검자(장진우)가 점검 범위·과업·기준을 정하고 전체 흐름을 직접 보며 점검을 주도했다. 발견의 채택, 심각도 확정, 설계 결정은 모두 점검자가 내렸다.
- 사람이 화면만으로 확인하기 어려운 부분은 AI 도구로 보완했다. 에이전트가 과업 A–E를 실제 로컬 앱에서 조작해 휴대폰 크기 영상 7개(A–E, F1 원문 보기, F2 일부 읽힘 안내)를 녹화했다(실측 분석 4회). 대상은 2분 넘는 분석 대기, 오프라인 실패, 서버 응답(충돌 데이터)과 화면 표시의 대조, 실제로 일으키기 어려운 부분 실패 화면이다. Claude는 영상과 녹화 메모로 발견 초안을 정리했고, 점검자가 영상으로 하나씩 확인해 확정했다.
- 첫 녹화의 이미지·PDF 샘플은 한글 폰트 없이 만들어져 글자가 네모 박스로 렌더됐다. 그 영향으로 생긴 3건(T16-B-02/03/04)은 정상 샘플 재녹화(F1)로 테스트 문제임을 확인해 심각도 0으로 남겼다. 평가 실행기(final_eval)는 처음부터 한글 폰트를 써서 T11·T23·DEV-190 점수에는 영향이 없다.
- 수업 시트 원본을 레포·로컬에서 찾지 못해 Nielsen 10 휴리스틱과 0–4 척도로 작성했다.
- 재현하지 못한 과업: A6(실제 부분 실패, F2에서 가짜 응답으로 화면만 확인), B4(해당 상황 없음). B3는 서버 충돌 데이터가 있는데 화면 표시가 없어 결함으로 기록했다.

## 2. 점검 과업

각 단계에서 위 휴리스틱으로 보고, 문제가 보이면 3장에 한 줄씩 적는다. 문제가 없으면 체크만 한다.

### A. 자료 올리기 (SCR-24 새 상품 · 자료 작업 화면)
- [ ] A1 새 상품 → 하단 AI 시트에서 상품사진·자료 추가(텍스트, 사진, 긴 이미지, PDF)
- [ ] A2 대표 사진 없이 분석을 누르면 막히고, 이유가 보이는가
- [ ] A3 분석 중 상태: 얼마나 걸리는지, 지금 무엇을 하는지 알 수 있는가(20쪽 PDF로 확인)
- [ ] A4 20쪽 넘는 PDF: "앞 20쪽만 분석했어요" 안내가 이해되는가
- [ ] A5 분석 실패: 실패 이유와 다시 시도·직접 입력 경로가 보이는가
- [ ] A6 일부만 읽힌 PDF: "N쪽을 읽지 못했어요 / 일부 내용을 읽지 못했어요"를 보고 무엇을 해야 할지 아는가

### B. 근거 검토
- [ ] B1 채워진 각 문구의 근거 원문(어느 파일·어느 쪽)을 찾을 수 있는가
- [ ] B2 "AI가 뺀 문구 N개" 칩과 모달: 왜 뺐는지, 내가 다시 넣을 수 있는지 이해되는가
- [ ] B3 자료끼리 값이 다를 때(충돌) 어떤 값을 고를지 판단할 수 있는가
- [ ] B4 근거를 확인하지 못해 제외한 후보 안내가 겁주지 않고 이해되는가

### C. 편집
- [ ] C1 문구 고치기·숨기기·복원
- [ ] C2 직접 고친 내용이 다시 분석 뒤에도 남는가(덮어쓰지 않는가)
- [ ] C3 사진 설명 넣기·대표 사진 바꾸기
- [ ] C4 빈 칸(점선)에 무엇을 넣어야 하는지 아는가

### D. 비공개 저장 · 반영
- [ ] D1 임시 저장 → 나갔다 다시 들어와도 그대로인가
- [ ] D2 저장 실패(네트워크 끊김 등) 때 입력이 남고 다시 저장되는가
- [ ] D3 반영 전에는 소비자 화면이 바뀌지 않는다는 것을 아는가
- [ ] D4 미리보기 = 반영 뒤 소비자 화면인가
- [ ] D5 반영 확인 창: 무엇이 공개되는지 분명한가
- [ ] D6 다음 단계(판매·가격, SCR-24b)로 넘어가는 흐름이 자연스러운가

### E. 주문 처리 (SCR-22 현황 · SCR-29 출하 처리)
- [ ] E1 현황에서 새 예약·출하할 주문이 바로 보이는가
- [ ] E2 입금 확인 상태를 이해할 수 있는가
- [ ] E3 출하 준비 주문 선택 → 송장 입력 → 출하 확인
- [ ] E4 잘못 누른 출하·송장 수정이 가능한가
- [ ] E5 주문 수량·금액이 상품 설정과 맞는가(불일치는 심각도 4 후보)
