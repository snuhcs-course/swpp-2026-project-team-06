## 2. PWA로 HE를 하려면 필요한 것

1. **지금 상태로는 "홈 화면에 추가"를 쓰면 안 된다.** 설치된 앱은 `start_url=/`로 열리고, DEV-198 평가 모드는 `?evaluator=1`로 들어온 탭의 sessionStorage에만 남아서 standalone 창에서는 테스트 계정 목록이 사라진다. 로그인 상태(localStorage)는 공유되므로 **Chrome 탭에서 먼저 로그인한 뒤** 홈 아이콘으로 열면 로그인된 채로 쓸 수는 있다. 하지만 로그아웃하거나 세션이 끊기면 복구 방법이 없다.
2. 안내 문서(README)에 적을 한 줄: **"홈 화면에 추가 대신, Chrome에서 주소(`…/login?evaluator=1`)를 직접 열어 쓰세요. 탭을 닫으면 다시 주소로 들어오세요."** Chrome이 띄우는 설치 배너("farmclub 설치")는 누르지 말라고도 적는다.
3. 코드로 해결하려면(내일 전엔 무리): 평가 모드를 sessionStorage 대신 localStorage에 두거나(`EXPO_PUBLIC_EVALUATOR_LOGIN`처럼 빌드 변수로), manifest `start_url`에 `?evaluator=1`을 붙인 평가용 manifest를 따로 두는 방법. DEV-198 후속.
4. 모바일 Chrome 탭은 APK의 A1·A2·P1이 모두 없다. 키보드·내비 바·투어 모두 정상.

## 3. 권장
내일 Android 폰 평가는 **Chrome 탭 + 평가 주소**로. APK(키보드·투어 깨짐)와 PWA(테스트 계정 목록 사라짐)는 쓰지 않는다. 노트북은 그대로.

## 4. 만든 데이터
없음. 메시지·주문 없음. 소비자 Chrome 세션은 로그아웃된 상태(PWA 점검 때 로그아웃), 생산자 Chrome 세션은 강영수로 로그인된 채 둠. 홈 화면에 `farmclub` PWA 아이콘 1개가 남아 있다(길게 눌러 제거 가능).
