### 원인 가설 (11/12, main @ `7ad9c123`, 오프라인)
`answer_question`은 ① 키워드 강제 전달(`_HANDOFF`) → ② 규칙 답(`_rule_answer`) → ③ 모델 + 검증(`grounding.validate_model_answer`) 순서다. P1 근거로 답할 수 있는 표현 15개를 ①②에 넣어 봤다.
1. **키워드 오탐**: `셔요`가 존댓말 어미에 걸린다 — "언제쯤 보내주셔요?" → 강제 전달. (`깎`은 "껍질 깎아" 같은 비흥정 표현에도 걸리지만 근거가 없어 결과는 같다.)
2. **규칙 표현 폭이 좁음**: "언제 와요?", "며칠 걸려요?"는 배송 규칙(`배송|도착|수령|받는|받을|출하`)에 안 걸리고, "한 박스부터 살 수 있어요?"는 소량 규칙(`소량|최소`)에 안 걸려 모델로 간다.
3. **FAQ는 질문 문장이 완전히 같을 때만** 규칙으로 답한다 — "보관 방법 알려주세요"(FAQ: "보관은 어떻게 하나요?")는 모델로 간다.
4. **거짓 충돌**: "예약하면 언제 출하돼요?" → 배송 기간(숫자 있음)과 예약 출하 원칙(숫자 없음)을 서로 다른 사실인데 충돌로 보고 전달한다(`_agree`는 한쪽만 숫자면 불일치).
5. (미확인) 모델 경로: 프롬프트의 "배송 날짜 약속은 항상 HANDOFF"가 받는 시기 질문까지 넘기게 하는지, 검증기가 바르게 바꿔 말한 답을 떨어뜨리는지는 capability set 실행으로 확인한다(유료).
