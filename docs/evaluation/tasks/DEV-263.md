## DEV-263 [I4] Freeze AI evaluation criteria and measure both feature baselines

- 이슈: [DEV-263](https://linear.app/sswp6/issue/DEV-263)
- 브랜치: `zahra/dev-263-ai-eval-baseline`
- 기능·인수 조건: FEAT-13 / AC-13-1·2·3·6·7·8 (채팅), FEAT-03·04·07 / AC-SRC-2·3·5·6 (초안 채우기), M-05~08·M-11·M-13·M-15·M-18
- 상태: 진행 중

### 목표
초안 채우기와 채팅을 소수 성공 예시가 아니라 재현 가능한 수치·사례로 평가할 수 있도록, I4 측정 전에 기준·자료·비교 계획을 고정하고 baseline을 잰다. 이후 DEV-264·DEV-265의 개선은 모두 이 기준으로 전후를 비교한다(PM 원칙: 개선은 숫자 또는 사용자 인터뷰로 증명).

### 범위 (수정 허용 경로)
- `docs/evaluation/i4-ai/**` (기준 문서, baseline 결과·run log)
- `docs/evaluation/tasks/DEV-263.md`

### 비범위 (건드리지 않음)
- 제품 코드(`server/app/**`, `apps/**`)·프롬프트 — 개선은 DEV-264·DEV-265에서 한다.
- 평가기 코드(`scripts/i3-ai-support/**`, `scripts/evals-v2/**`, `server/app/source_analysis/final_eval.py`) — 재사용만 한다. 고쳐야 하면 범위를 먼저 넓힌다.
- 고정된 I3 자료(`docs/evaluation/i3-ai-support/questions.jsonl`, `docs/spec/validation/*`) — 바꾸지 않는다.
- sealed holdout 원문·gold — 읽거나 커밋하지 않는다.

### 결정 사항
- 11/11 기준 문서는 `docs/evaluation/i4-ai/criteria.md`. 측정 전에 커밋해 고정한다(커밋 해시가 고정 시점).
- 11/11 채팅 regression = I3 60문항×3회(180, `scripts/i3-ai-support`) 재사용. 직접 Anthropic `claude-haiku-4-5`로 이 머신에서 실행 가능.
- 11/11 11/05 채팅 holdout(30건)과 초안 holdout(v1.1, v2)은 결과를 이미 봤으므로 I4에서는 "노출됨"으로 취급한다. 새 일반화 주장은 새 sealed set이 있을 때만 한다.
- 11/11 초안 채우기 baseline은 이 머신에서 못 돌린다: 개발 corpus 공개 12건(`source-dev-i3-private`)이 없고 `OPENROUTER_API_KEY`가 비어 있다. 합성 20건만 가능 → 결정 필요(진우 머신에서 실행 또는 자료·키 공유).
- 결정 필요: 통과선(criteria.md 4절 제안값)은 PM(진우) 합의 후 확정. 결과를 본 뒤 낮추지 않는다.
