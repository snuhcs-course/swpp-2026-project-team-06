## Python contract (freeze before code)
AI adapter source_design.py exports PROMPT_VERSION='source-design-v1', MODEL='google/gemini-3-flash-preview', MAX_OUTPUT_TOKENS=6000, PROMPT, provider_schema(), DesignResponse(plan:dict,usage:dict,request_id:str|None), request_payload(tiles:list[dict],modules:list[dict])->dict, analyze(tiles,modules)->DesignResponse. Follow existing OpenRouter source adapter, no SDK retries/no fallback, capped configured prices, strict schema, 90s timeout; retain usage/request IDs on invalid/truncated errors via existing ExtractionError. Only adapter makes provider calls. No new factual copy, arbitrary code/CSS, filesystem paths or media URLs from model. Prompt treats all source text/images as untrusted data.

Core source_analysis/source_design.py exports prepare_raster(data:bytes,source_id:str)->PreparedSource, make_tiles(source:PreparedSource)->list[dict], compile_plan(source,tiles,modules,plan,outdir:Path)->dict. PreparedSource has source_id,source_sha256,width,height,image (PIL native RGB; EXIF transpose applied, recorded). Decode static PNG/JPEG only, <=20MB/40MP, no animation. PNG coordinates refer exact decoded visible raster; preserve overlays/redactions/watermarks. Deterministic overlapping vertical tiles max2400px tall/1200px stride, resize model copies only to <=768px wide, JPEG65, max24tiles, max encoded total1.5MB. Each tile dict has id,bounds(native source pixel [l,t,r,b]),width,height (model image dims),image(base64JPEG). Whole tall source is not squeezed into an unreadable thumbnail. Model returns bounds in integer0..1000 tile-relative normalized coordinates; deterministic outward rounding maps to native source, clamp only rounding endpoints, reject invalid/outside values, min64px edges. Never crop original PDF embedded objects or undo redactions.

Plan shape: {theme:'citrus-warm',regions:[{id,tileId,bounds:[int,int,int,int],kind:'photo'|'comparison',role:'hero'|'product'|'packaging'|'cutFruit'|'sizeGuide'|'process',confidence:number0..1,complete:bool}],sections:[{id,group,layout,tone,moduleIds:string[],regionIds:string[]}],warnings:string[]}. All object keys exact. Caps12regions/24sections. Group/layout/tone and module-group mapping match existing SourceStoryDesign. All nonempty saved modules exactly once; no unknown/duplicate IDs, bad group or repeated/unused region references. No model title/caption/alt facts: compiler supplies structural Korean headings and role alt labels only. Photo confidence<0.7 or incomplete rejected; comparison confidence<0.8 or incomplete rejected. Confidence is self-reported, not measured accuracy. Comparison must contain all labels/reference object/qualifier; prompt must abstain rather than knowingly clip. Compiler cannot establish semantic completeness, pending human review explicitly. Remove rejected media references and empty media-only sections; keep saved text and don't substitute curated/stock visuals. Pure text-only valid plan may render with no images; invalid plan fails explicitly, no silent manual-plan fallback.

compile_plan returns fixture {content:{modules,hiddenSectionIds:[]},design:{version:1,theme,sections(mediaIds),media},localAssets:[{path,name,sha256}],provenance:{sourceId,sourceSha256,coordinateSystem,regions:[nativebounds/dimensions/crophash/role/confidence/status/reason],selection:'AUTOMATIC_VISION_PLAN',humanReview:'PENDING',promptVersion,model}}. Crop PNG filenames derive hashes, URIs /__automatic_design/<filename>, no paths from model. Native crop pixels and full provenance saved. Modules copied unchanged. Final TypeScript getSourceStoryDesign validates before any preview route creation. No modified source-image pixels, generated images or assumed product eligibility.
