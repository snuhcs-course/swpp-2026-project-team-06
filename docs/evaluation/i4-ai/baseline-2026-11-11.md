### What this baseline does and does not show

- **Shows:** the I3 regression behavior is intact on current `main`. Safety, state and fault handling are unchanged since I3 b2 (11/03, 180/180).
- **Does not show model answer quality.** Since I3 b2, more questions are handled by fixed rules: 149 trials vs 99, and model calls fell from 72 to 22. Every answerable trial here is a rule answer. So the set cannot measure the I4 goal: answering more of the questions it can answer, without needless handoffs. In the 11/05 sealed holdout, answerable action was 1/15 (`../evals-v2/README.md`).
- **Next for that goal:** measure that on the I4 producer-FAQ capability set (DEV-265), frozen before any improvement.
- **Comparable to I3 b2** in fixtures and scoring. The prompt blob and code differ, which is the intended treatment.
