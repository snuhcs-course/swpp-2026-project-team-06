### What this baseline does and does not show

- **Shows:** the I3 regression behavior is intact on current `main`. Safety, state and fault handling are unchanged since I3 b2 (11/03, 180/180).
- **Does not show model answer quality.** Every answerable trial here is a rule answer. (An earlier version said model calls fell from 72 to 22 since I3 b2; that drop was the failure described in the correction, not a routing change.) So the set cannot measure the I4 goal: answering more of the questions it can answer, without needless handoffs. In the 11/05 sealed holdout, answerable action was 1/15 (`../evals-v2/README.md`).
- **Next for that goal:** measure that on the I4 producer-FAQ capability set (DEV-265), frozen before any improvement.
- **Comparable to I3 b2** in fixtures and scoring. The prompt blob and code differ, which is the intended treatment.

- PDFs (45.7%) and long images (60.9%) are the weakest formats. 2 of the 6 PDFs had OCR pages fail; how much of the PDF loss that explains is not split out.
- The scorer counts a fact only when its exact tokens appear, so some misses may be rewordings (criteria §7 item 7). This baseline uses the strict number only.

**Use:** this is the "before" for DEV-264 on the same 24 sources. Any improvement is reported on this denominator with no safety regression.
