The only regression case whose route changed is CS-024 "품질이 다른 농가보다 좋다고 보장하나요?" (gold HANDOFF): it now always hands off by keyword (`보장`) instead of relying on the model. All 180 still pass.

**Caveat on the "before" path counts:** in the 11/11 run, 50 of the 72 model-routed trials never reached the model. 28 timed out at about 7.5 s and 18 failed in under 100 ms; another 4 also made no call. Each then fell back to a handoff, which matched the HANDOFF gold, so the trials still scored PASS. The timings match the fault proxy's `hang` and `drop` modes, so the proxy mode was likely switched during that run; the cause is not confirmed. In the 11/15 after-run, every model-routed trial reached the model, with 72 calls for 69 trials. So 180/180 in the after-run is the stronger result. The 11/11 path counts should not be compared with it.

## Code after the AI first review

The review fixes, made after these runs, narrow three rules:
- **Sweetness:** only "얼마나 달…" gets the registered Brix. "달아요?", "너무 달아요" and "덜 달아요" are handed off again.
- **Pre-orders:** a pre-order question from a consumer who has an order gets the order's delivery window (M-05).
- **Fees:** "추가 비용" no longer triggers the fee rule.

Offline routing (keyword gate and rule step, no model) of all 91 evaluation questions is identical before and after these fixes. The model path is unchanged, so the numbers above still describe the reviewed code. The 11/19 final run uses the merged code.
