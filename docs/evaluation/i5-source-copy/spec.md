validate_draft: source claim IDs exact; module matches all cited claims; claim coverage once; requiredTerms normalized literal substring guards; numeric facts (number+unit/range context, not bare set union) must be supported by the cited claims, with exact source qualifications. These guards do not establish general semantic validity; critic and human review remain explicit.

Replace only planned text modules from accepted draft plus deterministic option cards; no silent baseline fallback.
