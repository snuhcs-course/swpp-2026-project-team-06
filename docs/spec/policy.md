## 1. 소비자 이용 정책

출하 전에는 언제든 전액 환불하고, 출하 후에는 하자가 있을 때만 환불·교환한다. 문구는 화면에 넣을 초안이고, ○는 상품·주문 데이터로 채운다.

| 상황 | 사용자 문구(초안) | 규칙 |
| --- | --- | --- |
| 결제 수단 | “결제는 신용카드(카드로 내는 간편결제 포함)로만 할 수 있어요.” | R-01 |
| 결제 시점 | “예약할 때 전액을 한 번에 결제해요.” | R-02 |
| 가격 고정 | “예약한 때의 가격으로 확정돼요. 나중에 가격이 바뀌어도 그대로예요.” | R-17 |
| 수량 한도 | “한 번에 최대 ○개까지 예약할 수 있어요.” | R-23 |
| 품절 | “이 단계 물량이 다 팔렸어요. 다음 단계는 ○월 ○일에 열려요.” | R-06 |
| 배송비 | “무료배송” 또는 “배송비 ○원이 따로 붙어요.” 도서산간: “이 주소는 추가 운임 ○원이 붙어요.” | R-20 |
| 받는 시기 | “○월 ○일\~○월 ○일 사이에 받아요.” | R-05 |
| 받는 시기 변경 | “농가 사정으로 받는 시기가 ○월 ○일\~○일로 바뀌었어요. 새 기간으로 받거나 전액 환불받을 수 있어요.” | R-21 |
| 최대 지연 | “○월 ○일까지 출하되지 않으면 자동으로 전액 환불해 드려요.” | R-09 |
| 흉작·수량 부족 | “날씨 등으로 수확량이 모자라면 받을 수 있는 만큼 나눠 보내고, 나머지는 바로 환불해 드려요.” | R-10 |
| 출하 전 취소 | “출하 전에는 언제든 취소할 수 있고 전액 환불돼요. 수수료는 없어요.” | R-07 |
| 출하 후 | “신선식품이라 출하 후에는 단순 변심으로 취소·반품할 수 없어요. 받은 상품에 문제가 있으면 받은 뒤 24시간 안에 사진과 함께 알려주세요. 확인 후 환불하거나 교환해 드려요.” | R-11 |
| 환불 방법 | “환불은 결제한 카드의 승인 취소로 처리돼요. 포인트로 돌려드리지 않아요.” | R-08 |
| 환불 처리 기한 | “환불은 3영업일 안에 처리돼요. 카드사에 따라 반영까지 며칠 더 걸릴 수 있어요.” | R-12 |
| 농가 정지 | “농가 사정으로 판매가 중단돼 전액 환불해 드렸어요.” | R-24 |
| 구매 확정 | “잘 받으셨다면 구매 확정을 눌러주세요. 배송 완료 후 8일이 지나면 자동으로 확정돼요.” | R-14 |

- 하자 신고 기한은 받은 뒤 24시간이다(PQ-01). 단, 법상 표시·광고와 다른 상품은 더 긴 기간 안에 청약철회할 수 있어, 24시간이 지나도 이런 경우는 거부하지 않는다(법률 검토 필요). 출하 후 단순 변심 반품을 막으려면 이 내용을 결제 전에 고지해야 한다. 2장 동의 문구에 넣었고, 효력은 법률 검토에서 확인한다.
- I1에서는 자동 환불(R-09·10)이 동작하지 않는다(FEAT-24, P2). 문구는 그대로 두고 운영자가 Django Admin에서 처리한다.

## 2. 결제 전 고지·동의 문구

주문서(SCR-10)에서 결제하기 전에 아래 4개를 보여주고 항목마다 따로 체크받는다(R-03). 모두 체크해야 결제할 수 있고, 동의 시각을 기록한다. 한꺼번에 체크하는 ‘전체 동의’는 두되 항목별 내용을 펼쳐 볼 수 있게 한다.

| 동의 | 문구(초안) | 규칙 |
| --- | --- | --- |
| ① 받는 시기 | “이 상품은 수확 전 예약 상품이에요. ○월 ○일\~○월 ○일 사이에 받아요. 농가 사정으로 바뀌면 새 기간으로 받거나 전액 환불받을 수 있어요.” | R-05, R-21 |
| ② 지연 시 환불 | “○월 ○일까지 출하되지 않으면 자동으로 전액 환불해 드려요.” | R-04, R-09 |
| ③ 흉작·수량 부족 | “날씨 등으로 수확량이 모자라면 받을 수 있는 만큼 나눠 보내고, 나머지는 바로 환불해 드려요.” | R-10 |
| ④ 취소·반품 조건 | “출하 전에는 언제든 취소하고 전액 환불받을 수 있어요. 신선식품이라 출하 후에는 단순 변심 취소·반품이 안 되고, 받은 상품에 문제가 있을 때만 환불·교환해 드려요.” | R-07, R-11 |

문구 아래에는 이용약관과 개인정보 처리방침 전문 링크를 둔다. I1에서는 주문서 상단에 ‘테스트 서비스입니다. 실제 결제·배송은 일어나지 않아요’를 표시한다.

## 3. 생산자(입점) 정책

farmclub은 농가에서 상품을 사서 소비자에게 파는 직매입 방식이다. 그래서 소비자에 대한 판매자·환불 책임은 farmclub이 지고, 농가와의 책임은 공급 계약으로 정한다. 입점 동의는 가입 신청(SCR-20)에서 받는다.

| 항목 | 정책 | 규칙 |
| --- | --- | --- |
| 가입·확인 | 카카오로 로그인해 신청하고, farmclub이 전화·방문으로 농가인지 확인한 뒤 승인한다. 반려하면 사유를 알리고 다시 신청할 수 있다 | R-22 |
| 상품·가격 | 단계 일정·가격·물량은 농가가 기본값을 바탕으로 정하고 farmclub이 승인한다. 이른 단계가 더 싸야 한다. 판매 중 가격·옵션·단계를 바꾸면 다시 승인받는다 | R-18, R-25 |
| 배송비 | 무료배송과 별도 부과 중에 고르고, 도서산간 지역과 추가 운임을 정한다 | R-20 |
| 받는 시기 약속 | 상품마다 배송 예정 기간을 약속한다. 바뀌면 주문자가 새 기간 동의와 전액 환불 중에 고른다 | R-21 |
| 출하 | 수확을 시작하면 ‘수확 시작’을 누르고, 보낸 뒤 출하 처리한다(송장번호 포함). 원물 그대로 보낸다 | R-19, PRD C-04 |
| 정산 | 소비자가 구매 확정하거나 배송 완료 8일 뒤 자동 확정되면 매입이 확정된다. 한 주 동안 확정된 금액을 모아 주 1회 농가 계좌로 정산하고 거래명세서를 보낸다 | R-14 |
| 수수료·이용료 | 판매 금액의 일정 비율(직매입 마진), 월 매출이 기준 이상인 농가는 서버 이용료. 초기 입점 농가는 수수료 할인. 요율·기준 금액은 공급 계약서에 적는다 | PRD 12장, Q-24 |
| 고객 정보 | 배송에 필요한 정보(받는 사람·연락처·주소)만 보고 배송 목적으로만 쓴다. 배송 완료 후에는 가려진다 | R-15 |
| 직거래 유도 금지 | 메시지에 연락처·계좌를 적거나 farmclub에서 만난 소비자에게 직접 파는 것을 금지한다. 연락처는 자동으로 가려진다. 금지 기간·범위는 공급 계약서에 적는다 | M-16 |
| 정지 | 허위 정보(중량·품질·원산지 등)와 직거래 유도가 확인되면 바로 정지한다. 출하 지연·불이행, 금지 콘텐츠 등 나머지 위반은 먼저 경고한다. 정지되면 출하 전 주문은 모두 전액 환불되고, 농가의 책임은 공급 계약에 따른다. | R-24 |

**공급 계약서에 들어갈 항목** (앱 밖 서면 계약): 공급 수량·매입가·일정·품질 기준, 미달 시 처리(대체 공급·대금 감액·환불 비용 분담), 정산 시점과 철회·하자 환불분 반환, 고객 정보의 목적 외 사용 금지, 직거래 유도 금지, 흉작 등 불가항력 처리.

## 4. 소통·AI 운영 정책

농가는 팔로워 전체에게 말하고 소비자는 농가에게만 답하며, AI는 농가가 등록한 정보로만 답한다.

| 항목 | 정책 | 사용자 문구(초안) | 규칙 |
| --- | --- | --- | --- |
| 메시지 범위 | 농가 메시지는 팔로워 전원에게 가고, 공개를 고르면 농가 페이지 소식에도 남는다 | (생산자) “공개하면 팔로우하지 않은 사람도 농가 페이지에서 볼 수 있어요.” | M-01, M-14 |
| 답장 범위 | 답장은 내가 팔로우한 농가와 나만 본다. 소비자끼리 대화는 없다 | (소비자) “답장은 농가에게만 보여요.” | M-02, M-03, M-04 |
| 연락처 가림 | 전화번호·계좌번호·외부 메신저 ID는 자동으로 가린다 | “연락처와 계좌번호는 자동으로 가려져요. 거래는 farmclub 안에서 해주세요.” | M-16 |
| 금지 콘텐츠 | 욕설·비방, 광고·스팸, 불법 정보, 남의 개인정보, 측정하지 않은 당도 수치, 효능·질병 치료 표현, 남의 사진(사진은 본인 농가·작물만)은 금지한다. 농가와 소비자는 메시지·답장을 신고할 수 있고, 운영자가 확인해 지운다. 신고 기능은 I2(FEAT-31, P2)이고, I1은 운영자가 직접 찾아 Django Admin에서 지운다 | — | — |
| AI 표시 | 모든 AI 답에 ‘AI 안내’를 붙이고, 농가가 쓴 답과 구분한다 | “AI 안내는 농가가 등록한 정보로 답해요. 정확하지 않을 수 있어요.” | M-04, M-08 |
| AI가 답하는 것 | 받는 시기, 가격·단계, 당도(실측 우선, 예상이면 밝힘), 배송비, 내 주문 상태처럼 등록된 정보로 답할 수 있는 질문 | — | M-05, M-15 |
| AI가 답하지 않는 것 | 농약·재배 방식, 환불·보상 요구, 항의·불만, 등록 정보로 답할 수 없는 질문, 가격 할인·흥정, 배송 일정 변경 약속, 개인적인 대화는 농가에 넘긴다 | “농가에 전달했어요. 농가가 답하면 여기서 볼 수 있어요.” | M-06, M-07 |
| AI 오답 | AI 안내마다 ‘틀렸어요’ 버튼을 둔다. 누르면 그 질문이 농가에 전달되고 농가가 바로잡는다 | — | M-17 |

생성형 AI를 쓴다는 고지와 생성물 표시에 대한 법적 의무는 실운영 전 법률 검토에서 확인한다.

## 5. 개인정보 처리 요지

필요한 것만 모으고, 필요한 사람에게만 보여주며, 분석 데이터에는 넣지 않는다(PRD N-05). 처리방침 원문은 이 표를 바탕으로 쓰고 법률 검토를 받는다.

| 상황 | 모으는 정보 | 목적 | 보유 기간 | 누구에게 가나 |
| --- | --- | --- | --- | --- |
| 로그인 | 카카오 이름, 카카오 식별자 | 회원 식별 | 탈퇴 시까지(PQ-06) | — |
| 주문 | 받는 사람 이름·연락처·주소 | 배송, 거래 기록 | 전자상거래법상 거래 기록 보존 기간(검토 필요) | 해당 농가에 배송 업무를 처리 위탁. 배송 완료 후 가림(R-15) |
| 생산자 신청 | 이름, 농가명, 지역, 주 품목, 연락처 | 입점 심사, 정산, 연락 | 탈퇴·계약 종료 시까지(PQ-06) | — |
| 메시지·답장·사진 | 본문, 첨부 사진·영상 | 소통, AI 응답 | PQ-06 | 해당 농가. AI 서비스에는 연락처·주소를 뺀 본문만 보낸다(M-18). Anthropic Claude API(국외) 사용을 처리방침에 고지한다. 국외 이전 고지 요건은 법률 검토(PQ-08) |
| 이용 기록 | 화면 조회·주문 등 이벤트 | 서비스 개선(PRD 4장 지표) | PQ-06 | 개인정보는 넣지 않음 |
| 배송지 저장 | 받는 사람 이름·연락처·주소(소비자가 저장한 것) | 다음 주문 입력 간소화 | 삭제하거나 탈퇴할 때까지 | — |

동의는 로그인(SCR-05)에서 받고, 농가에 배송 정보를 넘기는 것은 처리 위탁으로 보고 처리방침에 수탁자(입점 농가)와 업무(배송)를 고지한다. 직매입이라 farmclub이 판매자이고 농가는 배송을 대신하는 구조이기 때문이다(법률 검토 필요).

## 6. 법정 표시

온라인 판매에 필요한 표시다. 항목은 실운영 전 법률 검토에서 확정한다(R-16).

| 위치 | 표시 항목 |
| --- | --- |
| 모든 화면 하단 | 상호, 대표자, 사업자등록번호, 통신판매업 신고번호, 주소, 연락처, 개인정보 보호책임자, 이용약관·개인정보 처리방침 링크 |
| 상품 상세(SCR-04) | 원산지, 생산자, 중량·수량·크기, 생산연도 또는 포장일, 보관 방법, 소비자 상담 연락처 등 농산물 상품정보 |
| 주문서(SCR-10) | 결제 전 고지·동의(2장) |

I1은 법인 설립 전이라 사업자 정보 자리에 ‘테스트 서비스’를 표시하고, 설립·신고 후 채운다.
