| ② 지연 시 환불 | “○월 ○일까지 출하되지 않으면 농가가 전액 환불해요.” | R-04, R-09 |

동의 4개 아래에 **중개자 고지와 입금 안내**를 한 문단으로 둔다(DEV-68, 체크 없음): “예약하면 농가 계좌로 직접 입금해요. 24시간 안에 입금하지 않으면 예약이 자동으로 취소돼요. farmclub은 통신판매중개자이고, 상품·배송·환불의 책임은 판매자인 ○○농가에 있어요.” 입금 안내(SCR-11)에도 같은 고지와 판매자 정보(6장)를 표시한다.

문구 아래에는 이용약관과 개인정보 처리방침 전문 링크를 둔다. I1·I2에서는 주문서 상단에 ‘테스트 서비스예요. 실제 입금·배송은 일어나지 않아요’를 표시한다.

## 3. 생산자(입점) 정책

farmclub은 농가와 소비자를 잇는 **통신판매중개자**다(2026-10-18 팀 결정, DEV-68, C안). 판매자는 농가이고, 소비자 돈은 농가 계좌로 직접 들어가며 farmclub은 돈을 받거나 보관하지 않는다. 소비자에 대한 판매·배송·환불 책임은 농가가 지고, farmclub은 입금 확인·환불 요청을 중개하며 이용 수수료를 따로 정산한다(수수료 정산은 후속). 농가는 승인 뒤 입금 계좌(은행·계좌번호·예금주)를 등록해야 상품 승인을 요청할 수 있다. 입점 동의는 가입 신청(SCR-20)에서 받는다.

| 항목 | 정책 | 규칙 |
| --- | --- | --- |
| 가입·확인 | 로그인해 신청하고(I1 테스트 계정, I2 카카오), farmclub이 전화·방문으로 농가인지 확인한 뒤 승인한다. 반려하면 사유를 알리고 다시 신청할 수 있다 | R-22 |
| 상품·가격 | 날짜별 예약 가격·물량은 농가가 직접 정한다. 이른 기간이 더 싸야 한다. farmclub은 공급 총중량의 최초·증액만 승인하고 가격 변경은 신규 주문부터 즉시 적용한다 | R-18, R-25 |
| 배송비 | 무료배송과 별도 부과 중에 고르고, 도서산간 지역과 추가 운임을 정한다 | R-20 |
| 받는 시기 약속 | 상품마다 배송 예정 기간을 약속한다. 바뀌면 주문자가 새 기간 동의와 전액 환불 중에 고른다 | R-21 |
| 출하 | 출하 준비로 기록된 주문을 보낸 뒤 출하 처리한다(송장번호 포함). 예약 주문은 조회만 한다. 원물 그대로 보낸다 | R-19, PRD C-04 |
| 정산 | 소비자가 구매 확정하거나 배송 완료 8일 뒤 자동 확정되면 매입이 확정된다. 한 주 동안 확정된 금액을 모아 주 1회 농가 계좌로 정산하고 거래명세서를 보낸다 | R-14 |
| 수수료·이용료 | 판매 금액의 일정 비율(직매입 마진), 월 매출이 기준 이상인 농가는 서버 이용료. 초기 입점 농가는 수수료 할인. 요율·기준 금액은 공급 계약서에 적는다 | PRD 12장, Q-24 |
| 고객 정보 | 배송에 필요한 정보(받는 사람·연락처·주소)만 보고 배송 목적으로만 쓴다. 배송 완료 후에는 가려진다 | R-15 |
| 직거래 유도 금지 | 소식·채팅에 연락처·계좌를 적거나 farmclub에서 만난 소비자에게 직접 파는 것을 금지한다. 연락처는 자동으로 가려진다. 금지 기간·범위는 공급 계약서에 적는다 | M-16 |
| 정지 | 허위 정보(중량·품질·원산지 등)와 직거래 유도가 확인되면 바로 정지한다. 출하 지연·불이행, 금지 콘텐츠 등 나머지 위반은 먼저 경고한다. 정지되면 출하 전 주문은 모두 전액 환불되고, 농가의 책임은 공급 계약에 따른다. | R-24 |

**공급 계약서에 들어갈 항목** (앱 밖 서면 계약): 공급 수량·매입가·일정·품질 기준, 미달 시 처리(대체 공급·대금 감액·환불 비용 분담), 정산 시점과 철회·하자 환불분 반환, 고객 정보의 목적 외 사용 금지, 직거래 유도 금지, 흉작 등 불가항력 처리.

## 4. 소통·AI 운영 정책

농가는 소식방에 방송하고 소비자 답장은 그 소비자와 농가만 본다. 별도 1:1 채팅에서 농가 AI ON·방 AUTO일 때만 AI가 근거 있는 정보로 답한다.

| 항목 | 정책 | 사용자 문구(초안) | 규칙 |
| --- | --- | --- | --- |
| 소식 범위 | 농가 소식은 팔로워 전원의 소식 탭에 가고, 공개를 고르면 농가 페이지 소식에도 남는다. 볼 수 있는 소식에는 좋아요를 누를 수 있다 | (생산자) “공개하면 팔로우하지 않은 사람도 농가 페이지에서 볼 수 있어요.” | M-01, M-14 |

I1은 법인 설립 전이라 사업자 정보 자리에 ‘테스트 서비스’를 표시하고, 설립·신고 후 채운다.

사업자 정보 값은 레포에 쓰지 않는다(GitHub 공개 동기화). 빌드 때 `EXPO_PUBLIC_BUSINESS_*`·`EXPO_PUBLIC_PRIVACY_OFFICER`로 넣고(배포는 GitHub Actions 변수 `BUSINESS_*`·`PRIVACY_OFFICER`), 값이 있는 항목만 하단에 보인다. 하나도 없으면 ‘테스트 서비스’만 보인다(DEV-113). 하단 위치는 지금 두 앱의 첫 화면(소비자 홈, 생산자 로그인)과 로그인·내 정보·환경설정이다.
