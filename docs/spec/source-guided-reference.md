# DEV-464 원문 기반 판매페이지 디자인 참조 실험

FEAT-03/04/07, AC-SRC-1/2/5/7/9/11, N-01/02 및 M-11/13/18을 따른다. 사용자 승인 범위는 고정된 기존 초안 글을 유지하면서 원문의 대표사진·포장·단면·완전한 크기 비교 그림을 관련 섹션에 배치하고 주황/크림 계열로 디자인하는 로컬 읽기 전용 참조다.

공용 ModuleStory의 명시적 선택 인자에만 타입이 있는 디자인 계획을 받는다. 생산자 편집/기존 소비자 렌더링, 서버 저장·반영 및 공개 동작은 바꾸지 않는다. 잘못된 계획은 기존 렌더러로 돌아간다. 모든 기존 글은 한 번씩 보존하고 숨긴 섹션과 빈 입력을 존중한다. 크기 그림은 비교 물체·레이블·대략적 비교 안내를 함께 보존하고 실측 크기를 추정하지 않는다. 사진·그림은 원문 비율과 픽셀 출처를 보존한다.

현재 한 자료의 디자인 계획·영역은 에이전트가 제안한 수동 참조이며 사람 검토 전이다. 자동 디자인 생성 정확도, 전체 사진 복구율, 농가 인수나 출시 승인이 아니다. 개인 원문·filled fixture·사진은 git 밖/무시된 로컬 영역에만 둔다. 로컬 Expo 앱에서 공용 컴포넌트의 실제 렌더를 확인하며 운영 배포는 하지 않는다. Figma 반영/후속은 DEV-430으로 추적한다.

## DEV-463 자동 시각 분석·배치 계획 실험
사용자 후속 승인으로 수동 참조와 별도의 로컬 실험을 추가한다. 원본 래스터와 고정 초안 글만으로 모델이 영역과 공용 섹션 배치를 제안하고, 좌표·스키마·모듈 보존을 검증한 뒤 원문 픽셀을 잘라 실제 공용 렌더러로 확인한다. 수동 좌표·배치 계획을 입력하지 않는다. 첫 범위는 사진·긴 이미지이며 PDF 자동 배치는 별도다. 글 재작성·자유 색상 생성은 포함하지 않는다. 기존 누적$5예산 안에서 예약 선행·불확실 비용 보존을 적용한다. 검토 전 자동 공개나 인수·정확도 주장은 하지 않는다.

자동 계획에 비교 그림이 있으면 같은 예약 예산 안에서 별도 시각 검토를 자동 실행한다. 단일 결과(그대로 완전함·확장 후 완전함·검증 불가)로 판정하며 잘못되거나 예산이 부족한 검토는 그림을 선택하지 않는다. 좌표는 같은 원문 문맥 안에서만 확장하고 비교 그림에8%문맥 여백을 더한다. 모델 원좌표와 실제 파생 좌표·해시를 함께 보존한다. 실제 실험은 알려진 래스터2건에 한정되며 사람 인수나 일반 정확도는 입증하지 않는다.

## DEV-450 글·옵션 연결 실험
사용자 승인으로 별도 글 편집 실험을 추가한다. 기존 자동 사진·배치 계획은 그대로 두고 원문 출처가 묶인 중량·과수·크기·포장을 같은 옵션 카드로 만든다. 원문 한도·범위·추정·부정·조건을 바꾸지 않으며, 서술은 중복을 줄인 뒤 출처·보호 검사와 별도 의미 검토를 거친다. 잘못되거나 불확실한 결과는 검토 필요로 남기고 이전 증거를 덮지 않는다. 도우미의 출처 감사는 사람 골드·농가 인수가 아니다. 누적5달러 기존 예산 안의 로컬 실험이며 공개·반영 흐름은 바꾸지 않는다.

## DEV-464 현재 고정 글의 시각 개선 (2026-11-25)
오늘 고정된 원문 보존 글을 새 로컬 fixture에 사용한다. 섹션 그림 아이콘, 큰 제목과 한국어 단어 줄바꿈, 주황/크림색, 관련 사진과 중량·원문 행으로 구성한 옵션 카드를 적용한다. 단일 구성의 단순 과수만 같은 카드에 합치며 조건/범위/대안이 모호하면 원문 서술을 유지한다. 같은 긴 문단의 완전 일치 중복만 최초 위치에 표시하고 원문 참조는 모두 보존한다. 서로 다른 옵션·수량·규격이나 유사 문장은 합치지 않는다. 같은 원문 영역은 한 번만 쓰며 본문과 완전 일치하는 사진 설명은 반복하지 않는다. 크기 비교 그림은 펼치기 버튼으로 원본 전체를 확인한다. 이미지가 없는 자료는 글·카드만 표시한다. 고정 평가/글 생성 및 기본 공개 렌더링은 바꾸지 않는다. 기존 자동 영역 증거 중 현재 구성과 맞는 사진을 선택한 참조이며 새로운 자동 배치 실행이나 일반 품질 보장이 아니다.

DEV-464: 섹션 제목 오른쪽에 남는 너비를 채우는 얇은 구분선을 복원한다. 좁은 화면에서 제목은 줄바꿈하고 구분선은 최소24px을 유지한다.

DEV-464: 가격·복수 세부 옵션처럼 보수적으로 나누기 어려운 구성 값도 원문 전체를 넓은 카드 안에 표시한다. 원문 숫자·구분을 추측해 재구성하지 않는다. 나머지 집중 검토용 텍스트/PDF 사례도 동일한 명시적 디자인 렌더러로 확인한다.

DEV-464: 사진별 captionRef는 같은 섹션의 저장 텍스트 인덱스 하나를 명시적으로 연결한다. 중복 연결·빈 참조·섹션 외 참조·비교 그림 연결은 거부하고 기존 렌더러로 폴백한다. 캡션은 해당 사진 바로 아래 한 번만 표시하며 사진 로딩 실패에도 남긴다. 원문 페이지 링크는 안전한 URI와 유효한 페이지 목록으로 검증한다. 페이지 경계를 넘는 사진/설명도 명시적 출처를 보존한다. 이는 알려진 자료의 검증된 참조 연결이며 자동 의미 매칭 정확도 주장이 아니다.

## DEV-464 시각적 스토리텔링 참조
명시적 사진 treatment(full/inset/mark)는 원문 비율·원본 최대 폭 안에서만 전체/삽입/작은 심벌로 표시한다. afterTextRef는 같은 섹션의 저장 서술 인덱스 바로 뒤에 사진을 배치한다. 참조 글은 순서를 유지하고 중복 표시/자동 재작성하지 않는다. 옵션/수량/규격이나 사진 캡션을 앵커로 쓰지 않으며 잘못된 참조는 기존 렌더러로 폴백한다. 숨긴 섹션·사진 실패 처리를 유지한다.
자료별 전 페이지 인벤토리와 누락/한도, 사진 역할(브랜드·상품·산지·사람·재배·포장), 연결 글과 캡션/페이지 출처, 중복·저해상도·제품 혼동 등의 제외 사유를 먼저 기록하고 그 위에 제한된 스토리보드를 만든다. 필요한 사진만 선택하며 모든 사진을 채우지 않는다. 알려진 PDF 한 건의 전41페이지 오프라인 참조는 로컬 진단 한도만 명시적으로 확장했다. 기본20페이지 한도나 고정 글/평가 결과는 바꾸지 않았다. 자동 PDF 의미 선택/페어링은 아직 검증되지 않았으며 이번 선택은 에이전트의 원문 검토 참조다.
