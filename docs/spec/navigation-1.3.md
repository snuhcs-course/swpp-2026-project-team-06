# 스펙 1.3 — 내비게이션과 메신저

DEV-3. 화면 구조 변경이며 서버 API·상태 enum·DB·권한은 [1.2 계약](./contracts-1.2.md)을 유지한다. 디자인 HTML은 SWPP-83에서 1.3 구조로 갱신했다.

## 탭과 경로

| 순서 | 소비자 | 생산자 |
| --- | --- | --- |
| 1 | 발견 `/` SCR-01 | 현황 `/` SCR-22 |
| 2 | 내 주문 `/orders` SCR-13 | 상품 `/products` SCR-23 |
| 3 | 채팅 `/chats` SCR-15·18 | 채팅 `/chats` SCR-28 |
| 4 | 내 정보 `/me` SCR-17 | 환경설정 `/settings` SCR-33 |

- 채팅 별도 플로팅 버튼 없음. 세 번째 탭 배지는 기존 1:1 안 읽음 수이며 소식방 읽음 상태는 추가하지 않는다.
- 주문 상세·완료·문의는 `/orders/:orderId`, `/orders/:orderId/done`, `/orders/:orderId/inquiry`. 로그인 복귀·결제 후 이동·뒤로가기를 함께 맞춘다.
- SCR-18 목록은 `/chats?view=news`, 1:1 목록은 `/chats?view=private`. 기존 `/news/:farmId` 방 주소는 유지하며 채팅에 속한다. `/news`는 통합 채팅 소식방 목록으로 연결한다.
- 소비자 최초 진입은 소식방, 생산자는 1:1. 선택과 목록 스크롤은 방 왕복 시 유지한다. 직접 링크 방의 뒤로가기 기본값은 해당 종류의 목록이다.
- 비로그인 소비자의 내 주문·채팅·내 정보는 안내 후 로그인하고 원래 목적지로 복귀한다. 공개 농가·상품 링크 유지.
- 환경설정은 농가 프로필·공유(SCR-30), AI 설정(SCR-31), 로그아웃. 데이터 초기화는 Mock 전용 확인 동작이다.

## 소통 화면

- 소비자는 여러 승인된 팔로우 농가의 소식방과 접근 가능한 농가별 기존 1:1을 본다. 결제 주문 문의의 팔로우 예외 유지.
- 원형 아바타 48px, 이름·최근 메시지 각 한 줄, 시각·기존 1:1 안 읽음 배지. 농가 사진이 없으면 이니셜, 생산자 소비자 목록은 기존 마스킹 이름 이니셜. 새 소비자 사진 필드는 없음.
- 방 헤더에도 원형 프로필. 날짜 구분, 상대/본인 말풍선, AI 표시, 하단 입력창·첨부. 다른 소비자 답장은 미리보기에도 노출하지 않는다(M-19).
- 생산자 소식방은 자기 농가 하나다. 현황·프로필의 '+ 소식'은 제거하고 방 입력창에서 글을 보낸다. 첨부는 SCR-27로 연결하고 게시 후 자기 방으로 돌아온다.
- 최근 메시지 정렬·페이지네이션 유지. 빈 상태·초기 로딩·재시도·기존 목록 유지 오류를 구분한다. 소식방과 1:1 저장 구조를 합치지 않는다.

## 상품 표시 그룹

필터 순서는 아래와 같고 기본은 판매 중이다. 모든 페이지를 읽어 개수를 계산하며 상품은 정확히 한 그룹에 속한다.

| 그룹 | 조건 |
| --- | --- |
| 판매 중 | PUBLISHED이고 중지되지 않았으며 availability가 ENDED가 아님 |
| 심사 중 | PENDING_APPROVAL |
| 작성 중 | DRAFT 또는 REJECTED; 반려에는 수정 필요와 사유 표시 |
| 판매 중지 | PUBLISHED이며 salesPaused=true 또는 availability=PAUSED |
| 판매 종료 | CLOSED 또는 중지되지 않은 PUBLISHED의 availability=ENDED |

CLOSED가 우선한다. 1.2의 수동 중지 우선순위를 유지하므로 중지된 상품은 기간이 지나도 중지 그룹에 남는다. 판매 예정·기간 공백·품절은 판매 중에서 보조 상태로 구분한다. 증액 심사는 현재 그룹에 '물량 추가 심사 중'을 표시한다. 최초 물량 심사만 심사 중에 포함한다. 중량과 가격 계약은 [1.4](./capacity-1.4.md)를 따른다. 현황의 승인 대기는 `/products?filter=review`, 답변 필요는 `/chats?view=private&needsReply=1`로 연결한다.

## 검증

- 두 농가 이상 팔로우·방 전환·답장 격리·주문 문의 예외·50개 초과 페이지네이션.
- 선택/스크롤 유지, 직접 링크·로그인 복귀, 결제 완료·주문 상세·문의 왕복.
- 모든 상품 그룹·개수·재심사·중지/재개·반려·종료.
- 환경설정→프로필·공유·AI 설정; 현황·프로필에 소식 작성 버튼 없음.
- 360/390/430px와 데스크톱에서 긴 이름·배지·키보드·입력창·탭 겹침 없음. 본문 17px, 메타 15px, 터치 영역 48px 이상.
