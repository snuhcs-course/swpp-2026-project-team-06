## 1. 개요

farmclub은 제주 감귤를 수확 전에 예약하고, 농가와 직접 소통하며 제철에 받는 직거래 서비스다. I1(제출 10/9)은 예약판매·소통·AI 세 차별점이 한 흐름으로 작동하는 프로토타입을 Mock 결제로 만든다.

- **소비자**: 믿을 수 있는 농가의 고당도 감귤를, 자라는 과정을 보며 수확 전에 일반 온라인 시세 이하로 예약한다.
- **생산자**: 쓰던 카톡·밴드 문구를 올리면 AI가 상품 페이지와 반복 응답을 맡고, 수확 전 예약으로 수요를 미리 안다.
- **판매 구조**: farmclub이 농가에서 사서 파는 직매입이다. 판매자와 환불 책임은 farmclub에 있다. 가격은 생산자가 플랫폼 기본값을 바탕으로 정하고 farmclub이 승인한다.

| 차별점 | 제품에서의 형태 |
| --- | --- |
| 예약판매 | 단계별 가격. 이른 단계에 살수록 저렴하다. 플랫폼이 기본값을 주고, 단계 일정·가격·물량은 생산자가 정한다 |
| 소통 | 버블(Bubble)처럼 농가 → 팔로워 1:N 메시지. 답장은 농가와 1:1로만 보인다 |
| AI | 상품 페이지 초안 작성, 반복 문의 1차 응답, 판단이 필요한 질문만 농가에 전달 |

## 2. 문제 정의와 배경

소비자는 품질을 미리 알 수 없어서 예약을 망설이고, 생산자는 고객 모집·반복 문의 응대·판매용 콘텐츠 제작을 혼자 감당하기 어렵다.

**유저 스터디 핵심 발견 (10/4 기준)**

| 대상 | 발견 | 제품에 주는 의미 |
| --- | --- | --- |
| 소비자 | 구매 기준은 맛·당도 >> 신선도 = 품질 > 가격 순이다 | 당도가 상품 정보의 중심 |
| 소비자 | 예약 구매의 가장 큰 장벽은 품질을 미리 알 수 없다는 점이다 | 재배 소식·품질 기준으로 신뢰를 만든다 |
| 소비자 | 산지 직구 경험이 적고, 대기 기간은 짧을수록 선호한다 | 배송 예정 기간을 항상 보여준다 |
| 소비자 | 재배·수확 콘텐츠가 가장 매력적이고, 품종 스토리보다 품질이 중요하다 | 농가 소식을 전한다, 품종은 부차적 |
| 소비자 | 일반 온라인 시세보다 비싼 가격은 사지 않는다 | ‘일반 가격 + 고품질’ 포지션 |
| 생산자 | 예약판매 경험이 적고 사진을 거의 찍지 않는다 | 텍스트 입력 중심, 입력 단계 최소화 |
| 생산자 | 14명 연락 중 4명 베타 참여, 2명 검토 후 참여 의사(10/2) | 데모에 실제 농가 문구 활용 가능 |

가설별 잠정 판정은 [근거](/docs/spec/evidence.md)에 있다. 잠정 결론은 ‘범위를 좁혀 Go’(품목 감귤, 일반 가격의 고품질)이며 P13(SWPP-17)에서 확정한다.

**경쟁 대안**: 스마트스토어·올웨이즈는 수확 후 재고 판매이고 농가와의 소통이 없다. 농사펀드·와디즈는 펀딩형이라 상품 구매가 아니라 리워드다.

## 3. 목표와 비목표

**I1 목표**

1. G1. 소비자가 농가를 팔로우하고 감귤를 단계 가격으로 예약 주문까지 끝낼 수 있다.
2. G2. 생산자가 기존 문구만으로 상품을 등록할 수 있다.
3. G3. 농가가 팔로워에게 소식을 보내고, 소비자 질문은 AI가 먼저 답하며 필요한 것만 농가에 간다.
4. G4. 소비자가 결제 전에 당도·등급·배송 예정 기간을 확인한다.
5. G5. 4장의 지표를 측정해 I2 방향을 정할 수 있다.

**비목표**

- 실제 돈의 흐름: 실결제·PG, 농가 정산, 선수금 관리
- 물류: 배송·송장 연동
- 운영 도구: 전용 운영자 화면(I2. I1은 운영자 전용 관리 API를 Swagger UI에서 호출)
- 상품 확장: 감귤 외 품목, 비규격품, 체험, 계약재배·CSA
- 커뮤니티: 소비자 간 대화
- 사진·영상 기반 AI 콘텐츠 생성

## 4. 성공 지표

I1은 가설 검증이 목적이므로 아래 지표를 측정한다. I1은 측정만 하고, 목표치와 Go/Pivot 기준은 I1 결과를 보고 I2에서 정한다.

| 지표 | 정의 | 검증 가설 |
| --- | --- | --- |
| 주문 전환율 | 상품 상세 조회 중 결제 완료 비율 | CH1, CH2 |
| 이른 단계 주문 비중 | 전체 주문 중 첫 단계 주문 비율 | CH2 |
| 팔로우 → 주문 | 팔로우한 소비자 중 주문한 비율 | CH3, CH4 |
| 답장률 | 전체 메시지 수신자 중 답장을 보낸 비율 | CH4 |
| AI 자체 해결률 | 소비자 질문 중 전달 없이 AI 응답으로 끝난 비율 | PH3 |
| AI 초안 게시율 | AI 초안 중 게시까지 간 비율과 생산자가 고친 정도 | PH1, PH5 |

측정에 필요한 이벤트 정의는 트래킹 플랜(기술 설계)에 둔다. 측정 데이터에는 개인정보를 넣지 않는다.

## 5. 대상 사용자

계정 역할은 소비자·생산자·운영자 세 가지이고, 앱은 소비자 앱과 생산자 앱으로 나뉘고, 같은 카카오 계정으로 둘 다 쓸 수 있다. 생산자도 소비자 앱에서 주문할 수 있고, 생산자 앱 권한은 승인 후에만 열린다.

| 역할 | 누구 | 필요한 것 |
| --- | --- | --- |
| 소비자 — 주 사용자 | 40\~50대, 여성 비중 높음. 구매력과 결정권이 있고 농가와 소통할 가능성이 큼 | 적은 단계의 예약, 당도·배송 시기·가격을 한눈에, 큰 글씨 |
| 소비자 — 간접 사용자 | 20\~30대. 직거래 경험이 적고 정보 탐색을 싫어함. 부모 대신 주문 | 받는 사람을 따로 입력, 비교 없이 고를 수 있는 상품 정보 |
| 생산자 | 제주 감귤 농가. 카톡·밴드로 판매해 왔고 사진을 거의 찍지 않음. 당도는 수확 때 측정 가능 | 문구 붙여넣기로 상품 등록, 기본값으로 쉽게 단계·가격 설정, 반복 문의 위임, 수요 파악, 단골에게 링크 공유 |
| 운영자 | farmclub 팀 | 기본값(단계·가격 프리셋) 관리, 생산자 가입·상품·가격 승인, 환불·예외 처리. I1은 운영자 전용 관리 API를 Swagger UI에서 호출해 처리(화면은 I2) |

생산자는 농가를 하나만 갖고, 다른 농가의 상품·주문·메시지에 접근할 수 없다. 소비자는 자기 주문과 자기 대화만 볼 수 있다.

## 6. 사용자 시나리오

I1 데모는 S-1 → S-4를 한 번에 실행한다. 인물은 가상이고 중량·당도는 예시다. 화면 단위 흐름은 IA가, 동작 세부는 기능 명세가 정한다.

**S-1. 생산자 상품 등록** — 제주 감귤 농가 강씨(60대)

1. 생산자로 가입하고 농가 프로필을 만든다. (FEAT-01, FEAT-02)
2. 밴드에 올리던 판매 문구를 붙여넣으면 AI가 상품 초안을 만들고, 문구에 없던 항목은 빈 칸으로 남긴다. (FEAT-03)
3. 강씨가 빈 칸을 채우고, 플랫폼이 제안한 단계·가격 기본값을 고르거나 고친 뒤 단계별 물량과 배송비 방식을 정해 게시를 요청한다. farmclub이 승인하면 공개된다. 그다음 농가 링크를 단골들에게 문자·카톡으로 보낸다. (FEAT-04, FEAT-05, FEAT-19)

**S-2. 소비자 예약 주문** — 김씨(52세), 맛있는 감귤를 제철에 받고 싶음

1. 강씨 농가를 찾아 팔로우한다. (FEAT-06)
2. 상품에서 품질과 받는 시기, 지금 사면 얼마인지 확인한다. (FEAT-07)
3. 5kg를 고르고 받는 사람을 어머니로 입력한다. 배송 기간·지연 시 환불·흉작 처리·취소 조건에 동의한다. (FEAT-08)
4. 카드로 전액 결제하면 예약이 완료되고 남은 물량이 줄어든다. (FEAT-09, FEAT-10)

**S-3. 소통과 AI 응답**

1. 강씨가 팔로워 전체에 “이번 주 착색 시작했어요”를 보낸다. (FEAT-12)
2. 김씨가 “배송은 언제예요?”라고 답하면 AI가 상품 정보로 바로 답한다. (FEAT-13)
3. “농약은 얼마나 치세요?”라고 물으면 AI는 답하지 않고 농가에 전달한다. 강씨의 답은 김씨에게만 보인다. (FEAT-13)

**S-4. 현황과 취소**

1. 강씨가 단계별 예약 수량과 배송할 주문을 본다. 택배를 보낸 뒤 “김○○님 5kg 오늘 보냈어요”라고 입력하면, AI가 해당 주문을 찾아 보여주고 강씨가 확인하면 출하로 바뀐다. (FEAT-14, FEAT-17)
2. 다른 소비자가 출하 전에 취소하면 전액 환불되고 물량이 돌아간다. (FEAT-11)

### 7.2 비즈니스 원칙

모든 기능은 아래 원칙을 지킨다. 규칙 전문(R-01\~R-25, M-01\~M-17)과 예외는 기능 명세(I1-P16) 1장에 있고, 코드·정책·기술 설계는 그 ID를 인용한다. MUST NOT은 Mock 결제에서도 지킨다.

1. **판매자는 farmclub이다.** 생산자·상품·가격은 farmclub 승인 후에만 공개·판매된다. 판매 중 가격·옵션·단계를 바꾸면 다시 승인받는다. (R-18, R-22, R-25, M-13)
2. **카드로 주문 시 전액을 받는다.** 분할 결제, 에스크로, 현금성 결제는 없다. (R-01, R-02)
3. **결제 전에 조건을 알리고 동의를 받는다.** 배송 기간·지연·흉작·취소 조건이고, 약속한 기간을 벗어나면 주문자가 동의와 환불 중에 고른다. (R-03\~R-05, R-21)
4. **출하 전에는 언제든 전액 환불한다.** 환불은 카드 취소로만 하고, 포인트·크레딧 같은 금전성 기능은 만들지 않는다. 농가가 정지되면 그 농가의 출하 전 주문도 전액 환불한다. (R-07\~R-12, R-24)
5. **단계 가격은 이른 단계가 더 싸고, 물량을 넘겨 팔지 않는다.** 주문 금액은 주문 시점 가격으로 고정된다. 한 주문의 최대 수량은 생산자가 정한다. (R-06, R-17, R-18, R-20, R-23)
6. **농가 정산은 구매 확정 때 확정된다.** 출하는 생산자가, 배송 완료는 택배 조회로 확인한다. (R-13, R-14, R-19)
7. **소통은 농가 → 팔로워 1:N이고, 답장은 1:1 비공개다.** 외부 연락처는 자동으로 가린다. (M-01\~M-04, M-14, M-16)
8. **AI는 근거가 있는 것만 답하고, 나머지는 농가에 넘긴다.** AI는 가격·상태를 확정하거나 게시하지 않고, 농가인 척하지 않는다. 소비자는 AI 답에 ‘틀렸어요’를 눌러 농가에 넘길 수 있다. (M-05\~M-13, M-15, M-17)
9. **개인정보는 필요한 만큼만 보인다.** 생산자는 배송에 필요한 정보만 보고, 법정 표시 의무를 지킨다. (R-15, R-16)

| 프리토타입 랜딩 페이지 | 생산자·소비자 가치 제안 문구 | 완료 | `docs/farmclub-producer.html`, `docs/farmclub-consumer.html` |

디자인은 7.3의 N-01·N-02(모바일 우선, 40\~50대가 읽고 누르기 쉬운 크기)를 따른다.

## 12. 비즈니스 모델

**수익 모델**: 올웨이즈처럼 판매 금액의 일정 비율을 수수료로 가져간다. 직매입이므로 실제로는 매입가와 판매가의 차이(마진)다. 월 매출이 기준 금액을 넘는 농가에는 서버 이용료를 받고, 초기 입점 농가에는 수수료를 할인한다. 요율·기준 금액·할인 조건은 공개 문서에 쓰지 않고 설정값으로 둔다(Q-24).

이른 단계 할인은 수확 전에 수요를 모으고, 팬이 생긴 농가가 farmclub 밖 직거래로 빠져나가지 않게 하는 장치다.

## 13. 출시 전략

**진입 경로**: 첫 경로는 농가가 문자·카톡으로 단골에게 보낸 링크다(FEAT-19). 링크를 누르면 그 농가 페이지로 바로 간다. 랜딩 페이지 대기자, farmclub SNS 같은 다른 경로는 이후 순위를 정한다. 가입 없이 농가·상품을 볼 수 있고, 주문·팔로우할 때 카카오로 로그인한다. 여기까지는 소비자 앱이고, 생산자는 생산자 앱 주소에서 가입을 신청한다.

유료 광고 대신 farmclub SNS 계정을 키운다. 어떤 SNS를 할지는 SWPP-77에서 정한다.

### 14.1 용어집

모든 문서와 화면은 이 용어를 쓴다. 코드 식별자와의 대응은 기술 설계가 정한다.

| 용어 | 뜻 | 혼동 금지 |
| --- | --- | --- |
| 농가 | 생산자 한 명이 운영하는 판매 단위. 팔로우·메시지의 대상 | ‘셀러’·‘판매자’가 아님(판매자는 farmclub) |
| 상품 | 한 농가의 한 품종·한 수확 시즌 판매물 |  |
| 중량 옵션 | 상품의 판매 단위. 예: 3kg, 5kg, 10kg |  |
| 단계 | 생산자가 기본값을 바탕으로 정한 판매 구간. 시작·종료 시점과 순서가 있다 | 농사 생육 단계가 아님 |
| 단계 가격 | 단계와 중량 옵션별 판매가 |  |
| 단계 물량 | 단계와 중량 옵션별 판매 가능 수량 | ‘재고’가 아님(수확 전) |
| 당도 | 품질의 1차 기준(°Bx). 예상값과 실측값을 구분 |  |
| 등급 | 외관·크기 기준 일반 등급 |  |
| 배송 예정 기간 | 약정한 배송 시작일\~종료일 |  |
