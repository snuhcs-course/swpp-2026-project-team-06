# 원문 보존·완화 골드 v2 (DEV-447/448)

FEAT-03/04/07 · AC-SRC-2/3/5/10 · M-11/18. 사용자는 복잡하고 모순된 기존 평가를 단순화하고, 검토 필요 정보를 초안에서 빼지 말고 공개 전 확인하도록 승인했다. 이 문서는 평가 정책이며 생산자의 개별 사실 승인이나 출시 승인이 아니다.

## 평가 기준
- 주 지표는 필수 사실의 페이지 전체 보존이다. 위치·문체·선택 정보는 이 점수에서 감점하지 않고 별도 기록한다.
- 기존 critical은 역사적 플래그로 보존하고, 새 essential/optional/review 분류를 별도 sidecar에 둔다. 기존 비critical은 기본 optional, 날짜·기간·발송 등 조건부 사실은 review, 과거 박스 자체 무게는 집중 검토 결과대로 optional이다.
- 단위·공백·범위 기호와 원문에서 확인한 동치 표현을 인정한다. 문장 전체/출처별 alias 일치는 제한된 근거일 뿐 의미 정확도 인증이 아니다. 내용이 다른 제품·옵션·수량·부정·조건은 동일 사실로 인정하지 않는다.
- 페이지 전체 키워드 보존과 같은 문장/옵션으로 연결된 보존을 분리한다. 연결되지 않은 숫자들은 관계 검토 대상으로 남기며 공백·줄바꿈 때문에 사실 자체가 없다고 단정하지 않는다.
- 금액·외부 플랫폼 문구·과거 판매 조건은 비공개 초안의 확인 대상으로 기록한다. 원문에 없는 주장과 개인정보/실제 질병 효능 등 공개 제한 문제는 별도 유지한다. 일반 홍보를 무조건 무근거 환각으로 분류하지 않는다.

## 버전과 근거
원본47자료354사실/154critical은 byte 그대로 남긴다. draft-first-gold-v2는 모든 원래 source/fact ID를 매핑하고 확인된 누락 서술어1개를 optional로 추가한다. 브랜드 소개를 요구하면서 같은 소개를 금지한 충돌은 source-specific rule disposition으로 해소한다. 인쇄된 과수 개수 표현은 집중 검토의 허용 해석을 해당 자료에서만 인정한다. 사실 문구 수정은 설명용이며 실제 채점 동치는 명시 alias와 원래 reference로 결정한다.

migrate.py는 명시된 development 입력만 처리하고 기존 입력/출력을 덮어쓰지 않는다. 원문·상세 골드·수정 이유는 private 파일에 둔다. 선택적 override는 알 수 없는 source/fact/금지 ID와 잘못된 분류를 거절한다. 원본·개정본·sidecar·출력·평가기 해시와 분모를 기록한다. baseline과 모든 비교 arm에 동일 정책을 적용한다. 점수 정의 변경으로 오른 값은 생성 개선으로 보고하지 않는다.

새 정책의 범주 분류는 사용자 승인 정책 적용이며 전체 원자료를 사람이 재검수했다는 뜻은 아니다. 미확정 의미·조건은 review로 명시한다. 사진/시각 디자인·새 holdout·새 유료 생성은 범위 밖이다. 실제 공개 검토 동작은 DEV-452의 source-preserving-drafts.md를 따른다.


## 오탐 교정 평가 v2 (DEV-448)
평가의 공백·단위 정규화는 원문과 출력에 동일 적용하고 원래 문단 경계를 유지한다. 줄바꿈을 지워 숫자/단위를 옆 문장과 붙여 만든 누락·무근거 판정은 교정한다. 숫자값·차원·범위·상하한·부정·조건은 정규화로 바꾸지 않는다.

출처에서 확인한 철자/동치 구절은 source/fact별 명시 selectorAliases로만 추가한다. 원문/골드 해시와 이유·출처를 결합하고 다른 자료로 전파하지 않는다. 이는 키워드 보존 진단의 허용 표현이며 의미 정확성 승인이나 생산자 공개 승인이 아니다. 원문 오타가 남은 경우 내용 보존과 교정 필요를 구분하고, 잘못된 섹션은 배치 지표로 남긴다. 일반 문법·의미 유사성 점수는 추측해서 채우지 않는다.

기존 scorer·골드·저장된 출력·이전 보고서는 보존한다. 새 평가 version과 별도 정책 sidecar를 모든 기존/신규 팔에 동일 적용하고, 바뀐 항목과 이유를 함께 보고한다. 평가 교정으로 얻은 점수는 생성기 개선과 분리한다. 새 유료 호출·OCR·추출·holdout 접근은 없다.
