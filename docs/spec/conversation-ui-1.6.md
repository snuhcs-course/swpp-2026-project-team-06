# 스펙 1.6 — 확정 Figma v6 대화 중심 프론트

DEV-51 · 2026-10-13. [Figma 현재 시안](https://www.figma.com/design/X8RKiRPZbFEEEwi4OhkF0G). 화면 표현·진입은 이 문서가 1.3/1.5의 이전 배치를 대체한다. API·권한·가격 기간·주문 상태 계약은 1.2/1.4/1.5를 유지한다. 원본 Figma와 과거 평가 기록은 보존한다.

홈·검색·상품의 모든 농가 링크와 `/s/farms/:id` 도착점은 소식방이다. 농가 소개를 경유하지 않는다. 소식방의 답장은 1:1로 이동하지 않는다. 상품의 명시적 1:1 문의·주문 문의 흐름은 유지한다.

## 가격·이미지

- 날짜별 가격표와 다음 기간 대비 이득 문구는 소비자 화면에서 제거한다. 생산자 판매 설정의 날짜별 가격 편집은 유지한다(R-18).
- 동일 옵션의 현재 기간 가격과 마지막 기간(seq 최대) 가격을 비교한다. 마지막 금액이 더 높고 현재 예약 가능할 때만 취소선을 표시한다. 비교값 조회 실패/누락/동일 금액이면 현재 금액만 표시한다. ‘정상가’나 임의 할인율은 붙이지 않는다.
- 시안 5kg 36,000→29,000원 / 10kg 68,000→55,000원은 데모 첫 기간 예시다. 날짜 변경 뒤 실제 현재 가격을 사용한다. 품절·중지·종료 상품에는 할인 금액을 만들지 않는다. 결제 시 서버 재검증·STAGE_CHANGED·기존 주문 스냅샷은 유지한다.
- 기존 AI 농가 이야기 이미지(`farm-story.png`)는 신규 Mock 시드 `p-house`에만 지정한다. 다른 상품·실서버 데이터에 fallback으로 삽입하지 않는다. 새 품질·인증 주장을 만들지 않는다. 실제 상품의 기존 text/image 블록은 유지한다.

| 화면 | 구성·동작 | 상태 |

| SCR-22 현황 | 주문·배송 2×2 큰 지표: 전체 주문, 예약 완료, 출하 준비, 출하. 주문/배송 관리 진입, 대표 상품 예약·출하 kg | 전체 cursor를 읽어 실제 건수 표시(전체 판매 기간). kg는 dashboard의 대표 상품 범위를 명시. 채팅 수·답변 진입·소식 작성 없음 |
| SCR-28 채팅 | 소식방 / 1:1 채팅만. 최초 소식방, 자신의 본문이 바로 채워짐 | 농가 하나짜리 목록·전체 대화/답변 필요 필터·목록 AI/직접 응대 상태 없음. 기존 안 읽음 배지 유지 |
| 생산자 소식방 | 두 선택지 → 판매 품목 → 대화 → 입력 → 4개 탭 | 판매 품목 기본 접힘, 전송해도 접힘 선택 유지. 입력은 탭 바로 위 고정. ‘보내는 소식은 모든 팔로워에게 보여요’는 첫 본문 시스템 안내로 함께 스크롤 |
| SCR-27 첨부 작성 | 기존 첨부·공개 여부·입력 보존·멱등 키 유지 | 성공 후 `/chats?view=news`, 다시 전송하지 않음 |
| SCR-29 주문/배송 | 전체/예약/출하 준비/출하 조회. 출하 준비에서 송장 저장·선택·확인 후 출하 | 모든 수확 시작 UI·확인·완료·프론트 호출 제거. RESERVED는 조회만. 기존 PREPARING→SHIPPED를 유지 |

**주문 전이 경계:** 기존 서버 `harvest-start` 계약은 제거하지 않지만 현재 프론트는 호출하지 않는다. RESERVED→PREPARING 자동 전이는 추가하지 않는다. 예약 주문을 보내기 위한 새로운 운영 전이 정책은 이 PR의 범위 밖이다. 서버에 이미 출하 준비로 기록된 주문만 현재 UI에서 출하한다. 취소·배송 완료 권한은 그대로다.

소비자 미리보기는 기존 소비자 앱 농가 URL을 열며 소비자와 동일하게 판매 품목을 펼쳐 보여준다. 생산자 1:1 대화 내부의 응대 모드 전환·AI 근거·문의 처리는 유지한다.
