# 근거 — 유저 스터디 \[잠정\]

잠정 결론은 ‘범위를 좁혀 Go’다: 품목은 감귤, 포지션은 일반 가격의 고품질이다. 10/4 회의 기준이며, 근거 충분성은 P13(SWPP-17) 판정표로 확정한다. PRD의 설계 결정을 바꿀 때 이 표를 먼저 확인한다. 정식 기록처는 위키 User Study Results다.

| 가설 | 내용 | 잠정 판정 | 근거(10/4) | 설계 반영 |
| --- | --- | --- | --- | --- |
| CH1 | 더 싸고, 품질 좋고, 적기에 받고 싶다 | 부분 통과 | 우선순위 맛·당도 >> 신선도 = 품질 > 가격. 시세 초과 가격은 거부 | 당도 중심 상세(FEAT-07), 프리미엄 가격 없음 |
| CH2 | 미리 예약할 의향이 있다 | 불명확 | 장벽은 품질 사전 확인 불가. 대기는 짧을수록 선호. 품종 관심 낮음 | 배송 예정 기간 상시 표시(R-05), 품종 무관 |
| CH3 | 재배 콘텐츠·체험에 가치를 느낀다 | 콘텐츠 통과 / 체험 판정 불가 | 재배·수확 콘텐츠가 가장 매력적 | 1:N 메시지(FEAT-12), 피드는 Q-01, 체험 Out |
| CH4 | 생산자와 직접 소통하고 싶다 | 불명확 | 40\~50대 소통 가능성, 농가 소통과 AI 안내 역할 분리 여지 | 1:N + AI 1차 응답(FEAT-13) |

## 2026-10-07 추가 인터뷰 반영 — 익명 요약

제공받은 생산자 인터뷰·전화 인터뷰·설문 정리에서 제품 요구만 추렸다. 원문 이름·연락처·개별 거래 조건은 공개 저장소에 싣지 않는다. 아래는 해석과 기능 연결이며 전체 시장의 통계로 일반화하지 않는다.

| 관찰 | 제품 결정 | 추적 |
| --- | --- | --- |
| 다른 판로와 수확 불확실성을 고려해 앱에 배정할 수량을 제한하고 싶음 | 상품별 총 판매 박스 한도, 기간 옵션 물량과 함께 검사 | R-26, FEAT-04·05 |
| 원하는 시기에 예약 접수를 멈추거나 다시 받고 싶음 | 판매 중지·재개, 이미 받은 예약은 보존 | R-27 |
| 소량 주문·배송 시점에 같은 설명을 반복함 | 농가 응대 원칙·FAQ 및 미리보기 | FEAT-32 |
| 맛 평가·품질·파손은 상황 확인과 직접 응대가 필요함 | 주문 문맥·비공개 사진 문의, AI 판단 금지 | FEAT-33, M-21 |
| 소비자 확보·지속 소식 제공에 부담이 있음 | 기존 농가 링크·텍스트 초안을 유지하고 소식방으로 접근을 단순화 | FEAT-03·12·19 |

허위 농가·사진 도용 우려는 기존 농가 승인/사진 정책으로 다루며 자동 진위 판정 기능을 추가하지 않는다. 새 기능은 [공통 계약](./contracts-1.2.md)의 범위·인수 조건으로 구현을 검증한다.
