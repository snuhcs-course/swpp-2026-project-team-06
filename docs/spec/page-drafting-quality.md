# DEV-446 판매페이지 콘텐츠·한국어 품질 검토 계약 (제안 v0.1)

상태: **사람 검토/승인 전**. 이 문서는 생성기·gold·scorer·화면을 변경하지 않는다. 현재 제품 계약은 [자료 분석](source-analysis.md), [직접 편집](source-editor.md), [통합](source-integration.md), FEAT-03/04/07 및 M-11/13/18이다. 충돌하면 기존 계약을 적용하고 질문으로 기록한다. 사람 승인 전 이 제안을 새로운 평가/릴리스 통과 근거로 사용하지 않는다.

Zahra가 Jinwoo를 gold 판정자·한국어 문장 reviewer·농가 피드백 조율 담당자로 지정했다. 역할 지정은 검토 수행·참여 일정·농가 동의를 뜻하지 않는다. Zahra는 범위/정책/gate 승인 담당이다. 에이전트가 작성한 판단은 Jinwoo가 원문과 대조하여 판정한다.

## 기존 9섹션·18모듈의 역할

다음은 현재 스키마/정리 라우팅의 역할을 정리한 **검토 기준 제안**이다. 템플릿 순서·숨김·저장·명시적 반영 동작은 변경하지 않는다. 하나의 원문에 여러 사실이 있으면 의미별로 나누되 원문 근거/조건을 보존한다.

## 사실 단위·포함 여부·중요도

하나의 claim은 대상 상품/농가, 관계, 값/단위, 부정, 예상/실측·대략 여부, 날짜·표본·조건을 함께 가진다. 어느 하나가 다르면 자동 중복으로 합치지 않는다. 같은 사실을 여러 원문이 지지하면 하나의 canonical ID로 묶고 모든 출처를 유지한다. 인용 ID 존재만으로 사실 보존을 인정하지 않는다.

| 분류 | 판정 기준 | 점수 처리 제안 |
| --- | --- | --- |
| required | 현재 대상에 적용되고, 안전하며, 구매 판단/상품 이해에 필요한 근거 있는 사실 | 승인된 eligible recall 분모에 포함 |
| optional | 유용하지만 생략이 구매 판단을 바꾸지 않는 보조 배경 | 별도 포함률/품질 검토; required 분모에 몰래 합치거나 빼지 않음 |
| excluded | 기존 계약상 제외(금액·판매/배송 일정·정책·개인정보·효능·다른 상품 등) 또는 적용 불가로 판정 | 이유 기록; 쓰면 정책/정확성 결함. 처리 성공과 구분 |
| unresolved | 원문 위치·대상·현재성·안전 분리 여부가 불명확하거나 판정 불일치 | 승인 gold 동결을 막음. 제외로 바꿔 점수를 높이지 않음 |

critical은 **틀리거나 빠지면 구매 대상을 오인하거나 품질·수량·사용/보관 판단이 크게 달라지는지**로 판단한다. 상품/품종·원산지·옵션과 연결된 중량/개수·핵심 맛/측정 조건·필수 보관 조건은 우선 검토한다. 향 한 단어·교배 연도·과거 연수·참고 그림은 자동 critical이 아니다. 실제 포함/중요도는 claim별 이유와 Jinwoo 판정을 남긴다. 비판적 사실을 선택적으로 optional로 내려 기존 실패를 지우지 않는다.

자료에 쓰인 생산자 주장과 독립 검증은 다르다. 인증 이름이 있다는 이유로 유효기간·대상·공적 검증 완료를 만들지 않는다. 현재성 불명확한 인증/수확/판매 실적은 unresolved로 두고 확인한다. 연도 없는 '올해/작년'을 실행 시점의 연도로 치환하지 않는다.

## 일차 위치·중복·문장 기준

각 canonical claim에 일차 모듈과 근거 있는 허용 대체 모듈을 **출력 평가 전에** 정한다. 의미가 보존된 다른 위치는 page-wide coverage로 인정하더라도 placement는 따로 기록한다. 역사 strict scorer의 결과는 그대로 보존한다. summary의 맛/크기 분리 등 기존 제품 라우팅은 유지한다. 새 대체 위치를 승인하지 않고 과거 점수를 올리지 않는다.

제목의 상품명, 원산지 표시와 소개의 짧은 식별 반복은 유용할 수 있다. 상세 문단 전체를 소개·맛·재배에 반복하는 것은 결함이다. 예: 제목 '제주 감귤', 소개 '제주에서 재배한 감귤이에요', 맛 '산미가 은은하고 과즙이 풍부해요'는 각 역할이 다르다. 세 곳 모두 같은 맛 설명을 붙이는 것은 반복이다. 서로 다른 옵션·표본·연도의 사실을 합쳐 반복을 줄이지 않는다.

문장은 짧고 자연스러운 존댓말로 쓰며 용어·대상·문체를 통일한다. 읽기 좋게 고치더라도 사실·조건을 버리지 않는다. 다음은 **가상 검토 예시**이며 실제 원문/모델 출력이 아니다.

| 근거 예시 | 허용 예시 | 결함 예시 |
| --- | --- | --- |
| '표본 5개의 평균 12브릭스' | '표본 5개의 평균 당도는 12브릭스예요.' | '모든 과일이 12브릭스 이상이에요.' |
| '5kg, 약 30~40개, 크기에 따라 다름' | '5kg에는 약 30~40개가 들어가며 크기에 따라 달라요.' | '30~40개예요.' (옵션/조건 누락) |
| '과피 점이 생길 수 있음. 교환 불가' | 외관 사실만 독립 근거로 안전하게 분리된 경우 '껍질에 점이 생길 수 있어요.' | 교환 불가까지 AI 본문에 게시 |
| '2025년 수확분을 소개한 기록' | 해당 연도를 유지한 농가 이야기 | 이번 판매 상품의 현재 수확분으로 소개 |

혼합 건강/가격/개인정보 후보를 모델이 다시 쓰기만 해서 안전한 것으로 보지 않는다. 현재 검증에서 거절한 후보는 자동 복원하지 않는다. 안전한 절 분리가 필요하면 DEV-453에서 별도 원문·범위 검증 후 처리한다.

## 평가 축과 승인 게이트

사실 보존(eligible claim별 1회), 사실 정확성/수식 조건, 위치, 한국어 편집 품질, 처리 성공을 각각 보고한다. 중복이 coverage를 늘리지 않으며, 한 문장의 맞는 사실이 다른 문장의 무근거 사실을 상쇄하지 않는다. 빈 required 집합은 100%로 꾸미지 않고 N/A·contract outcome으로 표시하되 실패/정책 검사는 유지한다.

기존 목표 **형식별 사실 recall ≥95%, unsupported critical/금지 내용 0건**과 기존 critical FAIL 규칙은 유지한다. 전체 평균으로 형식별 실패를 숨기지 않는다. 새 분모/정규화는 DEV-447/448에서 별도 승인·버전·old→new 매핑 후 양쪽 출력에 같은 기준을 적용한다. 생산자 인수와 공개 여부는 DEV-452/412/413에서 별도 판정한다.

한국어 품질의 4영역 1~5 척도, blind 비교 제안·major defect·통과/불일치 처리·기록 서식은 [review-protocol](../evaluation/i5-page-quality/review-protocol.md)과 [review-form](../evaluation/i5-page-quality/review-form.md)을 따른다. **이 절의 새 평가 절차/임계치는 아직 미승인**이며 과거 실험의 blind 평가를 주장하지 않는다.

## 비용·시간·개인정보 경계

사용자 승인 실호출 누적 상한은 $5다(DEV-445와 공유). 기존 정산 $1.322573 + 미확정 예약 $0.061929 = $1.384502를 이미 사용/예약한 것으로 본다. 실행 전 최신 ledger로 다시 확인한다. 예약 가능한 잔액보다 예상 최대비용이 크면 호출하지 않으며, 불확실 응답은 예약 유지·자동 재호출/모델 fallback 금지다. 이번 문서 작업에는 호출이 없다.

현재 정리 어댑터의 요청 timeout은 90초, 자동 재시도는 0이다. 이는 전체 업로드/OCR/페이지 생성의 사용자 지연 보장이 아니다. 다음 비교에는 소스별 전체/정리 단계 시간, 성공/timeout/실패, p50/p95/max와 표본 수를 남긴다. 여러 호출/작업의 전체 허용 지연과 timeout 실패 허용 여부는 **PM 결정 전 paid run을 막는 미결 조건**이다. 90초를 전체 서비스 SLA로 쓰지 않는다.

기존 어댑터·명시한 제공자/모델·동의한 개발 자료만 쓴다. M-18 가림, 로컬 비공개 원문·gold·진단, 공개 해시/집계 원칙을 지킨다. 새로운 제공자 전송/보존 조건은 별도 확인 전 사용하지 않는다. sealed holdout v2는 열지 않는다. 연구/개발 결과와 릴리스·농가 인수를 분리한다.
