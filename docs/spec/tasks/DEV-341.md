## DEV-341 Make producer photo add and load fast with display-size previews instead of full PNG (스펙)

- 이슈: [DEV-341](https://linear.app/sswp6/issue/DEV-341) · 주 기록 `server/tasks/DEV-341.md`
- 브랜치: `jangjinuite/dev-341-light-photos`
- 상태: PR #639 리뷰 중

### 왜
생산자 화면이 상품사진의 비공개 무손실 PNG(12MP → 약 20MB)를 그대로 받아 사진을 넣고 여는 것이 느렸다. 표시용 사본과 캐시 규칙이 바뀌므로 스펙과 영문 위키 요약을 같은 PR에서 고친다.

### 범위 (수정 허용 경로)
- `docs/spec/source-integration.md`(화면과 공개 계약의 상품사진 줄)
- `docs/spec/source-analysis.md`(작업 상태·자료 보호의 원본 저장 줄 다음 한 줄)
- `docs/wiki/Source-Analysis.md`(끝에 새 절 'Light producer photo previews (DEV-341, November 17)'. 과거 DEV-56/57/58 문단은 고치지 않음)
- `docs/spec/tasks/DEV-341.md`(이 파일)

### 비범위
- AC 문구(AC-SRC-6 등) — 외부 AI 요청·공개 사진 계약은 바뀌지 않는다
- `docs/wiki/Testing-Documentation.md` 03.19(채팅 첨부 사진 캐시) — 다른 경로

### 결정 사항
- 11/17 생산자 미리보기 캐시(`private, max-age=86400`, revision 주소·ETag·`Vary: Authorization`)는 "비공개 자료는 캐시하지 않는다"는 기존 서버 문서 문구의 예외로 적는다. 원본·가림 전 이미지는 `no-store` 그대로.
