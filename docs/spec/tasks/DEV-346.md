### 결정 사항
- PM 11/16: 새 상품과 판매페이지 수정은 같은 화면, 모든 상태에서 composer. 판매 중 상품은 명시적 '상품에 반영' 단계 유지.
- PM 11/16·17(프로토타입 리뷰): 판매 중·승인 대기·종료 상품은 composer에서 상품명·원산지·보관을 잠그고 SCR-25에서 고친다.
- PM 11/17: 버튼 이름은 모든 상태 '판매페이지 수정'('이어서 채우기' 안 씀). composer 밖에서 만든 예전 상품도 옮겨서 composer로 연다.
- PM 11/17(동기화 걷어냄): 구매자에게 보이는 상품은 composer에서 상품명·원산지·보관·품종·당도·대표사진을 잠그고 상품 편집에서만 고친다. 잠긴 칸을 누르면 시트 '상품명·원산지·보관·품종·당도·대표사진은 상품 편집에서 바꿔요' + '상품 편집으로 가기'. 반영은 상세만 바꾼다(대표사진·상품 값 그대로). source-integration.md·screens.md·wiki를 이 규칙으로 고쳤다.
- 기존 편집기(ProductPageEditor) 설명은 지우지 않고 'composer로 옮기지 못한 페이지와 예전 앱에서만 쓴다'로 범위를 적었다.
- API 변경(`composer` 요청·응답, `SourceAsset.productPhoto`)은 별도 계약 문서가 없어 `source-integration.md` 'DEV-346' 절에 적었다.
