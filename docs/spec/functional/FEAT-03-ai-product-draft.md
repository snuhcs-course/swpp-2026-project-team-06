# FEAT-03 AI 상품 초안

> 상위: [PRD](/docs/spec/prd.md) 7.1 · 규칙: [rules.md](./rules.md) · 화면: [IA](/docs/spec/ia.md), [화면 명세](/docs/spec/screens.md) · 추적표: [README](./README.md)

| 항목 | 내용 |
| --- | --- |
| 우선순위·출처 | P0 · PRD 7.1, S-1 |
| 앱·화면 | 생산자 앱 SCR-24 → SCR-25 |
| 목적 | 쓰던 카톡·밴드 문구만으로 상품을 만든다 |
| 사전 조건 | 승인된 생산자다 |
| 정상 흐름 | 1) 문구 붙여넣기 2) 초안 만들기(진행 표시) 3) 결과 확인, 빈 칸 강조 4) ‘편집으로’ → 값이 채워진 SCR-25 |
| 예외 흐름 | E1 AI 실패·시간 초과 → 붙여넣은 원문은 보존하고 빈 편집 화면에서 직접 입력. E2 문구에 가격이 있어도 채우지 않고 ‘가격은 단계 설정에서’ 안내 |
| 사후 조건 | 초안 상태의 상품이 생긴다(소비자에게 비공개) |
| 입력·검증 | 문구 필수, 최대 3,000자. 출력: 상품명·품종·중량 옵션·예상 당도·등급·배송 예정 기간·설명·빈 칸 목록 |
| 규칙 | M-10\~M-12 |

- [ ] AC-03-1. **Given** 당도·배송 시기가 없는 문구다 / **When** 초안을 만든다 / **Then** 두 항목은 비어 있고 빈 칸으로 표시된다
- [ ] AC-03-2. **Given** “5kg 25,000원”이 들어 있는 문구다 / **When** 초안을 만든다 / **Then** 가격은 채워지지 않는다
- [ ] AC-03-3. **Given** AI 호출이 실패한다 / **When** 초안 만들기를 누른다 / **Then** 빈 편집 화면으로 가서 직접 입력할 수 있다
