# FEAT-03 AI 상품 초안

> 상위: [PRD](/docs/spec/prd.md) 7.1 · 규칙: [rules.md](./rules.md) · 화면: [IA](/docs/spec/ia.md), [화면 명세](/docs/spec/screens.md) · 추적표: [README](./README.md)

| 항목 | 내용 |
| --- | --- |
| 우선순위·출처 | P0 · PRD 7.1, S-1 |
| 앱·화면 | 생산자 앱 SCR-24 → SCR-25 |
| 목적 | 쓰던 카톡·밴드 문구만으로 상품을 만든다 |
| 사전 조건 | 승인된 생산자다 |
| 정상 흐름 | 1) 문구 붙여넣기 2) 초안 만들기(진행 표시) 3) 결과 확인, 빈 칸 강조 4) ‘편집으로’ → 값이 채워진 SCR-25 |
| 예외 흐름 | E1 AI 실패·시간 초과 → 붙여넣은 원문은 보존하고 빈 편집 화면에서 직접 입력. E2 문구에 가격이 있어도 채우지 않고 ‘가격은 예약 기간별로 설정’ 안내 |
| 사후 조건 | 초안 상태의 상품이 생긴다(소비자에게 비공개) |
| 입력·검증 | 문구 필수, 최대 3,000자. 출력: 상품명·품종·중량 옵션·예상 당도·등급·배송 예정 기간·설명·빈 칸 목록. kg/KG/키로/킬로/키로그램/킬로그램은 같은 중량으로 비교하고, 원문에서 확인되지 않은 출력 필드는 개별적으로 비우고 빈 칸에 넣는다 |
| 규칙 | M-10\~M-12 |

- [ ] AC-03-1. **Given** 당도·배송 시기가 없는 문구다 / **When** 초안을 만든다 / **Then** 두 항목은 비어 있고 빈 칸으로 표시된다
- [ ] AC-03-2. **Given** “5kg 25,000원”이 들어 있는 문구다 / **When** 초안을 만든다 / **Then** 가격은 채워지지 않는다
- [ ] AC-03-3. **Given** AI 호출이 실패한다 / **When** 초안 만들기를 누른다 / **Then** 빈 편집 화면으로 가서 직접 입력할 수 있다

검증은 모델 지시만 믿지 않는다. 예상 당도는 원문의 당도/Brix 수치, 배송 예정 기간은 배송·수령 문맥, 품종·등급은 원문 문자열 근거가 있어야 한다. 상품명·설명은 원문에 없는 숫자·날짜를 추가하거나 가격·예약 기간·연락처·계좌를 포함할 수 없다. 근거 없는 필드 하나 때문에 근거 있는 다른 필드를 버리지는 않는다.

## 스펙 1.5
- [ ] AC-03-4: [농가·상품 상세 및 공개 소식방 계약](../storefront-1.5.md)의 화면·권한·검증을 따른다. 기존 농가 소식 탭 대신 소식방에서 공개 소식을 읽는다.

## 자료 분석 앱 통합 (DEV-56~58, DEV-90)

[자료 통합](../source-integration.md)·[판매페이지 직접 편집](../source-editor.md)의 AC-SRC-1~11을 적용한다. 승인 생산자는 새 상품에서 상품별 비공개 작업을 열고 텍스트·사진·PDF/TXT 자료와 상품사진을 별도로 넣어 분석한다. 기본 정보·출처 후보로 채운18개 모듈을 직접 수정하고 비공개 저장 후 명시적으로 상품에 반영한다. 이 동작은 구현/머지되었으며 DEV-90에서 운영 worker/OCR를 활성화했다. 실제 농가 인수·추출 정확도는 별도다. 기능이 꺼진 환경에서는 기존 문구/직접 입력 화면으로 진입한다. 가격·재고·판매 공개 상태는 분석이 확정하지 않는다.

### I2 생산자 오류 복구 (DEV-29/34/38)

초안 결과의 빈 문자열·공백뿐인 문자열·빈 옵션 배열도 확인 필요로 표시한다. 수동 상품 생성 중에는 초안 재시도와 중복 상품 생성을 막는다. 실패한 생성 요청은 입력을 유지하고 재시도할 수 있다.
