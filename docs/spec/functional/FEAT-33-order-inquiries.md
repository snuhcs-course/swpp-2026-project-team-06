# FEAT-33 주문 문제 문의·비공개 사진

스펙 1.2 · I1 Should · SCR-32 · 규칙: M-21, R-15. 승인 생산자/본인 소비자의 권한·입출력·오류는 [공통 계약](../contracts-1.2.md)을 따른다. 구현 완료 표시는 후속 PR에서 한다.

- [ ] AC-33-1. 본인 결제 주문에서 유형·설명·선택 사진으로 문의하면 해당 농가 대화에 주문 문맥과 함께 한 번만 접수된다.
- [ ] AC-33-2. 팔로우 해제 후에도 본인 결제 주문 문맥으로 문의할 수 있고 타인 주문/사진은 조회·연결할 수 없다.
- [ ] AC-33-3. 생산자 답변 필요에 표시하고 HUMAN으로 전환한다. 해결/재열기는 주문 상태·환불액을 바꾸지 않는다.
- [ ] AC-33-4. MIME·파일 용량·개수를 검증하고 비공개 저장·EXIF 제거·미연결 파일 정리를 적용한다.
