# FEAT-04 상품·중량 옵션 편집·게시 요청

> 상위: [PRD](/docs/spec/prd.md) 7.1 · 규칙: [rules.md](./rules.md) · 화면: [IA](/docs/spec/ia.md), [화면 명세](/docs/spec/screens.md) · 추적표: [README](./README.md)

| 항목 | 내용 |
| --- | --- |
| 우선순위·출처 | P0 · PRD 7.1, S-1 |
| 앱·화면 | 생산자 앱 SCR-25, SCR-23 |
| 목적 | 초안을 다듬어 farmclub 승인을 요청한다 |
| 사전 조건 | 초안 또는 판매 중인 상품이 있다 |
| 정상 흐름 | 1) 항목 입력 2) 저장 → 초안 3) 게시 요청 → 승인 대기 4) 운영자 승인 → 판매 중(소비자 앱 공개), 반려 → 사유 표시 후 다시 요청 |
| 예외 흐름 | E1 모든 옵션에 단계 가격이 없거나 배송 예정 기간이 없으면 게시 요청을 막고 빠진 항목 표시. E2 판매 중 가격·옵션·단계 변경 → 재승인 전까지 기존 값으로 판매. E3 판매 중 설명·사진·실측 당도·등급·배송비 변경 → 바로 반영. E4 배송 예정 기간 변경 → 주문자 동의·환불 흐름(R-21) |
| 사후 조건 | 상품 상태가 초안·승인 대기·판매 중·반려 중 하나가 된다. 이미 한 주문은 바뀌지 않는다(R-17) |
| 입력·검증 | 상품명·품종·원산지·보관 방법 필수(농산물 상품정보 표시). 중량 옵션 1개 이상. 상품 총 판매 한도는 게시 전에 0 이상 정수 필수, 판매량 미만 불가. 한 주문 최대 수량은 1 이상 정수. 배송 예정 기간은 시작 ≤ 끝. 배송비는 무료 또는 별도(금액 필수). 도서산간 지역·추가금 선택. 당도는 숫자(°Bx) |
| 규칙 | R-18, R-20, R-21, R-23, R-25, M-13 |

- [ ] AC-04-1. **Given** 배송 예정 기간이 비어 있다 / **When** 게시 요청을 하려 한다 / **Then** 버튼이 비활성이고 빠진 항목이 보인다
- [ ] AC-04-2. **Given** 승인 대기·반려 상품이다 / **When** 소비자 앱에서 찾는다 / **Then** 보이지 않는다
- [ ] AC-04-3. **Given** 승인 대기 상품이다 / **When** 운영자가 관리 API로 승인한다 / **Then** 판매 중으로 바뀌고 SCR-03에 나타난다
- [ ] AC-04-4. **Given** 판매 중 상품이다 / **When** 가격을 바꾸고 저장한다 / **Then** 재승인 전까지 소비자에게는 기존 가격이 보인다

## 스펙 1.2

[공통 계약](../contracts-1.2.md)을 적용한다.

- [ ] AC-04-5. 상품 총 판매 한도와 한 주문 상한을 따로 입력한다. 총 한도를 판매량 아래로 낮추면 오류이고 기존 값은 유지한다.
- [ ] AC-04-6. 판매 중지·재개를 확인 후 수행한다. 중지 중에도 상품은 보이고 기존 결제 주문은 유지된다.
