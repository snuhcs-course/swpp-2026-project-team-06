| 사후 조건 | 변화 없음(조회만) |

| 규칙 | R-05, R-06, R-16, R-20, M-15, M-24 |

- [ ] AC-07-1. **Given** 지금 단계의 남은 물량이 0이다 / **When** 상품 상세를 연다 / **Then** ‘품절’과 다음 단계 시작일이 보이고 예약하기가 눌리지 않는다
- [ ] AC-07-2. **Given** 측정 당도가 등록됐다 / **When** 상품 상세를 연다 / **Then** 측정 당도 한 값으로 보인다. 기존 데이터는 실측값을 우선하고 없으면 기존 예상값을 보존한다. 입력 변경·삭제 시 기존 두 API 필드를 동기화한다.

## 스펙 1.2

[공통 계약](../contracts-1.2.md)을 적용한다.

- [ ] AC-07-3. 현재 옵션 가격과 마지막 기간 비교 가격, 남은 박스를 보여주고 PAUSED/기간 공백/품절/종료를 구분하여 예약 버튼을 제한한다. 예약할 수 없는 상품(PAUSED·총 한도 소진 포함)은 홈 추천·농가 대표 상품에서 빠지고 상세·농가 판매 품목에는 남으며, 다음 기간 시작일은 기간 시작 전·이번 기간 품절일 때만 보인다(R-27, DEV-215).

- [ ] AC-07-7. 빈 값은 값 종류마다 한 문구로 보인다(M-24, DEV-227). **Given** 등록된 당도가 없다 / **Then** ‘당도 등록 전 · 궁금하면 1:1 채팅으로 농가에 물어보세요’, ‘-Brix’ 없음. **Given** 받는 시기가 확정 전이다(생산자 미리보기) / **Then** 마지막 예약 기간에서 유도한 ‘M월 ○순 이후 도착 예상’ + ‘받는 시기는 예약 전에 확정돼요.’, 예약 기간도 없으면 ‘받는 시기 확정 전’, 최대 지연 기한이 없으면 환불 기한 문장을 뺀다. **Given** 배송비가 별도인데 금액이 없다 / **Then** ‘배송비 확정 전’. **Given** 예약할 수 없다 / **Then** 가격 자리·상태 제목은 `availability` 이름(ia.md 4장)이고 ‘현재 예약 불가’는 쓰지 않는다.
- [ ] AC-07-8. (DEV-258) **Given** 원산지가 입력된 상품이다 / **When** 상품 상세(또는 생산자 구매자 화면 미리보기)를 연다 / **Then** 상품명 바로 아래 줄에 ‘원산지 ○○’가 상품명과 같은 글자 크기·색으로 보이고, 품절·판매 중지에도 같은 자리에 있다. 원산지가 비어 있으면 줄을 숨긴다. 근거: 원산지표시법 시행규칙 별표 3 2호가목1)(통신판매 화면은 상품명·가격 옆·위·아래에, 같거나 큰 글자·같은 색으로). 목록 카드는 대상에서 뺐다(후속 DEV-286).

## 자료 기반 판매페이지 통합 (DEV-56~58, DEV-90)

[자료 통합](../source-integration.md)·[판매페이지 직접 편집](../source-editor.md)의 AC-SRC-1~11을 적용한다. 생산자 편집/구매자 미리보기/공개 상세는 공용18개 모듈 렌더러를 사용한다. 내용 없는 항목과 숨긴 섹션은 공개에서 제외하며 사진 비율과 대표사진을 보존한다. 비공개 저장은 공개 상품을 바꾸지 않고 명시적 반영만 moduleDetail을 갱신한다. 실제 공개 여부는 기존 상품/농가 승인 계약을 유지한다. 기능은 구현/머지되었으며 운영 배포와 실제 농가 인수 상태는 통합 문서의 현재 상태를 따른다.
