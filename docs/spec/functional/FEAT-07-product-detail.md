# FEAT-07 상품 상세

> 상위: [PRD](/docs/spec/prd.md) 7.1 · 규칙: [rules.md](./rules.md) · 화면: [IA](/docs/spec/ia.md), [화면 명세](/docs/spec/screens.md) · 추적표: [README](./README.md)

| 항목 | 내용 |
| --- | --- |
| 우선순위·출처 | P0 · PRD 7.1, S-2 |
| 앱·화면 | 소비자 앱 SCR-04 |
| 목적 | 품질·받는 시기·지금 가격을 보고 살지 정한다 |
| 사전 조건 | 판매 중인 상품이다 |
| 정상 흐름 | 품질, 받는 시기, 옵션별 지금 가격·다음 단계 가격·남은 물량·단계 마감일, 배송비, 설명, 상품정보, 농가 요약(→ SCR-03, 당도 기록 n회), 예약한 사람 수(n명)를 보여주고 하단에 채팅하기(FEAT-12)와 예약하기를 둔다. 예약하기는 옵션·수량 시트를 연다. 최신 소식 칸은 없다(screens.md 결정 26). 지금 단계는 현재 시각이 기간 안에 든 단계다 |
| 예외 흐름 | E1 단계 사이 빈 기간·품절 → 예약하기를 막고 다음 단계 시작일 표시. E2 판매 중이 아닌 상품 → IA 예외 경로 |
| 사후 조건 | 변화 없음(조회만) |
| 입력·검증 | 당도는 실측값이 있으면 실측, 없으면 ‘예상’으로 표시 |
| 규칙 | R-05, R-06, R-16, R-20, M-15 |

- [ ] AC-07-1. **Given** 지금 단계의 남은 물량이 0이다 / **When** 상품 상세를 연다 / **Then** ‘품절’과 다음 단계 시작일이 보이고 예약하기가 눌리지 않는다
- [ ] AC-07-2. **Given** 실측 당도가 등록됐다 / **When** 상품 상세를 연다 / **Then** 예상값 대신 실측값이 보인다
