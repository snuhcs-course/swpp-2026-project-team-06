# FEAT-15 농가 소식 목록·반응

> 상위: [PRD](/docs/spec/prd.md) 7.1 · 규칙: [rules.md](./rules.md) · 화면: [IA](/docs/spec/ia.md), [화면 명세](/docs/spec/screens.md) · 추적표: [README](./README.md)

| 항목 | 내용 |
| --- | --- |
| 우선순위·출처 | P0 · PRD 7.1, S-3 |
| 앱·화면 | 소비자 앱 SCR-18 공개 소식방, SCR-18 소식(반응) |
| 목적 | 팔로우 전에도 농가가 공개한 재배 소식을 보고, 마음에 드는 소식에 좋아요로 반응한다 |
| 사전 조건 | 없음(좋아요는 로그인) |
| 정상 흐름 | 1) 농가의 공개 소식방: 공개 소식(글·사진·영상)을 최신순으로 보여준다 2) 소식마다 좋아요 수(숫자)와 내 좋아요 여부를 보여준다 3) 로그인한 사용자가 좋아요를 누르면 켜고, 다시 누르면 끈다(한 사람이 한 소식에 한 번) 4) 반응 종류는 ‘좋아요’ 하나 |
| 예외 흐름 | E1 소식이 없으면 빈 안내. E2 비로그인으로 좋아요 → FEAT-01 후 그 소식으로 돌아와 반영. E3 좋아요 실패 → 이전 상태로 되돌림 |
| 사후 조건 | 소식 조회는 변화 없음. 좋아요는 반응이 생기거나 지워지고 반응 수가 바뀐다 |
| 입력·검증 | 좋아요는 그 사용자가 볼 수 있는 소식에만 된다: 공개 소식, 또는 팔로우한 농가의 팔로워 전용 소식. 반응 수는 서버 값으로 갱신한다 |
| 규칙 | M-02, M-03, M-14 |

- [ ] AC-15-1. **Given** 비공개(팔로워 전용)로 올린 소식이 있다 / **When** 농가의 공개 소식방을 연다 / **Then** 그 소식은 보이지 않는다
- [ ] AC-15-2. **Given** 비로그인 상태다 / **When** 소식 탭을 연다 / **Then** 공개 소식이 보인다
- [ ] AC-15-3. **Given** 로그인한 소비자가 좋아요 수 3인 소식을 본다 / **When** 좋아요를 누르고 다시 누른다 / **Then** 처음에는 4와 내 좋아요 표시, 다시 누르면 3으로 돌아간다
- [ ] AC-15-4. **Given** 비로그인 상태로 공개 소식을 본다 / **When** 좋아요를 누르고 로그인한다 / **Then** 그 소식으로 돌아오고 좋아요가 반영돼 있다
- [ ] AC-15-5. **Given** 팔로우하지 않은 농가의 팔로워 전용 소식이다 / **When** 그 소식에 좋아요 API를 호출한다 / **Then** 거부되고 반응 수는 바뀌지 않는다

## 스펙 1.2

[공통 계약](../contracts-1.2.md)을 적용한다.

- [ ] AC-15-6. 방송의 좋아요는 소식방과 공개 소식 목록에서 공유한다. 소비자 비공개 답장에는 좋아요가 없다.

## 스펙 1.5
- [ ] AC-15-6: [농가·상품 상세 및 공개 소식방 계약](../storefront-1.5.md)의 화면·권한·검증을 따른다. 기존 농가 소식 탭 대신 소식방에서 공개 소식을 읽는다.
