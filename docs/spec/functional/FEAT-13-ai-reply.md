# FEAT-13 AI 응답·전달·생산자 답변

> 상위: [PRD](/docs/spec/prd.md) 7.1 · 규칙: [rules.md](./rules.md) · 화면: [IA](/docs/spec/ia.md), [화면 명세](/docs/spec/screens.md) · 추적표: [README](./README.md)

| 항목 | 내용 |
| --- | --- |
| 우선순위·출처 | P0 · PRD 7.1, S-3 |
| 앱·화면 | 소비자 앱 SCR-16 / 생산자 앱 SCR-28 |
| 목적 | 반복 질문은 AI가 답하고, 농가는 필요한 질문에만 답한다 |
| 사전 조건 | 소비자의 채팅 질문이 저장됨(FEAT-12) |
| 정상 흐름 | 1) 농가 AI ON·방 AUTO일 때만 자동 응답을 시도. 항상 전달할 주제(농약·재배 방식, 환불·보상, 항의)인지 판별 2) 아니면 농가·상품·단계·메시지·그 소비자의 주문에서 근거를 찾아 AI 안내로 답하고 근거 기록 3) 근거가 없거나 전달 주제면 ‘농가에 전달했어요’ 후 채팅의 답변 필요 목록에 넣음 4) 생산자가 채팅의 답변 필요 목록에서 질문을 눌러 소비자별 채팅에서 답하면 그 소비자 채팅에만 표시하고 답한 질문으로 옮김 5) (I2) 소비자가 AI 안내의 ‘틀렸어요’를 누르면 그 질문을 채팅의 답변 필요 목록에 넣음 |
| 예외 흐름 | E1 AI 실패·지연 → 전달로 처리. E2 환불 요구 → 운영자에게도 남김(I1은 로그) |
| 사후 조건 | AI 안내 메시지 또는 답할 질문이 생긴다 |
| 입력·검증 | 당도 질문은 실측값 우선, 없으면 ‘예상’임을 밝힘, 둘 다 없으면 전달 |
| 규칙 | M-05\~M-09, M-15, M-18, N-04. M-17은 I2 |

- [ ] AC-13-1. **Given** 농가 AI ON·방 AUTO이며 상품에 배송 예정 기간이 있다 / **When** “배송은 언제예요?”라고 채팅으로 묻는다 / **Then** AI 안내가 그 기간으로 답한다
- [ ] AC-13-2. **Given** 상품 설명에 재배 방식이 적혀 있더라도 / **When** “농약은 얼마나 치세요?”라고 채팅으로 묻는다 / **Then** AI는 답하지 않고 채팅의 답변 필요 목록에 들어간다
- [ ] AC-13-3. **Given** 농가 AI ON·방 AUTO이며 예상 당도만 등록됐다 / **When** “등록된 당도 수치는 얼마예요?”라고 채팅으로 묻는다 / **Then** AI가 예상값임을 밝히고 답한다
- [ ] AC-13-4. **Given** AI가 보낸 답이다 / **When** 채팅을 연다 / **Then** ‘AI 안내’ 표시가 붙어 있다

* [ ] AC-13-5. (I2, M-17) **Given** AI가 “1월 중순 배송”이라고 답했다 / **When** 소비자가 ‘틀렸어요’를 누른다 / **Then** 그 질문이 농가 채팅의 답변 필요 목록(SCR-28)에 나타나고 틀린 답으로 표시된다

- [ ] AC-13-6. 생산자 답변 성공은 HUMAN으로 전환하고 진행 중 AI도 저장 직전 모드를 검사한다. AUTO 재개는 이후 메시지부터다.
- [ ] AC-13-7. 농가 AI OFF이면 AUTO 방에도 AI 답이 없고 답변 필요로 남는다.
- [ ] AC-13-8. 주관적 맛·품질·파손 판단은 등록 수치가 있어도 생산자에게 전달한다.

설정 우선순위·근거·전달 상태는 [1.2 계약](../contracts-1.2.md), 설정 화면은 [FEAT-32](./FEAT-32-ai-settings.md)를 따른다.
