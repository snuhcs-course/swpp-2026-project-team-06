# FEAT-13 AI 응답·전달·생산자 답변

> 상위: [PRD](/docs/spec/prd.md) 7.1 · 규칙: [rules.md](./rules.md) · 화면: [IA](/docs/spec/ia.md), [화면 명세](/docs/spec/screens.md) · 추적표: [README](./README.md)

| 항목 | 내용 |
| --- | --- |
| 우선순위·출처 | P0 · PRD 7.1, S-3 |
| 앱·화면 | 소비자 앱 SCR-16 / 생산자 앱 SCR-28 |
| 목적 | 반복 질문은 AI가 답하고, 농가는 필요한 질문에만 답한다 |
| 사전 조건 | 소비자의 채팅 질문이 저장됨(FEAT-12) |
| 정상 흐름 | 1) 항상 전달할 주제(농약·재배 방식, 환불·보상, 항의)인지 판별 2) 아니면 농가·상품·단계·메시지·그 소비자의 주문에서 근거를 찾아 AI 안내로 답하고 근거 기록 3) 근거가 없거나 전달 주제면 ‘농가에 전달했어요’ 후 질문함에 넣음 4) 생산자가 답하면 그 소비자 채팅에만 표시하고 답한 질문으로 옮김 5) (I2) 소비자가 AI 안내의 ‘틀렸어요’를 누르면 그 질문을 질문함에 넣음 |
| 예외 흐름 | E1 AI 실패·지연 → 전달로 처리. E2 환불 요구 → 운영자에게도 남김(I1은 로그) |
| 사후 조건 | AI 안내 메시지 또는 답할 질문이 생긴다 |
| 입력·검증 | 당도 질문은 실측값 우선, 없으면 ‘예상’임을 밝힘, 둘 다 없으면 전달 |
| 규칙 | M-05\~M-09, M-15, M-18, N-04. M-17은 I2 |

- [ ] AC-13-1. **Given** 상품에 배송 예정 기간이 있다 / **When** “배송은 언제예요?”라고 채팅으로 묻는다 / **Then** AI 안내가 그 기간으로 답한다
- [ ] AC-13-2. **Given** 상품 설명에 재배 방식이 적혀 있더라도 / **When** “농약은 얼마나 치세요?”라고 채팅으로 묻는다 / **Then** AI는 답하지 않고 질문함에 들어간다
- [ ] AC-13-3. **Given** 예상 당도만 등록됐다 / **When** “얼마나 달아요?”라고 채팅으로 묻는다 / **Then** AI가 예상값임을 밝히고 답한다
- [ ] AC-13-4. **Given** AI가 보낸 답이다 / **When** 채팅을 연다 / **Then** ‘AI 안내’ 표시가 붙어 있다

* [ ] AC-13-5. (I2, M-17) **Given** AI가 “1월 중순 배송”이라고 답했다 / **When** 소비자가 ‘틀렸어요’를 누른다 / **Then** 그 질문이 농가 질문함(SCR-28)에 나타나고 틀린 답으로 표시된다
