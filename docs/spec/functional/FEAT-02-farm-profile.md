# FEAT-02 농가 프로필

> 상위: [PRD](/docs/spec/prd.md) 7.1 · 규칙: [rules.md](./rules.md) · 화면: [IA](/docs/spec/ia.md), [화면 명세](/docs/spec/screens.md) · 추적표: [README](./README.md)

| 항목 | 내용 |
| --- | --- |
| 우선순위·출처 | P0 · PRD 7.1, S-1 |
| 앱·화면 | 생산자 앱 SCR-30(편집) / 소비자 앱 SCR-03(표시) |
| 목적 | 소비자가 어떤 농가인지 알게 한다 |
| 사전 조건 | 승인된 생산자다 |
| 정상 흐름 | 1) 프로필 항목 줄(농가 이름·지역·소개)에서 하나를 골라 고치거나 대표 사진을 바꿈 2) 저장 3) 소비자 앱에 바로 반영 |
| 예외 흐름 | E1 필수값이 비면 저장하지 않고 빈 칸을 표시 |
| 사후 조건 | 농가 정보가 갱신된다 |
| 입력·검증 | 농가명·지역 필수, 소개·대표 사진 선택 |
| 규칙 | — |

- [ ] AC-02-1. **Given** 승인된 생산자다 / **When** 농가명을 바꾸고 저장한다 / **Then** SCR-02·SCR-03에 바뀜 이름이 보인다
- [ ] AC-02-2. **Given** 농가명을 비웠다 / **When** 저장을 누른다 / **Then** 저장되지 않고 빈 칸이 표시된다

## 스펙 1.3

- [ ] AC-02-3. 생산자 네 번째 환경설정(SCR-33)에서 프로필·공유·AI 설정·로그아웃으로 간다. 프로필 수정은 소비자 농가·채팅 아바타에 반영된다.

## 스펙 1.5
- [ ] AC-02-4: [농가·상품 상세 및 공개 소식방 계약](../storefront-1.5.md)의 화면·권한·검증을 따른다. 기존 농가 소식 탭 대신 소식방에서 공개 소식을 읽는다.
