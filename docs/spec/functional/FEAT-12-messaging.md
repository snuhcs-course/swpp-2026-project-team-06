# FEAT-12 1:N 메시지·답장

> 상위: [PRD](/docs/spec/prd.md) 7.1 · 규칙: [rules.md](./rules.md) · 화면: [IA](/docs/spec/ia.md) · 추적표: [README](./README.md)

| 항목 | 내용 |
| --- | --- |
| 우선순위·출처 | P0 · PRD 7.1, S-3 |
| 앱·화면 | 생산자 앱 SCR-27 / 소비자 앱 SCR-15, SCR-16 |
| 목적 | 농가는 팔로워 전체에 소식을 보내고, 소비자는 농가에게만 답한다 |
| 사전 조건 | 생산자는 승인됨. 소비자는 로그인하고 그 농가를 팔로우함 |
| 정상 흐름 | 1) 생산자가 본문·사진·영상과 공개 여부 입력 2) 전화번호·계좌번호·외부 메신저 ID 가림 3) 팔로워 전원 메시지함에 들어감 4) 공개면 SCR-03 소식 탭에도 남음 5) 소비자가 글·사진으로 답장 → 그 소비자와 농가의 대화에만 저장 → FEAT-13 |
| 예외 흐름 | E1 팔로워 0명이어도 보낼 수 있고 공개면 소식에 남는다. E2 팔로우하지 않은 농가에는 답장할 수 없다 |
| 사후 조건 | 메시지·답장이 저장된다(가린 상태로) |
| 입력·검증 | 본문과 첨부 중 하나는 필수. 첨부 개수·용량은 FQ-05. 소비자 답장은 글·사진만(영상 안 됨) |
| 규칙 | M-01\~M-04, M-14, M-16 |

- [ ] AC-12-1. **Given** 소비자 A가 농가에 답장했다 / **When** 소비자 B가 같은 농가 대화를 열거나 API를 호출한다 / **Then** A의 답장은 어디에도 나오지 않는다
- [ ] AC-12-2. **Given** 본문에 “010-1234-5678로 연락주세요”가 있다 / **When** 보낸다 / **Then** 번호가 가려진 채 저장·표시된다
- [ ] AC-12-3. **Given** 공개를 고른 메시지다 / **When** 보낸다 / **Then** 팔로워 메시지함과 농가 페이지 소식 탭에 모두 보인다
