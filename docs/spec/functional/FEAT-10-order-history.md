# FEAT-10 주문 내역·상세

> 상위: [PRD](/docs/spec/prd.md) 7.1 · 규칙: [rules.md](./rules.md) · 화면: [IA](/docs/spec/ia.md) · 추적표: [README](./README.md)

| 항목 | 내용 |
| --- | --- |
| 우선순위·출처 | P0 · PRD 7.1, S-2·S-4 |
| 앱·화면 | 소비자 앱 SCR-13, SCR-14 |
| 목적 | 내 주문의 진행과 받는 시기를 보고 필요한 행동을 한다 |
| 사전 조건 | 로그인했다 |
| 정상 흐름 | 1) 목록: 할 일이 있는 주문 먼저, 그다음 최신순 2) 상세: 상태(예약 완료·출하 준비·출하·배송 완료·구매 확정·환불), 배송 예정 기간, 금액, 받는 사람 3) 배송 기간이 바뀌면 ‘새 기간 동의’ 또는 ‘전액 환불’ 선택 4) 배송 완료 후 ‘구매 확정’, 없으면 8일 뒤 자동 확정 |
| 예외 흐름 | E1 남의 주문 주소로 접근 → 내 주문 내역. E2 농가 정지로 환불 → 사유 표시 |
| 사후 조건 | 동의·환불·구매 확정을 고르면 그 상태와 시각이 기록된다 |
| 입력·검증 | 없음 |
| 규칙 | R-05, R-13, R-14, R-21, R-24 |

- [ ] AC-10-1. **Given** 배송 기간이 바뀐 주문이 있다 / **When** 주문 내역을 연다 / **Then** 그 주문이 맨 위에 표시되고 동의하거나 환불받기 전까지 남는다
- [ ] AC-10-2. **Given** 배송 완료 후 8일이 지났다 / **When** 소비자가 구매 확정을 누르지 않았다 / **Then** 자동으로 구매 확정된다
- [ ] AC-10-3. **Given** 농가 정지로 환불된 주문이다 / **When** 주문 상세를 연다 / **Then** 환불 사유가 보인다
