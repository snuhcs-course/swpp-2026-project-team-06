# FEAT-34 farmclub 문의 대화방

스펙 I2 · DEV-111(생산자)·DEV-150(소비자) · SCR-28(생산자 1:1 채팅)·SCR-15·16(소비자 채팅) · 관리자 페이지 문의함 · 규칙: M-22. 생산자와 소비자가 앱 안에서 farmclub 운영팀에 묻고 답을 받는 창구다. 농가와의 채팅(FEAT-12)과 별개이고 AI가 답하지 않는다.

- [ ] AC-34-1. 운영자가 농가 가입을 승인하면 그 농가에 farmclub 대화방이 한 번만 생기고 운영팀 환영 메시지가 들어간다. 반려는 대화방을 만들지 않는다. 이미 승인된 농가는 배포 때 같은 대화방을 받는다.
- [ ] AC-34-2. 생산자 채팅 → 1:1 채팅 목록에 'farmclub'이 로고와 함께 보이고(고정하지 않고 다른 대화처럼 최근 순), 읽지 않은 운영팀 메시지 수가 표시된다. 대화방에는 AI 응대 바·주문 패널이 없고 AI 모드를 바꿀 수 없다.
- [ ] AC-34-3. 생산자가 보낸 문의는 관리자 페이지 문의함에 '답변 대기'로 보인다. 운영자가 대화를 열면 읽음으로 표시되고, 운영자 답장은 생산자 대화방에 'farmclub'으로 보인다. 같은 멱등 키로 다시 보내도 답장은 하나다.
- [ ] AC-34-4. 생산자의 대화방은 소비자 앱 어디에도 보이지 않고, 관리자 사용자 목록에도 운영팀 계정이 나오지 않는다. 문의함 API는 운영자만 부른다.
- [ ] AC-34-5. 생산자 도움말 투어(DEV-109)는 farmclub 대화방을 열어 문의 방법을 안내하고, 마지막 단계에서 모르는 것은 이 대화방으로 물어보라고 안내한다.
- [ ] AC-34-6. 소비자가 가입하면 farmclub 대화방이 한 번만 생기고 운영팀 환영 메시지가 들어간다(DEV-150). 생산자 계정 가입은 소비자 대화방을 만들지 않는다. 이미 가입한 소비자(탈퇴 제외)는 배포 때 같은 대화방을 받는다.
- [ ] AC-34-7. 소비자 채팅 → 1:1 채팅 목록에 'farmclub'이 로고와 함께 보이고(고정하지 않고 최근 순), 읽지 않은 운영팀 메시지 수가 표시된다. 소비자는 가입 온보딩(지금 버전 동의 포함)을 마쳐야 문의를 보낼 수 있다. 보낸 문의는 연락처가 가려진 채 관리자 문의함에 '소비자'·'답변 대기'로 보이고(문의한 적 있는 방만 문의함에 나온다), 운영자 답장은 소비자 대화방에 'farmclub'으로 보인다. AI는 답하지 않고, 사진 첨부는 받지 않는다.
- [ ] AC-34-8. 소비자의 대화방은 그 소비자와 운영팀만 본다. 다른 소비자·생산자는 읽거나 읽음 표시를 할 수 없고, 탈퇴하면 그 소비자가 쓴 문의 본문은 지운다.

## 정해 둔 것
- 소비자 대화방은 농가와의 1:1(Thread)과 따로 `support_threads`·`support_messages`에 둔다(사용자당 한 방). 소비자 1:1은 농가가 필수이고 팔로우·AI·전달 흐름에 묶여 있기 때문이다. 문의함은 생산자 방과 소비자 방을 함께 보인다. 생산자 방을 같은 테이블로 옮기는 정리는 후속이다.
- 대화방은 기존 1:1 대화(Thread)를 쓴다. 상대는 운영팀 계정 `u-farmclub`(이름 'farmclub', 로그인 수단 없음)이고 운영팀 메시지의 보낸 사람 종류는 `OPERATOR`다.
- 생산자 메시지에는 다른 1:1과 같이 연락처·계좌 가림(M-16)이 그대로 적용된다. 정산 계좌는 앱의 입금 계좌 화면에서 바꾼다.
- 문의함에는 정지·숨김 농가의 대화방도 보인다(이전 문의 기록을 보려고).
- 운영자 여러 명 배정, 처리 상태, 운영자의 사진 보기, 알림은 이번 범위가 아니다. 사진이 붙은 문의는 문의함에 '사진 N장'으로만 보인다.
