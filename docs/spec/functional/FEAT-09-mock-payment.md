# FEAT-09 카드 결제(Mock)

> 상위: [PRD](/docs/spec/prd.md) 7.1 · 규칙: [rules.md](./rules.md) · 화면: [IA](/docs/spec/ia.md), [화면 명세](/docs/spec/screens.md) · 추적표: [README](./README.md)

| 항목 | 내용 |
| --- | --- |
| 우선순위·출처 | P0 · PRD 7.1, S-2 |
| 앱·화면 | 소비자 앱 SCR-11 → SCR-12 |
| 목적 | 주문 금액을 카드로 한 번에 낸다(I1은 Mock) |
| 사전 조건 | 결제 전 주문이 있다 |
| 정상 흐름 | 1) 결제 금액 확인 2) 데모에서 성공 선택 → 물량 차감, 결제일 기록, 예약 완료 3) 완료 화면 |
| 예외 흐름 | E1 실패 선택 → 주문서로 돌아감, 물량 그대로. E2 결제 순간 물량 0 → 실패 처리와 품절 안내. E3 응답을 못 받아 다시 보냄 → 같은 멱등 키면 처음 결과를 돌려주고 결제·차감은 한 번만 |
| 사후 조건 | 주문은 예약 완료, 결제일 기록, 단계 물량 차감 |
| 입력·검증 | 결제 요청에 멱등 키(`Idempotency-Key`) 필수(화면 명세 7.1) |
| 규칙 | R-01, R-02, R-06, R-13, R-17 |

- [ ] AC-09-1. **Given** 남은 물량이 1이다 / **When** 두 사람이 동시에 결제한다 / **Then** 한 명만 성공하고 다른 한 명은 품절 안내를 받는다
- [ ] AC-09-2. **Given** 결제 전 주문이다 / **When** 실패를 고른다 / **Then** 남은 물량이 줄지 않고 주문서로 돌아간다
- [ ] AC-09-3. **Given** 결제 요청을 보냈다 / **When** 같은 멱등 키로 다시 보낸다 / **Then** 결제와 단계 물량 차감은 한 번만 일어나고 같은 결과를 받는다
