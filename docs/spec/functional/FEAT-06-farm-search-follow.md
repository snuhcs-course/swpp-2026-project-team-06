# FEAT-06 농가 탐색(검색)·팔로우

> 상위: [PRD](/docs/spec/prd.md) 7.1 · 규칙: [rules.md](./rules.md) · 화면: [IA](/docs/spec/ia.md) · 추적표: [README](./README.md)

| 항목 | 내용 |
| --- | --- |
| 우선순위·출처 | P0 · PRD 7.1, S-2 |
| 앱·화면 | 소비자 앱 SCR-02, SCR-03, SCR-17 |
| 목적 | 마감이 가까운 농가부터 보고, 찾아서 팔로우한다 |
| 사전 조건 | 없음(팔로우는 로그인) |
| 정상 흐름 | 1) 목록을 예약 마감 임박순으로 표시 2) 검색어 입력 → 농가명·품종·지역 부분 일치 3) 팔로우를 누를 때마다 켜고 끔 |
| 예외 흐름 | E1 검색 결과 없음 → 안내와 전체 목록 돌아가기. E2 비로그인 팔로우 → FEAT-01 |
| 사후 조건 | 팔로우가 생기거나 지워지고, 팔로우한 농가가 메시지함·내 정보에 나타난다 |
| 입력·검증 | 검색어 앞뒤 공백 제거, 빈 검색어면 전체 목록. 정렬: 판매 중 상품의 현재 단계가 가장 일찍 끝나는 농가가 위, 판매 중 상품 없는 농가는 맨 아래. 필터는 I2 |
| 규칙 | — |

- [ ] AC-06-1. **Given** 단계 마감이 내일인 농가 A와 다음 주인 농가 B가 있다 / **When** 농가 목록을 연다 / **Then** A가 B보다 위에 보인다
- [ ] AC-06-2. **Given** 품종에 한라봉이 있는 농가가 있다 / **When** “한라봉”으로 검색한다 / **Then** 그 농가만 나온다
- [ ] AC-06-3. **Given** 로그인한 소비자다 / **When** 농가를 팔로우한다 / **Then** 그 농가가 내 정보와 메시지함에 나타난다
