# FEAT-06 농가 탐색(홈·검색)·팔로우

> 상위: [PRD](/docs/spec/prd.md) 7.1 · 규칙: [rules.md](./rules.md) · 화면: [IA](/docs/spec/ia.md), [화면 명세](/docs/spec/screens.md) · 추적표: [README](./README.md)

| 항목 | 내용 |
| --- | --- |
| 우선순위·출처 | P0 · PRD 7.1, S-2 |
| 앱·화면 | 소비자 앱 SCR-01(홈·발견), SCR-02, SCR-03, SCR-17 |
| 목적 | 첫 화면에서 마감이 가까운 상품과 농가부터 보고, 찾아서 팔로우한다 |
| 사전 조건 | 없음(팔로우는 로그인) |
| 정상 흐름 | 1) 홈(SCR-01): 사진·본문 소식 가로 목록 → 상품 가로 목록(예약 마감 임박순 상위 N개, n명 예약), 헤더 검색 아이콘 → 농가 목록 2) 농가 목록: 예약 마감 임박순 3) 검색어 입력 → 농가명·품종·지역 부분 일치 4) 팔로우를 누르면 ‘✓ 팔로잉’, 다시 누르면 확인 없이 끊고 버튼이 ‘팔로우’로 바뀌며 토스트 ‘팔로우를 끊었어요 · 되돌리기’(4초)를 보인다. 되돌리기는 다시 팔로우한다(소식방·주문 완료 화면 같음, DEV-230) |
| 예외 흐름 | E1 검색 결과 없음 → 안내와 전체 목록 돌아가기. E2 비로그인 팔로우 → FEAT-01. E3 판매 중 상품이 없음 → 홈에 ‘현재 예약 가능한 상품이 없어요’와 소식 목록 유지. E4 목록이 있는 채 검색 요청 실패 → 실패 안내와 다시 시도. 이전 목록을 검색 결과처럼 보이지 않고, 다시 시도해도 같은 농가가 두 번 나오지 않는다(SCR-02) |
| 사후 조건 | 팔로우가 생기거나 지워지고, 팔로우한 농가가 내 정보의 팔로우 목록에, 그 농가의 소식이 채팅 안 소식방(SCR-18)에 나타난다. 해제하면 새 소식이 오지 않고 채팅 안 소식방 목록에서 빠진다. 농가 페이지의 소식방은 비우지 않는다: 공개 소식과 본인 답장(흐리게)만 남고 팔로워 전용 소식은 숨기며, 위에 ‘팔로우를 끊어 새 소식이 오지 않아요 · 다시 팔로우’ 띠, 입력칸은 ‘다시 팔로우하면 답장할 수 있어요’로 잠근다(본인 답장이 없으면 처음 온 사람과 같은 화면). 다시 팔로우하면 이전 채팅이 그대로 보이고 목록에도 다시 나타난다(DEV-230) |
| 입력·검증 | 검색어 앞뒤 공백 제거, 빈 검색어면 전체 목록. 정렬: 판매 중 상품의 현재 단계가 가장 일찍 끝나는 농가(상품)가 위, 판매 중 상품 없는 농가는 맨 아래. 홈 추천 상품은 같은 정렬의 상위 N개(N은 서버 설정 값). 농가 프로필만 나열하는 홈 영역은 없다. 농가 링크는 소식방을 직접 연다. 필터는 I2 |
| 규칙 | — |

- [ ] AC-06-1. **Given** 단계 마감이 내일인 농가 A와 다음 주인 농가 B가 있다 / **When** 농가 목록을 연다 / **Then** A가 B보다 위에 보인다
- [ ] AC-06-2. **Given** 품종에 한라봉이 있는 농가가 있다 / **When** “한라봉”으로 검색한다 / **Then** 그 농가만 나온다
- [ ] AC-06-3. **Given** 로그인한 소비자다 / **When** 농가를 팔로우한다 / **Then** 그 농가가 내 정보의 팔로우 목록에 나타나고, 그 농가의 소식이 채팅 안 소식방에 보인다
- [ ] AC-06-4. **Given** 단계 마감이 내일인 상품 A와 다음 주인 상품 B가 판매 중이다 / **When** 홈을 연다 / **Then** 추천 상품에서 A가 B보다 앞에 보인다
- [ ] AC-06-5. **Given** 판매 중인 상품이 하나도 없다 / **When** 홈을 연다 / **Then** ‘현재 예약 가능한 상품이 없어요’가 보이고 소식 목록은 그대로 보인다
- [ ] AC-06-8. **Given** 강씨네 귤밭을 팔로우하고 소식방에 답장한 소비자다 / **When** 소식방에서 ‘✓ 팔로잉’을 눌러 끊었다가 ‘되돌리기’(또는 띠의 ‘다시 팔로우’)를 누른다 / **Then** 끊은 직후 ‘팔로우를 끊었어요 · 되돌리기’ 토스트, 흐린 내 답장, 띠, 잠긴 입력이 보이고 팔로워 전용 소식은 숨으며 채팅 소식방 목록에서 그 농가가 빠진다. 다시 팔로우하면 팔로워 전용 소식·진한 내 답장·열린 입력·목록 줄이 모두 해제 전과 같다(DEV-230)
- [ ] AC-06-7. **Given** 농가 목록에 농가 4곳이 보인다 / **When** “한라네”로 검색한 요청이 실패한 뒤 ‘다시 시도’를 누르고 성공한다 / **Then** 실패했을 때는 검색칸 아래 실패 안내와 ‘이전 목록 · 농가 4곳’이 보이고, 다시 시도한 뒤에는 한라네 농가만 한 번 나온다(같은 농가가 두 번 나오지 않는다)
