# FEAT-14 생산자 현황

> 상위: [PRD](/docs/spec/prd.md) 7.1 · 규칙: [rules.md](./rules.md) · 화면: [IA](/docs/spec/ia.md), [화면 명세](/docs/spec/screens.md) · 추적표: [README](./README.md)

| 항목 | 내용 |
| --- | --- |
| 우선순위·출처 | P0 · PRD 7.1, S-4 |
| 앱·화면 | 생산자 앱 SCR-22 |
| 목적 | 주문과 배송 현황을 한눈에 본다 |
| 사전 조건 | 승인된 생산자다 |
| 정상 흐름 | 제목 아래 할 일 목록(ListRow: 입금 확인할 주문 n건 → 입금 대기 탭 / 환불 보낼 주문 n건 → 환불 탭 / 입금 계좌 등록, DEV-68 / 수확을 시작할 예약 n건 → 예약 기간이 가장 먼저 끝난 기간 카드, DEV-231), 전체 주문(입금 대기 포함)·예약 완료(설명 ‘수확을 시작하면 출하 준비로’)·출하 준비·출하 큰 지표, 주문/배송 관리 진입, 대표 상품 예약·출하 kg. 채팅·소식 작성·답변 관련 내용은 채팅 탭에만 둔다 |
| 예외 흐름 | E1 판매 중 상품이 없으면 빈 상태 안내 |
| 사후 조건 | 변화 없음(조회만). 단 원산지 표시제도 안내의 ‘확인했어요’는 읽은 시각을 남긴다(DEV-121) |
| 입력·검증 | 배송 정보는 배송 완료 전 주문만 보인다 |
| 규칙 | R-15 |

- [ ] AC-14-1. **Given** 현황 화면을 보고 있다 / **When** 새 주문이 입금 안내를 받고 생산자가 입금을 확인한다 / **Then** 다시 열면 입금 대기 할 일·전체/예약 주문 지표와 대표 상품 예약 kg가 갱신된다
- [ ] AC-14-2. **Given** 배송 완료된 주문이다 / **When** 현황에서 그 주문을 본다 / **Then** 주소·연락처가 가려져 있다

- [ ] AC-14-3. 대표 상품의 예약 중/출하 완료 kg를 상품명과 함께 표시하고 전체 주문 건수와 구분한다. 승인/한도/추가 물량은 상품 관리에서 유지한다. 현황에는 채팅 관련 정보가 없다.
- [ ] AC-14-5. (DEV-231) **Given** 예약 기간이 어제 끝난 기간에 예약 완료 3건, 오늘까지 열린 기간에 1건이 있다 / **When** 현황을 연다 / **Then** 할 일 ‘수확을 시작할 예약 3건’(끝난 기간만, 한국 날짜 기준)이 보이고 누르면 그 상품의 예약 기간 화면, 그 기간 카드로 간다. 그 기간의 수확을 시작하면 이 줄이 사라진다
- [ ] AC-14-6. (DEV-121, 원산지표시법 제6조 ⑥·시행규칙 제4조의2 1호) **Given** 지금 버전의 원산지 표시제도 안내를 읽지 않은 생산자다 / **When** 현황을 연다 / **Then** 할 일 맨 위에 ‘원산지 표시제도 안내를 읽어 주세요’가 보이고, 누르면 안내 화면(`/origin-notice`)에서 표시 대상·방법, 거짓 표시 금지, 위반 시 제재를 본다. ‘확인했어요’를 누르면 서버에 읽은 시각·버전이 남고, 그 뒤로 현황 맨 아래에 ‘원산지 표시제도 안내 · ○월 ○일 확인함’ 줄이 늘 남는다(새로고침해도)
