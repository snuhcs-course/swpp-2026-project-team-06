# FEAT-14 생산자 현황

> 상위: [PRD](/docs/spec/prd.md) 7.1 · 규칙: [rules.md](./rules.md) · 화면: [IA](/docs/spec/ia.md), [화면 명세](/docs/spec/screens.md) · 추적표: [README](./README.md)

| 항목 | 내용 |
| --- | --- |
| 우선순위·출처 | P0 · PRD 7.1, S-4 |
| 앱·화면 | 생산자 앱 SCR-22 |
| 목적 | 할 일과 단계별 예약 수량을 한눈에 본다 |
| 사전 조건 | 승인된 생산자다 |
| 정상 흐름 | 할 일(답할 질문 수·출할 주문 수·승인 대기 상품, 누르면 각 화면), 상품의 예약한 사람 수·주문 수, 단계별·옵션별 예약 수량(박스)과 남은 물량, 최근 예약(이름 앞 글자), 떠 있는 ‘+ 소식’. 출하 처리는 할 일 ‘출하할 주문’으로 들어간다 |
| 예외 흐름 | E1 판매 중 상품이 없으면 ‘새 상품’ 안내 |
| 사후 조건 | 변화 없음(조회만) |
| 입력·검증 | 배송 정보는 배송 완료 전 주문만 보인다 |
| 규칙 | R-15 |

- [ ] AC-14-1. **Given** 현황 화면을 보고 있다 / **When** 새 주문이 결제된다 / **Then** 다시 열면 해당 단계의 예약 수량이 늘고 남은 물량이 줄어 있다
- [ ] AC-14-2. **Given** 배송 완료된 주문이다 / **When** 현황에서 그 주문을 본다 / **Then** 주소·연락처가 가려져 있다
