# FEAT-11 출하 전 취소

> 상위: [PRD](/docs/spec/prd.md) 7.1 · 규칙: [rules.md](./rules.md) · 화면: [IA](/docs/spec/ia.md) · 추적표: [README](./README.md)

| 항목 | 내용 |
| --- | --- |
| 우선순위·출처 | P0 · PRD 7.1, S-4 |
| 앱·화면 | 소비자 앱 SCR-14 |
| 목적 | 출하 전에는 언제든 취소하고 전액 돌려받는다 |
| 사전 조건 | 주문이 예약 완료 또는 출하 준비다 |
| 정상 흐름 | 1) 취소 2) 확인 3) Mock 환불, 상태 환불, 단계 물량 복구, 사유 기록 |
| 예외 흐름 | E1 출하 후에는 취소 버튼이 없다(하자 환불은 운영자, R-11) |
| 사후 조건 | 주문은 환불, 그 단계 물량이 되돌아온다 |
| 입력·검증 | 없음(위약금·수수료 없음) |
| 규칙 | R-07, R-08 |

- [ ] AC-11-1. **Given** 예약 완료 주문이다 / **When** 취소한다 / **Then** 전액 환불되고 그 단계의 남은 물량이 늘어난다
- [ ] AC-11-2. **Given** 출하된 주문이다 / **When** 주문 상세를 연다 / **Then** 취소 버튼이 없다
