# FEAT-01 회원가입·로그인

> 상위: [PRD](/docs/spec/prd.md) 7.1 · 규칙: [rules.md](./rules.md) · 화면: [IA](/docs/spec/ia.md) · 추적표: [README](./README.md)

| 항목 | 내용 |
| --- | --- |
| 우선순위·출처 | P0 · PRD 7.1, S-1·S-2 |
| 앱·화면 | 소비자 앱 SCR-05 / 생산자 앱 SCR-05·20·21 |
| 목적 | 가입 없이 둘러보고, 필요한 순간에만 카카오로 로그인한다 |
| 사전 조건 | 카카오 계정이 있다 |
| 정상 흐름 | 1) 팔로우·예약하기·답장을 누르면 SCR-05로 이동 2) 카카오 인증. 처음이면 계정 생성과 약관·개인정보 동의 3) 누른 화면·행동으로 복귀, 입력값 유지 4) 생산자 앱은 상태에 따라 신청 전 → SCR-20, 신청·반려 → SCR-21, 승인 → SCR-22 |
| 예외 흐름 | E1 카카오 인증 취소 → 원래 화면, 행동 실행 안 함. E2 반려 → SCR-21에 사유와 다시 신청. E3 정지 → 정지 안내만 표시 |
| 사후 조건 | 로그인 상태가 된다. 생산자 신청 시 농가가 승인 대기로 생긴다 |
| 입력·검증 | 카카오에서는 이름만 받는다. 생산자 신청: 농가명·지역·주 품목·연락처 필수, 연락처는 휴대폰 번호 형식 |
| 규칙 | R-22, N-05, N-06 |

- [ ] AC-01-1. **Given** 비로그인으로 상품 상세에 있다 / **When** 예약하기를 누르고 카카오 로그인을 마친다 / **Then** 주문서(SCR-10)가 열린다
- [ ] AC-01-2. **Given** 소비자 앱에 로그인한 카카오 계정이 있다 / **When** 같은 계정으로 생산자 앱에 로그인한다 / **Then** 새 계정 없이 같은 사용자로 로그인된다
- [ ] AC-01-3. **Given** 승인 전 생산자다 / **When** SCR-22\~30 주소나 생산자 API를 호출한다 / **Then** SCR-21로 이동하고 API는 거부한다
