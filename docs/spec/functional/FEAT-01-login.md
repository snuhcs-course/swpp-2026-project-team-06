# FEAT-01 회원가입·로그인

> 상위: [PRD](/docs/spec/prd.md) 7.1 · 규칙: [rules.md](./rules.md) · 화면: [IA](/docs/spec/ia.md), [화면 명세](/docs/spec/screens.md) · 추적표: [README](./README.md)

| 항목 | 내용 |
| --- | --- |
| 우선순위·출처 | P0 · PRD 7.1, S-1·S-2 |
| 앱·화면 | 소비자 앱 SCR-05·17 / 생산자 앱 SCR-19·20·21 |
| 목적 | 가입 없이 둘러보고, 필요한 순간에만 로그인한다. 소비자 계정과 생산자 계정은 따로이고 앱별로 로그인한다(ADR 0010). I1은 시드 테스트 계정을 고르는 Mock 로그인이고, 카카오 로그인은 I2다(ADR 0009, 0003) |
| 사전 조건 | 서버의 Mock 로그인 설정이 켜져 있고 시드 테스트 계정이 있다(소비자 2: 김민지·이서준 / 생산자 5: 승인·확인 중·반려·정지·농가 없음) |
| 정상 흐름 | 1) 소비자 앱에서 팔로우·예약·채팅하기·좋아요를 누르거나 소식·채팅·내 정보 탭을 열면 안내 시트 → SCR-05 2) 소비자 테스트 계정을 고름(처음이면 약관·개인정보 처리방침 안내) 3) 누른 화면·행동으로 복귀, 입력값 유지 4) 생산자 앱은 SCR-19에서 생산자 테스트 계정을 고르고, 상태에 따라 농가 없음 → SCR-20, 신청·반려 → SCR-21, 승인 → SCR-22, 정지 → 정지 안내 5) 생산자 가입 신청(SCR-20)이 생산자 계정 만들기를 겸한다. 소비자 앱의 ‘농가로 시작하기’는 안내 시트를 거쳐 생산자 앱 가입으로 간다 |
| 예외 흐름 | E1 계정을 고르지 않고 뒤로 → 원래 화면, 행동 실행 안 함. E2 반려 → SCR-21에 사유와 다시 신청. E3 정지 → 정지 안내만 표시. E4 Mock 로그인이 꺼져 있음 → 로그인할 수 없다는 안내 |
| 사후 조건 | 그 앱의 계정으로 로그인 상태가 된다. 생산자 신청 시 농가가 승인 대기로 생긴다 |
| 입력·검증 | 그 앱의 시드 테스트 계정만 고를 수 있고 새 계정은 만들지 않는다. 생산자 신청: 대표자 이름·농가명·지역·주 품목·연락처 필수, 연락처는 휴대폰 번호 형식, 입점 정책 동의. (I2) 카카오에서는 이름만 받는다(FQ-01) |
| 규칙 | R-22, N-05, N-06 |
