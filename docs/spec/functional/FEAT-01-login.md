# FEAT-01 회원가입·로그인

> 상위: [PRD](/docs/spec/prd.md) 7.1 · 규칙: [rules.md](./rules.md) · 화면: [IA](/docs/spec/ia.md), [화면 명세](/docs/spec/screens.md) · 추적표: [README](./README.md)

| 항목 | 내용 |
| --- | --- |
| 우선순위·출처 | P0 · PRD 7.1, S-1·S-2 |
| 앱·화면 | 소비자 앱 SCR-05 / 생산자 앱 SCR-05·20·21 |
| 목적 | 가입 없이 둘러보고, 필요한 순간에만 로그인한다. I1은 시드 테스트 계정을 고르는 Mock 로그인이고, 카카오 로그인은 I2다(ADR 0009, 0003) |
| 사전 조건 | 서버의 Mock 로그인 설정이 켜져 있고 시드 테스트 계정이 있다(소비자 2, 승인된 생산자 1, 승인 대기 생산자 1) |
| 정상 흐름 | 1) 팔로우·예약하기·채팅하기·좋아요를 누르거나 소식·채팅·내 정보 탭을 열면 SCR-05로 이동 2) 테스트 계정 목록에서 하나를 고름(처음이면 약관·개인정보 처리방침 안내) 3) 누른 화면·행동으로 복귀, 입력값 유지 4) 생산자 앱은 상태에 따라 농가 없음 → SCR-20, 신청·반려 → SCR-21, 승인 → SCR-22 |
| 예외 흐름 | E1 계정을 고르지 않고 뒤로 → 원래 화면, 행동 실행 안 함. E2 반려 → SCR-21에 사유와 다시 신청. E3 정지 → 정지 안내만 표시. E4 Mock 로그인이 꺼져 있음 → 로그인할 수 없다는 안내 |
| 사후 조건 | 로그인 상태가 된다. 생산자 신청 시 농가가 승인 대기로 생긴다 |
| 입력·검증 | 시드에 있는 테스트 계정만 고를 수 있고 새 계정은 만들지 않는다. 생산자 신청: 농가명·지역·주 품목·연락처 필수, 연락처는 휴대폰 번호 형식. (I2) 카카오에서는 이름만 받는다(FQ-01) |
| 규칙 | R-22, N-05, N-06 |

- [ ] AC-01-1. **Given** 비로그인으로 상품 상세에 있다 / **When** 예약하기를 누르고 테스트 계정으로 로그인한다 / **Then** 주문서(SCR-10)가 열린다
- [ ] AC-01-2. **Given** 소비자 앱에 로그인한 테스트 계정이 있다 / **When** 같은 계정으로 생산자 앱에 로그인한다 / **Then** 새 계정 없이 같은 사용자로 로그인된다
- [ ] AC-01-3. **Given** 승인 전 생산자다 / **When** SCR-22\~30 주소나 생산자 API를 호출한다 / **Then** SCR-21로 이동하고 API는 거부한다
- [ ] AC-01-4. **Given** Mock 로그인이 켜져 있다 / **When** 시드에 없는 사용자 ID로 테스트 로그인 API를 호출한다 / **Then** 거부되고 새 계정이 생기지 않는다
- [ ] AC-01-5. **Given** Mock 로그인이 꺼져 있다 / **When** 테스트 계정 목록·테스트 로그인 API를 호출한다 / **Then** 둘 다 거부된다
