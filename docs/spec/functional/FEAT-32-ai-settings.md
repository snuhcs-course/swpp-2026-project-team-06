# FEAT-32 농가 AI 응답 설정

스펙 1.2 · I1 Should · SCR-31 · 규칙: M-05, M-18, M-20. 자기 농가의 승인 생산자 권한·입출력·오류는 [공통 계약](../contracts-1.2.md)을 따른다. 구현 완료 표시는 후속 PR에서 한다.

- [ ] AC-32-1. 농가 설정 ON/OFF·응대 원칙·FAQ·추가 전달 주제를 저장하고 재조회하면 버전과 값이 유지된다.
- [ ] AC-32-2. 정책과 상품 사실에 반하는 FAQ로 가격·환불·배송 약속을 바꾸지 않고 전달한다.
- [ ] AC-32-3. 미리보기는 답변·근거·전달 사유를 보여주되 대화·설정·문의 기록을 변경하지 않는다.
- [ ] AC-32-4. 다른 농가 접근과 오래된 버전 저장을 거부하고 입력을 보존한다.
