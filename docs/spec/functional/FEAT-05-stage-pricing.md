# FEAT-05 단계·가격·물량 설정

> 상위: [PRD](/docs/spec/prd.md) 7.1 · 규칙: [rules.md](./rules.md) · 화면: [IA](/docs/spec/ia.md), [화면 명세](/docs/spec/screens.md) · 추적표: [README](./README.md)

| 항목 | 내용 |
| --- | --- |
| 우선순위·출처 | P0 · PRD 7.1, S-1 |
| 앱·화면 | 생산자 앱 SCR-26 |
| 목적 | 기본값을 바탕으로 단계별 기간·가격·물량을 쉽게 정한다 |
| 사전 조건 | 상품에 중량 옵션이 1개 이상 있다 |
| 정상 흐름 | 1) 기본값 선택 2) 단계 수·기간·할인 폭이 채워짐 3) 기간·가격·물량 수정 4) 저장 → FEAT-04 게시 요청 |
| 예외 흐름 | E1 검증 실패 → 칸별 이유 표시, 저장 안 함. E2 승인 후 변경 → 재승인 전까지 기존 값으로 판매(R-25) |
| 사후 조건 | 단계·단계 가격·단계 물량이 저장된다 |
| 입력·검증 | 단계 기간은 겹치지 않고, 마지막 단계 종료일은 배송 예정 시작일보다 늦지 않다. 같은 옵션에서 이른 단계 가격 < 다음 단계 가격. 가격은 1원 이상 정수, 물량은 0 이상 정수 |
| 규칙 | R-06, R-17, R-18, R-25 |

- [ ] AC-05-1. **Given** 2단계 5kg가 25,000원이다 / **When** 1단계 5kg를 27,000원으로 입력하고 저장한다 / **Then** 저장되지 않고 이유가 보인다
- [ ] AC-05-2. **Given** 1단계가 10/7\~10/20이다 / **When** 2단계를 10/15부터로 입력한다 / **Then** 기간이 겹쳐 저장되지 않는다
- [ ] AC-05-3. **Given** 기본값을 고른다 / **When** 화면이 열린다 / **Then** 단계 수·기간·할인 폭이 채워져 있다
