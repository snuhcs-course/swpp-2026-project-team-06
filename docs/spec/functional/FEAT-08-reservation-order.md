# FEAT-08 예약 주문

> 상위: [PRD](/docs/spec/prd.md) 7.1 · 규칙: [rules.md](./rules.md) · 화면: [IA](/docs/spec/ia.md) · 추적표: [README](./README.md)

| 항목 | 내용 |
| --- | --- |
| 우선순위·출처 | P0 · PRD 7.1, S-2 |
| 앱·화면 | 소비자 앱 SCR-10 |
| 목적 | 조건에 동의하고 예약 주문을 만든다 |
| 사전 조건 | 로그인했고, 상품이 판매 중이며, 지금 단계가 있고 남은 물량이 1 이상이다 |
| 정상 흐름 | 1) 옵션·수량 선택 2) 받는 사람·연락처·주소 입력 3) 합계 = 단계 가격 × 수량 + 배송비 + 도서산간 추가금(해당 시) 4) 동의 4개 5) 결제하기 → 서버가 단계·가격·물량 재확인 6) 주문 생성(결제 전), 동의 시각 기록 → FEAT-09 |
| 예외 흐름 | E1 그사이 단계가 바뀌거나 품절 → 바뀐 가격·품절 안내, 입력값 유지. 물량은 잡아두지 않고 결제 순간 선착순으로 확정한다 |
| 사후 조건 | 결제 전 주문이 생기고 주문 금액은 이 시점 단계 가격으로 고정된다 |
| 입력·검증 | 받는 사람 이름·연락처(휴대폰 형식)·주소 필수. 동의 4개 모두 필수. 수량은 1\~최대. 주소가 생산자가 정한 도서산간 지역이면 추가금 적용 |
| 규칙 | R-03, R-06, R-17, R-20, R-23 |

- [ ] AC-08-1. **Given** 동의 4개 중 하나를 체크하지 않았다 / **When** 결제하기를 누른다 / **Then** 다음으로 넘어가지 않는다
- [ ] AC-08-2. **Given** 한 주문 최대 수량이 3이다 / **When** 수량을 고른다 / **Then** 4 이상은 고를 수 없다
- [ ] AC-08-3. **Given** 배송비 별도 상품이다 / **When** 주문서를 연다 / **Then** 상품 금액·배송비·합계가 나뉘어 보인다
- [ ] AC-08-4. **Given** 받는 주소가 생산자가 정한 도서산간 지역이다 / **When** 주소를 입력한다 / **Then** 추가 운임이 합계에 더해져 보인다
