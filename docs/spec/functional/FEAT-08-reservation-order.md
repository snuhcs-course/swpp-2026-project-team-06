# FEAT-08 예약 주문

> 상위: [PRD](/docs/spec/prd.md) 7.1 · 규칙: [rules.md](./rules.md) · 화면: [IA](/docs/spec/ia.md), [화면 명세](/docs/spec/screens.md) · 추적표: [README](./README.md)

| 항목 | 내용 |
| --- | --- |
| 우선순위·출처 | P0 · PRD 7.1, S-2 |
| 앱·화면 | 소비자 앱 SCR-04(옵션·수량 시트), SCR-10과 배송지 입력 하위 화면, SCR-17 배송지 관리(`/me/addresses`) |
| 목적 | 조건에 동의하고 예약 주문을 만든다 |
| 사전 조건 | 로그인했고, 상품이 판매 중이며, 지금 단계가 있고 남은 물량이 1 이상이다 |
| 정상 흐름 | 1) 옵션·수량 선택 2) 받는 사람·연락처·우편번호·주소·상세 주소(I1은 직접 입력, 우편번호 찾기 없음)·배송 메모(선택) 입력(저장된 배송지가 있으면 기본으로 채움, 새 주소는 저장할 수 있음) 3) 합계 = 단계 가격 × 수량 + 배송비 + 도서산간 추가금(해당 시) 4) 동의 4개 5) 결제하기 → 멱등 키와 함께 1회 요청, 서버가 단계·가격·물량 재확인 6) 주문 생성(결제 전), 동의 시각 기록 → FEAT-09 |
| 예외 흐름 | E1 그사이 단계가 바뀌거나 품절 → 바뀐 가격·품절 안내(409), 입력값 유지, 다시 확인받음. 물량은 잡아두지 않고 결제 순간 선착순으로 확정한다. E2 같은 요청이 두 번 감(중복 탭·재전송) → 같은 멱등 키면 주문은 하나만 생긴다 |
| 사후 조건 | 결제 전 주문이 생기고 주문 금액은 이 시점 단계 가격으로 고정된다. 동의 시각과 문구 버전이 기록된다 |
| 입력·검증 | 받는 사람 이름·연락처(휴대폰 형식)·우편번호·주소 필수, 상세 주소·배송 메모(100자 이하) 선택. 주소·배송 메모는 주문에 복사해 저장한다(저장 배송지를 바꿔도 지난 주문은 그대로). 동의 4개 모두 필수. 수량은 1\~최대. 주소가 생산자가 정한 도서산간 지역이면 추가금 적용 |
| 규칙 | R-03, R-06, R-17, R-20, R-23 |

- [ ] AC-08-1. **Given** 동의 4개 중 하나를 체크하지 않았다 / **When** 결제하기를 누른다 / **Then** 다음으로 넘어가지 않는다
- [ ] AC-08-2. **Given** 한 주문 최대 수량이 3이다 / **When** 수량을 고른다 / **Then** 4 이상은 고를 수 없다
- [ ] AC-08-3. **Given** 배송비 별도 상품이다 / **When** 주문서를 연다 / **Then** 상품 금액·배송비·합계가 나뉘어 보인다
- [ ] AC-08-4. **Given** 받는 주소가 생산자가 정한 도서산간 지역이다 / **When** 주소를 입력한다 / **Then** 추가 운임이 합계에 더해져 보인다

* [ ] AC-08-5. **Given** 내 정보에 배송지를 저장해 두었다 / **When** 주문서를 연다 / **Then** 받는 사람·연락처·주소가 채워져 있고 고칠 수 있다
