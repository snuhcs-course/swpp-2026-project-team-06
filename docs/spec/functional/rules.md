# 비즈니스 규칙 상세 (R·M)

> 상위: [기능 명세 README](./README.md) · [PRD](/docs/spec/prd.md) 7.2

PRD 7.2에서 옮긴 규칙 전문이다. MUST NOT 규칙은 Mock 결제에서도 지킨다. 사용자에게 보일 약관·안내 문구는 서비스 정책이, 상태 전이·데이터 제약은 기술 설계가 이 ID를 인용해 쓴다.

## 1.1 주문·결제·가격

| ID | 규칙 |
| --- | --- |
| R-01 | 결제수단은 신용카드와 카드 재원 간편결제만 받는다. 계좌이체·무통장·가상계좌·페이머니는 받지 않는다(MUST NOT). |
| R-02 | 주문 시 전액을 한 번에 결제한다. 예약금·잔금 분할과 에스크로는 없다. |
| R-03 | 결제 전에 배송 예정 기간, 최대 지연 기한과 초과 시 자동 전액 환불, 흉작·수량 부족 시 처리, 취소 조건을 보여주고 별도 동의를 받는다. 동의 시각과 동의한 문구의 버전을 기록한다(MUST). |
| R-04 | 최대 지연 기한은 카드 승인 취소가 가능한 기한 안이다. 값은 PRD Q-07에서 정하고 설정값으로 둔다. |
| R-05 | 결제 화면과 주문 내역에 배송 예정 기간을 항상 표시한다. 단계가 바뀔 때 주문자에게 진행 알림을 보낸다(SHOULD, I1 제외 → FEAT-18). |
| R-06 | 단계 물량을 넘는 주문은 받지 않는다. 동시 주문에서도 같다. 다 팔리면 다음 단계 일정까지 품절로 표시한다. 다음 단계를 앞당겨 열지 않는다. |
| R-17 | 주문 금액은 주문 시점 단계 가격으로 고정된다. 이후 바뀌어도 기존 주문에는 영향이 없다. |
| R-18 | 단계 일정·가격·물량은 생산자가 정한다. 플랫폼은 기본값(단계 구성·기간·단계별 할인 폭)을 제공하고, 생산자는 고르거나 고친다. 이른 단계가 더 싸야 한다는 원칙은 지킨다. 생산자가 정한 단계·가격은 farmclub이 승인해야 판매된다(MUST). |
| R-20 | 배송비는 생산자가 상품마다 무료배송과 별도 부과 중에서 정한다. 별도면 결제 전에 상품 금액과 배송비를 나눠 보여주고 합계를 결제한다. 도서산간 지역과 추가 운임도 생산자가 상품마다 정하고, 주문서에서 주소가 그 지역이면 결제 전에 표시한다. 무료배송 유도 방식은 이후 유저 스터디로 정한다. |
| R-21 | 배송 예정 기간은 결제 전에 명시한다(R-03). 이 기간을 벗어나게 되면 주문자에게 알리고, 새 기간에 동의하거나 전액 환불받는 것 중 고르게 한다. 이 처리 방식도 결제 전에 고지한다. |
| R-22 | 생산자는 가입 신청 후 farmclub이 농가임을 확인하고 승인해야 상품을 올릴 수 있다. 로그인은 I1은 시드 테스트 계정(Mock), I2부터 카카오이고, 농가 확인은 전화·방문으로 한다. |
| R-23 | 한 주문은 한 중량 옵션을 여러 개 담을 수 있다. 한 주문의 최대 수량은 생산자가 상품마다 정하고, 배송지는 주문당 1곳이다. 수량은 단계 물량(R-06)을 넘지 않는다. |
| R-25 | 판매 중인 상품의 가격·중량 옵션·단계를 바꾸면 farmclub 재승인을 받아야 반영되고, 승인 전까지는 기존 값으로 계속 판매한다. 설명·사진·실측 당도·등급·배송비는 바로 반영한다. 배송 예정 기간 변경은 R-21을 따른다. 이미 한 주문은 바뀌지 않는다(R-17). |

## 1.2 환불

| ID | 규칙 |
| --- | --- |
| R-07 | 출하 전 취소는 사유와 관계없이 전액 환불한다. 위약금·수수료는 받지 않는다(MUST NOT). |
| R-08 | 환불은 카드 승인 취소로만 한다. 포인트·크레딧·충전금·예치금·상품권 같은 금전성 기능은 만들지 않는다(MUST NOT). |
| R-09 | 최대 지연 기한까지 출하되지 않은 주문은 자동으로 전액 환불한다. |
| R-10 | 흉작·수량 부족이면 가능한 수량을 주문에 비례 배분하고 부족분을 즉시 환불한다. |
| R-11 | 배송 후에는 하자가 있을 때 환불·교환한다. 기한과 절차는 서비스 정책이 정한다. |
| R-12 | 환불은 법정 기한 안에 처리한다. 구체 기한은 서비스 정책이 정한다. |
| R-24 | 농가 승인이 취소(활동 정지)되면 그 농가의 출하 전 주문은 모두 전액 환불한다. 다른 농가로 대체하지 않는다. 소비자 주문 상세에 환불 사유를 표시한다. 흉작으로 수량만 부족한 경우는 R-10을 따른다. |

## 1.3 정산·개인정보·표시·출하

| ID | 규칙 |
| --- | --- |
| R-13 | 주문마다 결제일·배송 완료일·구매 확정일을 반드시 기록한다. 선수금·정산의 근거다. |
| R-14 | 농가 매입·정산은 구매 확정 시점에 확정된다. 구매 확정은 소비자가 직접 하거나, 배송 완료 후 8일이 지나면 자동으로 된다(네이버 방식). I1은 기록만 남긴다. |
| R-15 | 생산자는 배송에 필요한 정보(받는 사람·연락처·주소)만 보고, 배송 완료 후에는 가린다(SHOULD). |
| R-16 | 법정 표시 의무(원산지, 상품정보, 사업자 정보)를 지킨다. 항목은 서비스 정책이, 위치는 화면 명세가 정한다. |
| R-19 | 출하는 생산자가 처리한다. 생산자가 주문을 골라 송장번호와 함께 출하로 바꾸고, 확인해야 반영된다. 생산자는 출하까지만 바꾸고, 배송 완료는 택배 조회로 수령을 확인해 바꾼다. I1은 운영자가 처리하고, 택배 연동은 FEAT-22다. (I2) 자연어(예: 송장번호와 함께 “김○○님 5kg 보냈어요”)로 입력하면 AI가 해당 주문과 바뀔 상태를 보여주고 생산자가 확인한다. AI가 혼자 상태를 바꾸지 않는다(MUST NOT). |

## 1.4 소통

| ID | 규칙 |
| --- | --- |
| M-01 | 소식(전체 메시지)은 생산자만 올리고, 그 농가를 팔로우한 소비자 전원의 소식 탭에 간다. 글·사진·영상을 보낼 수 있고, 용량·형식 제한은 기술 설계가 정한다. |
| M-02 | 소비자의 채팅(질문·답장)은 그 소비자와 농가만 본다. 다른 소비자에게 보이지 않는다(MUST NOT). |
| M-03 | 소비자끼리 대화하는 기능은 없다. 단체방·댓글을 만들지 않는다. |
| M-04 | 채팅은 팔로우한 농가에만 보낼 수 있다(팔로우하지 않은 농가에서 채팅하기를 누르면 팔로우부터 한다, FEAT-12). 농가의 답과 AI의 답은 구분해 표시한다. |
| M-14 | 생산자는 소식을 올릴 때 공개 여부를 고른다. 공개 소식은 농가 페이지 소식 목록에 남아 누구나 볼 수 있고, 팔로워 전용 소식은 팔로워의 소식 탭에만 간다. 소비자의 채팅은 항상 비공개다(M-02). |
| M-16 | 메시지·답장에 전화번호·계좌번호·외부 메신저 ID가 있으면 자동으로 가린다(예: 010-○○○○-○○○○). 거래와 소통을 플랫폼 안에 두기 위해서다. |

## 1.5 AI

| ID | 규칙 |
| --- | --- |
| M-05 | 소비자가 채팅으로 질문을 보내면 AI가 먼저 응답을 시도한다. 근거는 그 농가의 프로필·상품·단계·메시지와 그 소비자 자신의 주문뿐이다. |
| M-06 | 근거로 답할 수 없으면 추측하지 않고(MUST NOT) “농가에 전달했어요”라고 알린 뒤 생산자에게 넘긴다. |
| M-07 | 농약·재배 방식, 환불·보상 요구, 항의·불만, 가격 할인·흥정, 배송 일정 변경 약속, 개인적인 대화는 항상 생산자에게 넘기고, 환불 요구는 운영자에게도 알린다. |
| M-08 | AI는 농가 본인인 척하지 않는다. 모든 AI 응답은 AI 안내로 표시하고 근거를 기록한다. |
| M-09 | 생산자가 넘겨받은 질문에 답하면, 그 답은 질문한 소비자에게만 간다. |
| M-10 | 생산자가 쓰던 문구(텍스트)로 상품 초안을 만든다. 입출력 항목은 이 문서 FEAT-03에서 정한다. |
| M-11 | 입력에 없는 값은 빈 칸으로 두고 표시한다. 당도·배송 시기를 지어내지 않는다(MUST NOT). |
| M-12 | AI는 가격·단계를 확정하지 않는다. 가격·단계는 생산자가 기본값을 바탕으로 직접 정한다(R-18). |
| M-13 | 초안은 생산자가 확인해 게시를 요청하고 farmclub이 승인해야 공개된다. AI가 직접 게시하지 않는다. |
| M-15 | 당도 질문은 AI가 등록된 당도로 답한다. 실측값이 있으면 실측값을, 없으면 예상값임을 밝힌다. 둘 다 없으면 농가에 전달한다. 실측값은 대부분 수확 직전 농가가 측정해 공개한다. |
| M-17 | (I2) AI 안내마다 ‘틀렸어요’ 버튼을 둔다. 소비자가 누르면 그 질문을 농가 질문함에 넣고, 농가가 바로잡는 답을 보낸다. 어떤 AI 답이 틀렸다고 표시됐는지 기록한다. |
| M-18 | AI에 보내는 데이터에서 연락처·주소 등 개인정보를 뺀다(MUST NOT 전송). 주문 상태·배송 예정 기간처럼 답에 필요한 값만 넘긴다. |
