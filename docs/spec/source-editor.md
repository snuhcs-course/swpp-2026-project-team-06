# DEV-58 판매페이지 직접 편집

이 문서는 이전 개인정보 검토·확정 단계와 분리된 편집 폼 설명을 대체한다.

- 자료와 상품사진은 별도 썸네일 박스다. 자료의 텍스트/TXT는 원문 수정 가능하며 사진/PDF는 편집하지 않는다. 첨부 제외 시 기존 저장 초안은 유지하되 최신 자료로 다시 저장해야 적용할 수 있다.
- 업로드 전에 개인정보를 직접 가리도록 안내한다. 새 자료는 자동/수동 가림 및 사용자 승인 대기 없이 분석한다. 기존 가림본과 자료 버전 취소 보호는 유지한다.
- 상품사진은 OCR·시각 AI 없이 준비한다. 사진별 한 줄 설명만 묶어서 모델에 보내 사진 섹션에 배치한다. 설명은 상품 사실이나 공개 캡션으로 사용하지 않는다. 빈 설명·모호한 설명은 수동 배치하고, 저장된 수동 선택을 우선한다.
- 분석 결과를 읽은 후 상세페이지 편집 버튼을 활성화한다. 내부 작업 개수·실행 기록 대신 최신 분석 상태 하나만 표시한다.
- 실제 판매페이지 렌더러를 공유해 문구 직접 수정, 사진 추가·제외·교체·순서 및 위치 이동, 항목별 ON/OFF를 제공한다. OFF 항목은 원래 위치에 접힌 한 줄로 남고 값은 보존한다. 자료에 없는 사실을 만들지 않는다.
- 비공개 저장과 명시적 공개·상품 반영을 분리한다. 미저장 입력·실패 재시도·버전 충돌 보호를 유지한다.
- 사진 설명 수정은 별도 descriptionVersion으로 검사한다. 이미지 근거 버전은 변경하지 않는다. 마이그레이션 0012는 사진 설명·설명 버전·배치 결과·분석 입력 스냅샷을 추가한다.

## 편집 조작 (DEV-58)
- 첨부 파일명은 화면에 표시하지 않는다. 텍스트 타일은 원문을 짧게 줄인 대괄호 미리보기와 ×를 제공하며 카드 본문을 누르면 전체 내용을 수정한다. 별도 연필은 표시하지 않는다. 사진·PDF는 썸네일과 ×를 제공한다. 별도 버튼 줄 없이 내용이 카드 전체를 채우고 아이콘은 우측 상단에 오버레이한다. 첨부 사진·PDF는 정사각 cover 미리보기이며 실제 판매페이지 사진 비율은 유지한다. 상품사진 설명은 카드 안에서 바로 수정하고 blur/분석 직전 저장한다. 실패한 입력은 보존하고 카드 안에서 재시도한다.
- 사진 자리에는 점선 둥근 사각형과 + 사진 추가를 항상 표시한다. 기존 상품사진 선택/새 업로드를 제공하고 사진을 누르면 제외·순서·이동 도구를 연다. 모든 편집 도구는 공개 페이지에 표시하지 않는다.
- 눈 아이콘으로 끄면 접히고 제목이 흐려지며 켜면 펼쳐진다. 별도 접기 화살표와 접힘 상태는 제공하지 않는다. 켜진 항목은 항상 내용을 표시한다. 미리보기/공개는 켜진 내용을 모두 표시한다. 충돌 항목은 내용 확인에서 해결한 뒤 켤 수 있다.
- 카드와 편집 조작부는 작은 regular 글씨/44px 터치 영역을 사용하고 기존 판매페이지 본문 강조는 유지한다. 기존 API/DB 계약 유지.
