# ADR 0011 — 기존 자료 분석의 별도 Sol 어댑터

- 상태: DEV-54 구현, 실자료 모델 평가는 미실시
- 날짜: 2026-10-14
- 범위: FEAT-03/04/07의 자료 분석 확장, M-10~13/M-18

사용자가 선택한 GPT-6.1 Sol을 새 자료 분석에만 사용한다. 기존 ADR 0004의 Claude 단건 초안·채팅 동작은 바꾸지 않는다.

모델 호출은 app/ai/source_analysis.py에 한정한다. source_analysis 도메인은 비공개 자료·작업·근거 검토·상세 초안을 소유한다. API와 별도 worker는 PostgreSQL 큐를 공유하고, 가림 검토가 완료된 사본만 외부 모델에 전송한다. Mock은 명시적인 개발 fixture이며 실제 호출 실패를 대체하지 않는다.

새 상세 초안은 18개 모듈의 schemaVersion=1 계약이다. 기존 detailContent로 암묵적으로 변환하거나 상품/가격/주문을 변경하지 않는다. 실제 API 품질·속도·비용은 후속 고정 자료 평가로 확인한다. 선택적 AI 이미지 생성은 고려 중이고 이 구현에는 없다.
