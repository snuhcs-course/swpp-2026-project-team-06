# 0003 인증: 카카오 로그인 + JWT

- 상태: I2로 연기 (2026-10-07, P22). I1은 [0009](./0009-mock-login.md) Mock 로그인을 쓰고, 아래 결정은 I2에서 그대로 적용한다
- 관련: FEAT-01, R-22, N-05, N-06
- 갱신: 계정 분리([0010](./0010-separate-accounts.md), SWPP-81). 같은 카카오 식별자라도 소비자 계정과 생산자 계정은 따로다

## 배경
가입 없이 둘러보고 팔로우·예약·답장 때만 카카오로 로그인한다. 카카오에서는 이름만 받는다. (원래 결정: 같은 카카오 계정으로 두 앱을 쓴다 → 0010에서 앱별 계정으로 바뀜)

## 결정
각 앱이 카카오 인가 코드를 받아 `POST /api/auth/kakao`(앱 구분 `app` 포함)로 넘기고, 서버가 (카카오 식별자, 역할)로 그 앱의 사용자를 찾거나 만들어 JWT(PyJWT)를 발급한다. 역할(`role`)과 농가 승인 상태는 서버에서 검사한다.

## 결과
- 앱과 API가 다른 도메인이어도 쿠키 문제 없이 동작한다.
- 토큰을 브라우저에 저장하므로 XSS에 주의한다. 액세스 토큰은 짧게, 리프레시 토큰은 회전한다.
- 카카오 개발자 콘솔에 두 앱의 리다이렉트 주소를 등록해야 한다.
