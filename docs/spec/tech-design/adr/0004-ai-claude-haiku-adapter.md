# 0004 AI: Claude Haiku 4.5, 어댑터 한 곳

- 상태: 결정 (2026-10-07)
- 관련: FEAT-03, FEAT-13, FEAT-17(I2), M-05~M-18, N-04, N-08, Q-19, PQ-08
- 갱신 (2026-10-07, P22): 출하 문장 해석(FEAT-17)과 ‘틀렸어요’(M-17)는 I2. I1의 AI 호출은 상품 초안과 문의 응답 두 가지다

## 배경
상품 초안 추출, 문의 응답, 출하 문장 해석에 AI를 쓴다. 이후 자체 모델 서빙을 검토할 수 있어야 한다.

## 결정
Claude API의 Claude Haiku 4.5(`claude-haiku-4-5`)를 쓴다. 모든 호출은 `server/ai`의 어댑터를 거치고, 출력은 정해진 JSON 형식으로만 받는다. 보내기 전에 연락처·주소·계좌를 지운다(M-18). 호출 기록은 Langfuse에 남긴다.

## 결과
- 모델을 바꿀 때 어댑터만 고친다(자체 모델 서빙 포함).
- 외부 AI로 데이터를 보내는 것을 처리방침에 고지한다(PQ-08).
- 정확도(N-08 80%)는 시드 문구 모음으로 평가한다.
