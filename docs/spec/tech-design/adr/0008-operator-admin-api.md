# 0008 운영자 처리: 관리 API + Swagger UI, 화면은 I2

- 상태: 결정 (2026-10-07). [0002](./0002-backend-django-admin.md)의 Django Admin 결정을 대체한다
- 관련: R-22, R-24, R-25, FEAT-23, N-06

## 배경
FastAPI로 바꾸면서 Django Admin을 쓸 수 없다. I1에는 운영자 전용 화면을 만들 시간이 없다.

## 결정
운영자 업무는 `/admin/...` 관리 API로 만들고, FastAPI가 제공하는 Swagger UI(`/docs`)에서 호출한다.
- 대상: 생산자 승인·반려, 상품 승인·반려, 배송 완료, 환불, 농가 정지(R-24), 메시지 삭제
- 모든 관리 API는 서버에서 `ADMIN` 역할을 검사한다(N-06).
- 운영 환경의 `/docs`는 ADMIN 로그인 뒤에만 열리게 하거나 공개하지 않는다.
- 전용 운영자 화면(FEAT-23)은 I2에서 만든다.

## 결과
- 화면 없이도 I1 운영이 가능하다. 대신 운영자가 API 형식을 알아야 한다.
- 관리 API는 I2 화면이 그대로 쓴다.
