# 0001 프론트엔드: Expo 웹 출력, 앱 2개

- 상태: 결정 (2026-10-07)
- 관련: N-01, N-02, FEAT-19

## 배경
소비자 앱과 생산자 앱은 별도 모바일 웹이다. 지금은 링크로 들어오는 웹이 먼저지만, 이후 Android·iOS 앱을 낼 수 있어야 한다.

## 결정
Expo(React Native, TypeScript) + Expo Router로 `apps/consumer`, `apps/producer` 두 앱을 만들고 웹으로 출력해 Vercel에 올린다. 공통 컴포넌트는 `packages/ui`에 둔다.

## 결과
- 한 코드로 I2 이후 앱 빌드가 가능하다.
- 웹 출력만으로는 페이지별 서버 메타태그(링크 미리보기)를 만들기 어렵다 → 0006으로 보완한다.
- 웹 전용 라이브러리 일부는 쓸 수 없다. React Native Web에서 동작하는지 확인한다.

## 검토한 대안
- Next.js: 링크 미리보기와 웹 품질은 낫지만 앱으로 넓히려면 다시 만들어야 한다.
- Vite + React: 가장 단순하지만 앱 확장과 미리보기를 따로 해결해야 한다.
