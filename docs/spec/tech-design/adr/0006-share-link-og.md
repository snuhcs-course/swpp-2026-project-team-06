# 0006 공유 링크: 서버 OG 페이지

- 상태: 결정 (2026-10-07)
- 관련: FEAT-19, AC-19-1, AC-19-2

## 배경
첫 진입은 농가가 카톡으로 보낸 링크다. 카톡 미리보기는 링크 주소의 HTML 메타태그(OG)를 읽는데, 웹 출력 앱은 페이지별 메타태그를 서버에서 만들기 어렵다.

## 결정
농가 링크는 서버의 `/s/farms/<id>`로 만든다. 이 주소는 농가 이름·소개·대표 사진으로 OG 태그를 채운 HTML을 주고, 사람은 바로 소비자 앱 농가 페이지로 이동시킨다. 승인 취소된 농가는 ‘찾을 수 없는 농가’로 보낸다.

## 결과
- 카톡·문자 미리보기가 농가 정보로 뜬다.
- 링크가 서버를 한 번 거친다.
