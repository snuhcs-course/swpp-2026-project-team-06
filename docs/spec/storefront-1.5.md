# 스펙 1.5 — 농가·상품 상세와 공개 소식방

## 화면
기존 4개 하단 탭은 유지한다. SCR-03은 농가 이름·짧은 대표 사진과 팔로우 버튼, 팔로워 수 / 소식방 입장 / 1:1 채팅 순서의 3열, 상품 목록, 긴 농가 소개 순서다. 최신 소식 카드·상품/소식 탭은 제거한다. 상품이 없어도 소개와 소식방은 열린다.
SCR-04는 상품 사진·상품명·가격·예약 정보 다음에 사진/제목/본문의 긴 상세를 펼친다. 상품 고시·취소 규정은 하단, 예약 CTA는 화면 하단에 유지한다. 상세 없는 기존 농가/상품은 intro/description을 표시한다. 사진은 원래 비율을 유지한다.

## 상세 생성·편집 (FEAT-02/03/04/07)
생산자는 농가 프로필 또는 상품 편집에서 상세 편집으로 들어간다. 등록 정보·입력 글·사진 → 초안 생성 → 제목/본문/사진 추가·삭제·순서 수정 → 소비자와 같은 미리보기 → 저장 순서다. 재생성은 기존 편집안을 덮기 전 확인한다. 생성은 공개 데이터를 바꾸지 않으며 저장 시에만 반영된다. 떠나기 전 저장하지 않은 변경을 확인한다. 생성/저장 실패 시 입력과 편집안 보존, 재시도 가능. 상품 심사 중·종료 상태의 수정 제한과 version 충돌은 기존 계약을 따른다.
가격/예약 날짜는 기존 판매 설정에만 표시하고 AI가 상세에 확정값으로 중복 생성하지 않는다. 당도·인증·원산지 등 입력 근거 없는 사실을 만들지 않는다. 이미지는 사용자가 고른 사진만 사용하며 이번 범위에 이미지 생성 AI는 없다. Mock은 입력·등록 내용을 구성하는 데모임을 표시한다. 실제 AI는 DEV-4 서버 어댑터 책임이며 브라우저에서 AI 키를 취급하지 않는다.

### API·자료형
- DetailContent = { blocks: DetailBlock[] }. 블록은 {id, type:"text", title, body} 또는 {id, type:"image", uri, alt}. 최대 30개, id 중복 금지, 제목 100자/본문 3000자/alt 200자. text는 제목 또는 본문 필수. 이미지 URI는 HTTPS 또는 서비스 상대 경로; 로컬 Mock에서는 localhost HTTP·이미지 data URL도 허용한다. HTML을 실행하지 않는다.
- FarmDetail/MyFarm/ProductDetail/MyProduct에 detailContent?: DetailContent 추가. 없는 값은 기존 intro/description, 빈 blocks 저장은 사용자 작성 상세 제거를 뜻한다.
- PATCH /api/farms/me, PATCH /api/products/:productId에 detailContent 추가. 농가는 본인만, 상품은 기존 version·멱등 키·수정 가능 상태 검사 유지.
- POST /api/farms/me/detail-draft 및 POST /api/products/mine/:productId/detail-draft. 본인 생산자만. 입력 {inputText, photos:string[]} (글 최대 3000자, 사진 최대 10개); 등록 정보는 서버가 조회한다. 응답 {content:DetailContent, mode:"mock"|"ai"}. 생성은 저장하지 않는다. 오류는 기존 공통 오류 응답. 실제 AI 지연·실패는 편집안을 유지하고 직접 편집을 허용한다.
- 실제 미디어는 기존 업로드 경로의 URL, 로컬은 공유 Mock 업로드 사용. DB에 상세가 없는 기존 레코드를 지우거나 초기화하지 않는다.

## 소식방 (FEAT-12/15)
GET /api/messaging/rooms/:farmId/messages는 승인 농가의 공개 소식 읽기를 비로그인/미팔로우에도 허용한다. 팔로워는 전체 방송+본인 답장, 소유 생산자는 전체 방송+모든 소비자 답장을 본다. 다른 농가 생산자·미승인 생산자는 기존 접근 거부를 유지한다. 소비자가 팔로우 해제하면 공개 방송만 반환한다. 삭제/정지 농가는 404.
권한 필터는 페이지네이션·요약 계산 전에 적용한다. room 요약에 canReply:boolean 추가. POST 답장은 로그인+팔로우 또는 소유 생산자만 허용. 좋아요는 공개 소식이면 로그인한 소비자, 전용 소식이면 팔로워만. 읽기만으로 팔로우하지 않는다.
소식방은 공개 읽기 안내 및 로그인/팔로우 진입 버튼을 표시한다. 로그인·팔로우 후 해당 방으로 복귀한다. 권한 변경 시 기존 메시지 캐시를 폐기해 전용 소식·답장이 남지 않게 한다.
농가 입장 시 뒤로 가기는 농가, 채팅 목록 입장 시 목록. 직접 URL은 농가를 기본 복귀 대상으로 한다. 주문 완료의 소식 보기 역시 해당 소식방으로 이동한다.

## 기존 모순 정리
스펙 1.4에 따라 최초·증액 공급 물량만 승인한다. 일반 가격/예약 기간 편집은 재승인 대기가 아니며, 기존 주문 때문에 잠긴 필드는 기존 변경 동의 계약을 따른다. '승인 대기 편집안 저장'은 '예약 기간 저장', '가격은 단계 설정에서'는 '가격은 예약 기간별로 설정'으로 정리한다.
기존 문서의 상품/소식 전환·공개 소식 탭·반복 가격 심사 설명은 본 계약으로 대체한다. 탭/승인 변경의 과거 결정 기록은 이력을 보존하되 현재 기준을 연결한다.
