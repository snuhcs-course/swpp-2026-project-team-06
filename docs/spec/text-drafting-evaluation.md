# DEV-448 텍스트 중심 평가 (명시적 opt-in)

FEAT-03/04/07 · AC-SRC-2/3/5/10/11 · M-11/18. 기존 strict scorer/gold는 변경하지 않는다. 새 text_score는 page-wide 보존·의미/근거·위치·반복·처리 결과를 분리하는 개발 진단이다. 승인되지 않은 gold/의미 판단을 human approved로 부르지 않는다. 판단 범위를 넘는 paraphrase는 UNKNOWN이며 lexical token만으로 의미 정확성을 인정하지 않는다. 실제 기존 정답/임계치는 변경하지 않고 새 결과와 나란히 기록한다.

가격·개인정보·효능·정책 경계는 현재 source-analysis.md 계약을 따른다. 정상 빈 결과는 명시된 빈 gold 계약에서만 구분한다. source/product/option/measurement/sample/time 조건이 다른 값은 같은 근거로 쓰지 않는다. support false를 token 일치로 덮지 않는다. 전체 출력의 추가 주장도 별도 검사한다. historical criticalGate는 95% 전체/형식별 recall 통과가 아니다. 미해결 의미와 처리 불완전은 새 acceptance에서 드러낸다.

이번 범위는 텍스트 출력과 점수다. 이미지/PDF의 글 읽기는 유지하되 사진 선택·크롭·시각 디자인 평가를 포함하지 않는다. 생산자 직접 수정·비공개 저장·명시 적용/권한은 그대로다. 실제 제품 채택/운영 배포는 별도이며 source/editor 계약 변경을 암묵적으로 수행하지 않는다.


## DEV-450 명시적 inventory writer 실험
기본 v11 worker/큐/캐시는 유지한다. 별도 refine_inventory 호출만 전체 승인 후보 inventory와 target·자료 revision·안전 규칙·writer version의 해시에 결합된 응답을 처리한다. KEEP 문구는 인용한 unit 원문을 순서대로 그대로 유지해야 하며, 공백 연속/NFC 정규화만 허용한다. 자유로운 의역·단위 변환·수식어 제거는 거절한다. 모든 unit은 KEEP/EXCLUDE/REVIEW 중 하나이며, EXCLUDE/REVIEW는 검토 필요 상태다. 기존 최종 안전 검증이 KEEP를 거절하면 INCOMPLETE이고 원문으로 복구하지 않는다. 전체 입력 한도를 넘으면 잘라내지 않고 실패한다. 비 mock 호출은 요청의 개인정보가 가려져 있지 않으면 전송 전에 거절한다.
이 경로는 텍스트 조립 실험이며 일반 생산자 흐름에 자동 적용되지 않는다. 보존된 unit의 수는 원자료 추출 recall·의미 정확도·검증된 전체 gold 점수가 아니다. offline literal control은 모델 개선 증거가 아니며 검토/실패 예시도 분모에 남긴다. 비공개 저장·명시 적용·생산자 수정 보호 계약은 변경하지 않는다.

모든 결과는 requiresContentReview=true, statusScope=ASSEMBLY_ACCOUNTING_ONLY를 포함한다. COMPLETE/EMPTY도 내용 승인·공개 가능 상태가 아니며 기존 안전 휴리스틱의 상품/서비스 구분 한계를 해결했다고 주장하지 않는다.


## 문장 구간 배치 실험
새 refine_passages 경로는 승인 후보를 보수적인 완결 문장 구간으로 나누고, 모델이 구간 ID의 배치/제외/검토만 정하게 한다. 모델은 문구·offset을 생성하지 않는다. 간혹·이번·표본·수량 등 맥락을 분리할 위험이 있으면 원 단위 전체를 묶는다. 원 단위가 검토 필요이면 구간도 KEEP할 수 없다. 안전한 구간의 추출 field hint는 배치 강제가 아니며 기존 텍스트 모듈 분류를 사용한다. 과거/공통 자료 범위 제약과 최종 안전 검증은 유지한다.
내부 원본 snapshot/offset/revision 해시는 유지하고 전송 시 중복 근거·모듈 목록만 공유한다. 전체 구간을 보존하며 실제 전송 한도를 넘으면 실패한다. 기존 v11 및 literal adapter·편집/저장/적용 계약은 바꾸지 않는다. 평가에서는 기존8개 예시와 별도 추출 복구2개를 합산하지 않고 실패·미실행도 남긴다. 원래5달러 누적한도 안에서 이번 고정한도1.50달러를 사용하며 불확실한 요청/비용은 예약 유지 후 중단한다.


부분 인적 검토는 실제 검토한 자료/출력 버전 및 답한 차원에만 연결한다. 문체 허용은 전역 수량 동치 규칙이 아니며, 빈 답변은 승인으로 보지 않는다. 텍스트 자연스러움/생산자 문체 의견은 사실 보존·근거·배치 평가와 별도 정성 기록으로 보관한다. 새 calibration 도구는 사람 판단과 선택적 judge 예측의 일치도를 작은 검토 부분집합에서만 보고하며, 미검토/판단 불가/실패/기권 분모를 드러낸다. 원본 gold를 자동 수정하거나 미검토 출력을 승인하지 않는다.


문체 실험은 실제 첫 검토의 네 v11 출력을 그대로 기준으로 별도 수행한다. 모듈·문장 단위·인용 관계를 고정하고, 생산자 문체와 자연스러운 문장 연결만 다듬는다. 원문 문체 예시는 스타일 근거이며 새 사실을 가져오는 허가가 아니다. 수치/옵션 연결·명시적 부정/조건/과거 맥락과 기존 최종 안전 검증을 유지하며 거절 문구를 원문으로 자동 복구하지 않는다. 별도 모델 critic의 PASS도 미보정 진단일 뿐 사람 승인이나 배포 승인이 아니다.
