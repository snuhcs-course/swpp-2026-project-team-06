# 판매페이지 템플릿 3종 — DEV-52

FEAT-03/04/07의 후속 디자인 검토 단계이며 현재 상품 편집/API 계약은 바꾸지 않는다.

생산자가 제공한 사진·문구를 산지 상점/산지 화보/농가 이야기로 배치한다. 같은 내용을 세 시안에서 비교하고 직접 고칠 수 있다. 원문 추출 AI와 판매 저장 연결은 후속 작업이다.

사진/농장/사람/상품정보는 생성하지 않는다. 없는 필드는 숨기거나 편집기에서 입력을 안내한다. 이미지 생성은 미리 제작한 추상 배경·장식으로 한정한다. 폰트는 상업 사용 및 웹 임베딩·재배포를 허용하는 라이선스만 사용한다.

기존 상세 이미지 저장을 대체하거나 자동 변환하지 않는다. 이 단계의 자료는 브라우저 메모리에서만 유지되고 상품으로 게시되지 않는다. 구현·검증 기준은 [작업실 명세](../design/sales-templates/spec.md)의 AC-TPL-1~7다.

명시적 예시 보기에서는 기존 가상 농가의 사진·문구를 불러오며 실판매 자료가 아님을 표시한다. 사용자 입력 대체·비우기는 확인을 거친다. Do Hyeon·Gowun Batang·Pretendard의 OFL을 동봉하며 정보 추출이나 생성 문구는 추가하지 않는다.

상품 표지 → 원산지·품종·중량 요약 → 원문 문단과 추가 사진을 교차한 설명 장면 → 입력한 구성 안내·농가 소식 → 입력한 포장·보관·배송 안내 순서다. 농가 이야기 시안은 표지 안에서 사진이 제목보다 먼저 나온다. 빈 줄로 나눈 원문과 두 번째 이후 사진을 순서대로 배치하며, 부족한 문구나 사진을 생성하지 않는다.

구성 안내와 농가 소식은 선택 입력이며 독립된 제목으로 구분한다. 사진은 이야기 문단, 구성, 소식 순서로 대응하고 소식 장면에서는 사진이 먼저 보인다. 구성 장면은 입력한 중량도 함께 표시한다. 120자를 넘는 문단은 17px 본문으로 읽히게 하며 원문을 줄이거나 늘리지 않는다. 데모는 기존 가상 농가 원문과 사진 6장을 사용하고 포장·보관·배송은 비워 둔다. 국내 상세 이미지 비교 범위와 한계는 작업 폴더 coupang-research.md에 기록한다.

## 상품 판단 정보 보강
상품 요약 다음에 맛·식감, 크기·편차, 품질 기록·인증, 수확·출하를 입력한 경우 표시한다. 하단 선택 정보는 구매 전 유의사항/문의·문제 접수, 포장/배송, 보관/먹는 방법으로 나눈다. 미입력 항목은 본문에서 숨기고 편집기의 추가 정보 목록에서 해당 입력란으로 이동할 수 있다. 입력 여부는 사실 검증이나 게시 가능 판정이 아니다. 기존 거래·환불 정책은 바꾸지 않는다. 데모는 scr-03/scr-04의 원문만 사용하며 없는 규격·당도·인증·날짜·보관법·정책은 생성하지 않는다. 근거는 작업 폴더 content-analysis.md에 기록한다.
