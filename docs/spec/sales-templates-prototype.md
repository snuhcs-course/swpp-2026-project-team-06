# 판매페이지 템플릿 3종 — DEV-52

FEAT-03/04/07의 후속 디자인 검토 단계이며 현재 상품 편집/API 계약은 바꾸지 않는다.

생산자가 제공한 사진·문구를 기본 상품형/매거진형/농가 편지형으로 배치한다. 같은 내용을 세 시안에서 비교하고 직접 고칠 수 있다. 원문 추출 AI와 판매 저장 연결은 후속 작업이다.

사진/농장/사람/상품정보는 생성하지 않는다. 없는 필드는 숨기거나 편집기에서 입력을 안내한다. 이미지 생성은 미리 제작한 추상 배경·장식으로 한정한다. 폰트는 상업 사용 및 웹 임베딩·재배포를 허용하는 라이선스만 사용한다.

기존 상세 이미지 저장을 대체하거나 자동 변환하지 않는다. 이 단계의 자료는 브라우저 메모리에서만 유지되고 상품으로 게시되지 않는다. 구현·검증 기준은 [작업실 명세](../design/sales-templates/spec.md)의 AC-TPL-1~5다.
