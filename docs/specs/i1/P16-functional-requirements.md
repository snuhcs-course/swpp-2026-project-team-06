# P16 기능 요구사항

> SWPP-20 · 상태: 초안 · 기준: P14, P15
> 형식: **사용자 → 행동 → 결과**. 우선순위는 Must / Should / Won't(I1). 화면 ID는 P15 기준.

## 1. 계정·프로필 (AUTH)
| ID | 요구사항 | 화면 | 우선순위 |
| -- | -- | -- | -- |
| AUTH-1 | 사용자 → 이메일·비밀번호·이름으로 가입 → 계정이 만들어지고 역할 선택으로 이동 | S-03, S-04 | Must |
| AUTH-2 | 사용자 → 로그인 → 역할에 맞는 홈(C-01/P-01)으로 이동, 앱 재실행 시 로그인 유지 | S-02 | Must |
| AUTH-3 | 사용자 → 역할(소비자/생산자) 선택 → 역할 확정 (I1에서는 변경 불가) | S-04 | Must |
| AUTH-4 | 생산자 → 농가명·지역·소개·대표 사진·주요 품목 입력 → 농가 프로필 생성, 농가 목록에 노출 | S-05, P-52 | Must |
| AUTH-5 | 소비자 → 배송지(이름·연락처·주소) 등록·수정 → 주문서에서 기본 배송지로 사용 | C-52 | Must |
| AUTH-6 | 사용자 → 로그아웃 → 로그인 화면 | C-51, P-51 | Must |

## 2. 농가 탐색·팔로우 (FARM)
| ID | 요구사항 | 화면 | 우선순위 |
| -- | -- | -- | -- |
| FARM-1 | 소비자 → 농가 목록 진입 → 판매 중 상품이 있는 농가 우선으로 목록 표시(대표 사진·농가명·지역·최근 당도) | C-11 | Must |
| FARM-2 | 소비자 → 농가 선택 → 소개, 판매 상품, 팔로워 수, 최근 메시지 1건 표시 | C-12 | Must |
| FARM-3 | 소비자 → 팔로우/언팔로우 → 메시지방 목록에 추가/제거, 팔로워 수 갱신 | C-12 | Must |

## 3. AI 상품 등록 (REG)
| ID | 요구사항 | 화면 | 우선순위 |
| -- | -- | -- | -- |
| REG-1 | 생산자 → 기존 판매글(네이버 카페·카톡·밴드 등) 텍스트 붙여넣기 → AI가 상품 초안 생성: 상품명, 품종, 설명, 중량 옵션(중량·기존 가격), 목표 당도, 크기·등급, 수확 시기, 발송 시기, 보관 방법 | P-12, P-13 | Must |
| REG-2 | 생산자 → 사진 첨부(선택, 최대 5장) → 초안 대표 이미지로 사용 | P-12 | Must (최소 1장 업로드, 다중은 Should) |
| REG-3 | AI가 찾지 못한 필수 항목 → 초안에서 "확인 필요"로 표시, 비어 있으면 검토 요청 불가 | P-13 | Must |
| REG-4 | 생산자 → 초안 수정, 옵션별 **공급 가능 수량** 입력 → 저장(초안 상태 유지) | P-13 | Must |
| REG-5 | 생산자 → 검토 요청 → 상태 "검토 중", 운영자 검토 목록에 표시 | P-13, A-01 | Must |
| REG-6 | 생산자 → 내 상품 목록에서 상태·반려 사유 확인 → 반려 시 초안 편집으로 재진입 | P-11 | Must |
| REG-7 | AI 추출 실패(타임아웃·형식 오류) → 빈 초안 + "직접 입력" 안내, 원문은 보존 | P-13 | Must |
| REG-8 | 사진 속 전단지 글자 인식(OCR) → 초안 생성 | P-12 | Won't |

## 4. 판매 단계·게시 (ADM)
| ID | 요구사항 | 화면 | 우선순위 |
| -- | -- | -- | -- |
| ADM-1 | 운영자 → 검토 요청 상품 목록 확인 → 상품 상세·원문·AI 초안 열람 | A-01, A-02 | Must |
| ADM-2 | 운영자 → 판매 단계(이름·시작·종료일)와 옵션별 단계 가격 입력 → 저장 (P17 단계 규칙 검증) | A-02 | Must |
| ADM-3 | 운영자 → 배송 예정 기간·최대 지연 기한 확정 → 게시 → 상품 "판매 중", 소비자에게 노출 | A-02 | Must |
| ADM-4 | 운영자 → 반려(사유 입력) → 상품 "초안", 생산자에게 알림 | A-02 | Must |
| ADM-5 | 운영자 → 주문 상태 강제 변경(흉작·지연 초과 환불) → 소비자·생산자 알림 | A-03 | Must |

## 5. 버블형 메시지 (MSG)
| ID | 요구사항 | 화면 | 우선순위 |
| -- | -- | -- | -- |
| MSG-1 | 생산자 → 메시지 작성(텍스트 필수, 당도 수치 선택) → 모든 팔로워의 메시지방에 동시 표시 | P-31 | Must |
| MSG-1a | 메시지에 사진 1장 첨부 | P-31 | Should |
| MSG-2 | 소비자 → 메시지방 진입 → 농부 메시지와 **내 답장만** 시간순으로 표시 (다른 소비자 답장은 보이지 않음, 1:1 대화처럼) | C-31 | Must |
| MSG-3 | 소비자 → 답장 입력 → 내 메시지방에 표시, 생산자 문의함에 도착 | C-31, P-32 | Must |
| MSG-4 | 소비자 → 메시지방 목록 → 팔로우 농가별 최근 메시지·안 읽은 수 표시 | C-30 | Must |
| MSG-5 | 생산자 → 문의함 → 소비자별 답장 목록, 직접 답변 → 해당 소비자 메시지방에만 표시 | P-32, P-33 | Must |
| MSG-6 | 당도가 입력된 메시지 → 상품 상세·농가 목록의 "최근 당도"로 반영 | C-11, C-21 | Must |
| MSG-7 | 메시지에 상품 카드 첨부 → 탭하면 상품 상세 | P-31, C-31 | Should |
| MSG-8 | 실시간 수신(웹소켓) | — | Won't (I1은 진입·당겨서 새로고침 시 갱신) |

## 6. AI 문의 응대 (AI) — Should
| ID | 요구사항 | 화면 | 우선순위 |
| -- | -- | -- | -- |
| AI-1 | 소비자 답장 도착 → AI가 상품 정보·최근 메시지·배송 일정만 근거로 답변 가능 여부 판단 → 가능하면 "AI 답변" 표시와 함께 메시지방에 답변 | C-31 | Should |
| AI-2 | 답변 불가·정책 판단 필요(가격 조정, 환불, 일정 변경, 근거 없음) → 답하지 않고 "농부님께 전달했어요" 표시, 문의함에 "확인 필요"로 분류 | C-31, P-32 | Should |
| AI-3 | 생산자 → 문의함에서 AI 답변 내역 확인, 필요 시 추가 답변 | P-32, P-33 | Should |
| AI-4 | AI 오류·타임아웃 → "확인 필요"로 분류(답장 유실 없음) | — | Should |

## 7. 상품·주문 (ORD)
| ID | 요구사항 | 화면 | 우선순위 |
| -- | -- | -- | -- |
| ORD-1 | 소비자 → 홈·농가 프로필에서 판매 중 상품 확인 → 현재 단계 가격, 다음 단계 가격·전환일, 남은 수량 표시 | C-01, C-12 | Must |
| ORD-2 | 소비자 → 상품 상세 → 품질 기준(목표 당도·등급), 최근 측정 당도, 단계별 가격 타임라인, 배송 예정 기간, 최대 지연 기한, 상품정보(원산지 등) 표시 | C-21 | Must |
| ORD-3 | 소비자 → 옵션·수량 선택 → 남은 수량 초과 시 선택 불가 | C-22 | Must |
| ORD-4 | 소비자 → 주문서에서 배송지 확인, **사전 동의 4항목** 체크 → 모두 체크해야 결제 버튼 활성 | C-23 | Must |
| ORD-5 | 소비자 → Mock 결제 → 주문 시점 단계 가격으로 금액 확정, 주문 "예약 완료", 재고 차감 | C-24, C-25 | Must |
| ORD-6 | 소비자 → 내 주문 → 상태 타임라인(예약 완료 → 출하 준비 → 발송 → 배송 완료), 송장번호 표시 | C-41, C-42 | Must |
| ORD-7 | 소비자 → 발송 전 취소 → 주문 "취소·환불", 재고 복구 | C-42 | Must |
| ORD-8 | 생산자 → 대시보드 → 상품·옵션별 주문 수량 / 공급 수량 집계 | P-01 | Should (Must 대체: 주문 목록 상단 합계) |
| ORD-9 | 생산자 → 주문 목록 → 상태 변경(출하 준비 → 발송[송장번호] → 배송 완료) → 소비자 알림 | P-41, P-42 | Must |
| ORD-10 | 단계 종료일 도래 → 다음 단계 가격 자동 적용, 마지막 단계 종료 또는 전 옵션 품절 → 상품 "판매 마감" | — | Must |
| ORD-11 | 최대 지연 기한까지 배송 완료가 아닌 주문 → 운영자 목록에 표시 (자동 환불은 I2) | A-03 | Should |
| ORD-12 | 실결제(PG)·정산 | — | Won't |

## 9. 비기능 요구사항
| ID | 요구사항 |
| -- | -- |
| NFR-1 | AI 상품 초안은 20초 안에 반환, 초과 시 REG-7 처리 |
| NFR-2 | AI 초안 추출 정확도: 베타 판매글 5개 기준 필수 필드 80% 이상 정확 (사람 검수 기준) |
| NFR-3 | 40~50대 사용성: 본문 16sp 이상, 주요 버튼 48dp 이상, 한 화면 한 가지 주 행동 |
| NFR-4 | 대상 기기 Galaxy S23 (Android 14), 최소 Android 10 |
| NFR-5 | 개인정보: 소비자 연락처·주소는 주문한 상품의 생산자에게만, 출하 처리 목적으로만 노출 |
| NFR-6 | AI 응답에는 항상 "AI" 라벨, AI 입력·출력 로그 저장 (품질 평가용) |
| NFR-7 | 금액은 서버에서 계산 (클라이언트 값 신뢰 안 함), 재고 차감은 트랜잭션으로 초과 판매 방지 |

## 10. P13 판정과의 정합성 확인
| P13 결론 | 관련 요구사항 | 충돌 |
| -- | -- | -- |
| 당도가 최우선 | MSG-1·MSG-6·ORD-2 | 없음 |
| 품질 불확실성이 장벽 | ORD-2(품질 기준·측정 당도) | 없음 |
| 일반 온라인가 초과 불가 | ADM-2 + P17 가격 규칙 | 없음 |
| 대기 짧을수록 좋음 | ORD-2(배송 예정·최대 지연) | 없음 |
| 생산자 사진 부담 | REG-2·MSG-1 사진 선택 항목 | 없음 |
