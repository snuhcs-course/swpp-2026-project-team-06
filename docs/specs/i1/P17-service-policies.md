# P17 서비스 정책

> SWPP-21 · 상태: 초안 · 기준: P14, P16, 운영 구조 제안(10/04)
> 이 문서는 **제품이 따를 규칙**만 다룬다. 실제 약관 문구는 오픈 전 별도 검토한다.
> I1은 Mock 결제이므로 "환불"은 주문 상태 변경으로만 구현한다.

## 1. 역할
| 역할 | 할 수 있는 것 | 할 수 없는 것 |
| -- | -- | -- |
| 소비자 | 팔로우, 메시지방 답장, 예약구매·취소, 배송지 관리 | 다른 소비자 답장 보기, 상품 등록 |
| 생산자 | 농가 프로필, 상품 초안·검토 요청, 팔로워 메시지 발송, 문의 답변, 출하 처리 | **판매가 설정**, 상품 직접 게시, 소비자 연락처를 출하 외 목적으로 사용 |
| 운영자 | 상품 검토·게시·반려, 판매 단계·가격 설정, 주문 상태 강제 변경, 콘텐츠 숨김 | — |

- 한 계정은 한 역할 (I1). 생산자 계정 하나에 농가 하나.

## 2. 판매 주체와 가격
- 소비자에게 판매하는 주체는 **플랫폼(farmclub)** 이고, 생산자는 공급자다. 소비자 화면에는 농가가 "생산자"로, 플랫폼이 "판매자"로 표시된다.
- **판매 단계 일정과 단계별 판매가는 플랫폼이 정하고, 공급 수량은 생산자가 정한다.**
- 생산자가 판매글에 적은 가격(AI가 추출한 "기존 가격")은 운영자가 단계 가격을 정할 때 참고값으로만 쓴다.

### 2.1 판매 단계 규칙
| 규칙 | 내용 |
| -- | -- |
| 단계 수 | 상품당 1~3단계. 기본값 3단계: **얼리버드 → 예약 → 수확 임박** |
| 기간 | 단계는 겹치지 않고 이어진다. 마지막 단계 종료일 ≤ 배송 예정 시작일 |
| 가격 | 뒤 단계 가격 ≥ 앞 단계 가격 (이른 단계일수록 저렴). 마지막 단계 가격은 일반 온라인 판매가 수준을 넘지 않는다 |
| 적용 | 소비자가 결제한 시점의 단계 가격으로 확정. 이후 단계가 바뀌어도 주문 금액은 변하지 않는다 |
| 표시 | 상품 상세에 전체 단계 타임라인, 현재 단계, 다음 단계 가격·전환일 표시 |
| 변경 | 게시 후 단계 가격·일정 변경 불가 (I1). 필요 시 마감 후 새 상품으로 |

## 3. 상품 등록
- **필수 항목**: 상품명, 품종(모르면 "감귤"), 설명, 중량 옵션 1개 이상(중량·공급 수량), 품질 기준(목표 당도 Brix, 크기·등급), 수확 예정 시기, 배송 예정 기간, 보관 방법, 원산지.
- AI 초안은 **생산자가 확인·수정한 뒤에만** 검토 요청할 수 있다. 화면에 "AI가 작성한 초안입니다. 사실과 다른 내용이 없는지 확인해 주세요"를 표시한다.
- 옵션은 중량 기준(예: 3kg / 5kg / 10kg). 비규격 상품 옵션은 I1에서 받지 않는다.
- 사진은 본인 농가·작물 사진만 올린다.

### 3.1 상품 상태
```
초안 ──검토 요청──▶ 검토 중 ──게시──▶ 판매 중 ──마감──▶ 판매 마감 ──전 주문 종결──▶ 완료
  ▲                   │
  └─────반려(사유)────┘
```
- 판매 마감: 마지막 단계 종료, 전 옵션 품절, 운영자 수동 마감 중 하나.

## 4. 주문·결제
- 주문 시 **전액 결제** (예약금·잔금 분할 없음). I1은 Mock 결제로 "결제 완료"만 재현한다.
- 한 주문 = 한 상품의 한 옵션 × 수량. 장바구니 없음 (I1).
- 재고 = 옵션별 공급 수량. 결제 시점에 재고를 차감하고, 남은 수량을 넘는 주문은 받지 않는다.
- 적립금·포인트·충전금·상품권 기능은 두지 않는다. 환불은 결제 취소로만 한다.

### 4.1 결제 전 사전 동의 (4항목, 모두 필수)
1. 배송 예정 기간 (예: 2027년 1월 중순~하순)
2. 최대 지연 기한과, 기한을 넘기면 자동 전액 환불
3. 흉작·수량 부족 시 처리 (수량 비례 배분 + 부족분 환불)
4. 취소 조건 (발송 전 전액 환불, 발송 후 신선식품 기준)

동의 시각과 항목 문구 버전을 주문에 저장한다.

### 4.2 주문 상태
```
예약 완료 ──▶ 출하 준비 ──▶ 발송 ──▶ 배송 완료
    │             │
    └──취소·환불──┘ (소비자: 발송 전 / 운영자: 흉작·지연)
```
| 상태 | 바꾸는 주체 | 소비자 알림 |
| -- | -- | -- |
| 예약 완료 | 결제 완료 시 자동 | O |
| 출하 준비 | 생산자 | O |
| 발송 | 생산자 (송장번호 필수) | O |
| 배송 완료 | 생산자 또는 운영자 | O |
| 취소·환불 | 소비자(발송 전), 운영자 | O |

- 상태가 바뀔 때마다 소비자에게 알림을 보낸다 (장기 예약배송에서 "잊힌 주문"을 막는다).

## 5. 취소·환불·흉작
| 시점·상황 | 처리 |
| -- | -- |
| 발송 전 | 소비자가 앱에서 직접 취소 → 전액 환불, 재고 복구 |
| 발송 후 | 신선식품 기준: 하자(부패·파손·현저한 품질 미달) 시 수령 후 7일 내 사진과 함께 신고 → 환불·교환 (I1은 운영자 수동 처리) |
| 흉작·수량 부족 | 확보 수량을 주문 순서와 무관하게 **수량 비례 배분**, 부족분 즉시 환불 (I1은 운영자 수동) |
| 최대 지연 기한 초과 | 전액 환불 (I1은 운영자 목록에 표시 후 수동 처리) |
| 환불 처리 기한 | 3영업일 이내 |

## 6. 소통 정책 (버블형 메시지)
- **농부 → 팔로워**: 생산자가 보낸 메시지는 그 농가를 팔로우한 모든 소비자의 메시지방에 표시된다.
- **소비자 → 농부**: 소비자 답장은 해당 생산자(와 AI)에게만 보인다. 소비자끼리는 서로의 답장을 볼 수 없다.
- 생산자 답변은 답장한 소비자의 메시지방에만 표시된다.
- 소비자는 닉네임(이름)으로 표시되고, 생산자는 소비자 연락처를 메시지에서 볼 수 없다.
- 메시지에 외부 연락처·계좌·외부 판매 링크를 쓰거나 플랫폼 밖 직거래를 유도하지 않는다 (운영자 숨김 대상).
- 팔로우를 끊으면 메시지방이 목록에서 사라지고, 다시 팔로우하면 이전 대화가 보인다.

### 6.1 AI 응답 원칙 (Should)
- AI는 **상품 정보, 그 농가의 최근 메시지, 판매·배송 일정**만 근거로 답한다. 근거가 없으면 추측하지 않는다.
- 답할 수 있는 것: 배송 예정 시기, 보관 방법, 현재 생육·당도 소식, 옵션·가격 안내, 주문 상태 안내.
- **답하지 않고 생산자에게 넘기는 것**: 가격 할인·흥정, 환불·교환 판단, 배송 일정 변경 약속, 농법·인증 등 근거 없는 사실, 불만·항의, 개인적 대화.
- AI 답변에는 항상 "AI 답변" 라벨을 붙이고, 넘긴 경우 "농부님께 전달했어요"를 표시한다.
- AI는 농부를 사칭하지 않는다 (1인칭 "제가 키운"을 쓰지 않음).

## 7. 콘텐츠 정책
- 메시지·상품 사진·설명은 사실이어야 한다. 측정하지 않은 당도를 쓰지 않는다.
- 금지: 허위·과장(효능·질병 치료 표현 등), 타인 사진 도용, 욕설·비방, 개인정보 노출, 외부 거래 유도.
- 운영자는 위반 콘텐츠를 숨길 수 있고, 숨긴 메시지는 소비자에게 "운영 정책에 따라 숨겨진 메시지"로 표시된다.
- I1에서는 신고 기능·AI 필터 없이 운영자가 수동으로 처리한다.

## 8. 개인정보
- 수집 항목: 이메일, 이름, 배송지(이름·연락처·주소). 가입·주문 시 수집 목적을 고지한다.
- 생산자는 **자기 상품을 주문한 소비자의 배송 정보만**, 출하 화면에서만 본다 (생산자 직접 배송 = 처리위탁으로 고지).
- AI에 보내는 데이터에서 연락처·주소는 제외한다.

## 9. 알림
- 앱 내 알림 목록이 기본 (I1). 대상: 주문 상태 변경, 새 농부 메시지, 문의 답변, 상품 게시·반려, 문의 전달(생산자).
