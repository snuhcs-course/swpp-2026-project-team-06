- 11/23 내용 구성 보드 PM 승인("추천대로"): 어긋남 표 15개, 설계 결정 6개, 흐름도 10칸·갈림길 메모 3개, 목차 14절, 검사 키 12개. 구현한 페이지는 0절(한눈에) + 1~14절 + 15절(알려진 한계, PM 품질 기준으로 추가) = 16절이고 목차도 16개.
- 11/23 원본은 빌드 없는 정적 HTML `docs/guide/index.html` 한 파일. 규칙은 링크로 가리키고 값만 `data-agents`로 표시.
- 11/23 검사 자리는 처음에 `changes` job의 단계였지만, 실패하면 Classify가 비어 server·apps·integration이 모두 건너뛰어지는 문제가 있어(독립 검토) 별도 job `guide`로 뺐다. `ci-ok`의 needs에 넣어 PR·머지 큐에서는 막고, main push에서는 단계 `continue-on-error`로 경고만 남겨 배포(workflow_run 성공 조건)를 멈추지 않는다. 새 필수 체크는 만들지 않는다.
- 11/23 키 `sections`는 요소 표시 대신 페이지의 저장소 링크(`…/blob|tree/main/<경로>#<제목>`) 전부를 본다: 파일이 있는지, 앵커가 그 파일의 제목(GitHub 앵커 규칙)과 맞는지. AGENTS.md 밖(README·CI.md·스킬)의 가리킴도 함께 잡는다.
- 11/23 자주 바뀌는 숫자(ADR 범위, 워크플로 개수, CI 시간)는 페이지에 쓰지 않고 링크로 둔다. 고위험 경로 수와 작업 단계 수는 검사 대상이라 쓴다.
- 11/23 "어디에 무엇이 있나"의 일정 시트·GitHub Projects 줄은 평가용이라 남긴다(PM).
- 11/23 ruleset 필수 승인 수 0은 "GitHub 설정은 승인을 강제하지 않고, 사람 리뷰는 AGENTS.md 규칙으로 지켜요"로 적는다(PM).
- 11/23 새 주소 `https://snuhcs-course.github.io/swpp-2026-project-team-06/guide/`. 옛 `farmclub-guide.vercel.app`은 308 리다이렉트 뒤 한 이터레이션 지나 삭제(사람).
- 11/23 PM 품질 기준 추가("AI 전문가와 시니어 개발자가 봐도 수준이 떨어져 보이면 안 된다"): 절마다 규칙이 생긴 이유와 막는 실패를 먼저 적고, 근거는 저장소에 있는 이슈 파일·ADR만 쓴다(SWPP-119·126·130·115, ADR 0014·DEV-219, DEV-139, DEV-234, DEV-74·88, DEV-196). 5절에 에이전트가 읽는 순서·경계·통제의 층(강제 여부 포함)을 넣고, 15절 "알려진 한계"를 새로 둔다.
- 11/23 검사 스크립트는 키 → 절·방식(text·set·count) 선언 표 하나로 두고, 절을 못 찾거나 절에서 값을 못 뽑거나 선언한 방식의 요소가 페이지에 없으면 실패한다(조용히 통과하지 않음). 테스트는 키·방식마다 실패 경우를 자동으로 만든다.
- 11/23 이름 규칙의 예시는 실제 저장소 기록(DEV-434의 브랜치·커밋·PR 제목)을 쓴다.
- 11/23 독립 검토 두 건(시니어 개발자, AI 에이전트 운영) 반영:
  - 검사: text도 부분 문자열이 아니라 절에서 뽑은 값과 같은지 비교, 빈 값·주석·hidden·<template>·작은따옴표·겹친 태그·비표준 저장소 링크·잘못된 URL 인코딩을 실패로, 목록 `<li>` 수도 count와 대조, 링크 검사를 KEYS 밖으로 분리, 코드 펜스·중복 제목 앵커 처리, Actions 어노테이션. 테스트는 실제 파일 대신 fixture.
  - 페이지 사실 정정: SWPP 이슈의 연동, spec-check 트리거·SKIPPED·environment 보호 규칙 없음, Agent 시간 어림 규칙, 이슈 파일에 기대는 층의 공통 약점, 머지 큐가 고른 검사만 돈다는 것, ruleset이 막는 것(직접 push·force push).
  - 15절 한계 보강: 자기 리뷰, 리뷰 뒤 push, 고위험 밖의 검사 코드, spec-check 정확도 미측정·같은 계열 모델, 에이전트 권한, 비밀값 검사 없음, 프롬프트 주입, hotfix 라벨.
  - 캡처는 전체 페이지 PNG(약 9MB) 대신 뷰포트 JPEG 12장(합 약 0.98MB), 그 커밋을 고쳐 써서 히스토리에 남기지 않음.
