# 당도계 설명용 일러스트

2026-10-17 사용자 요청으로 내장 `image_gen`을 사용해 생성했다. 기존 outline-medium.png를 시각적으로 검토해 선·종이 질감·색감의 스타일을 맞췄다. 생성 PNG를 재가공 없이 복사하고 투명 알파를 보존했다. 실제 기기 사진/측정 증빙이 아닌 설명용 장식이며, LCD에는 수치를 넣지 않았다. 실측값이 있을 때만 앱에 표시하고 숫자·측정일은 API 값으로 따로 렌더한다.
