### 결정 사항
- 11/04 PM 결정: 확인 시트 없음(FEAT-06 4 "확인 없이" 유지). 토스트 누락은 버그(screens.md 토스트 쓰는 곳 '팔로우 해제', design README 팔로우 토글).
- 11/04 PM 결정: 해제해도 내 답장은 흐리게 남김, 팔로워 전용 방송은 숨김, 상단 띠 + 잠긴 입력, 다시 팔로우하면 그대로. 채팅 목록 흐린 줄이 기본, '숨기기'는 선택.
- 11/04 확인: 서버는 지금 해제한 소비자에게 내 답장을 주지 않는다(`server/app/messaging/service.py` `_room_rows` `replies.where(false())`), 채팅 목록 `rooms()`도 팔로우한 농가만 → 서버 변경 필요. 새 응답 필드는 없음(기존 `canReply`로 판정). 답장 행은 해제 때 지우지 않아 재팔로우 복원은 서버 변경 없음.
- 11/04 제안: '예전 팔로워' 판정은 "이 방에 내 답장이 있음"(새 필드 없음). 되돌리기 토스트는 4초. 다시 팔로우에는 토스트 없음. '팔로잉'에 체크 아이콘(README 기존 규칙).

- 11/05 PM 결정: 채팅 목록에서 끊은 농가는 보이지 않는다(묶음·흐린 줄·숨기기·기기 저장 없음, 무브 5 삭제, `rooms()` 변경 없음). 나머지는 제안대로 — 즉시 해제 + ‘팔로우를 끊었어요 · 되돌리기’(4초 예외), 농가 페이지 소식방에서 내 답장 45%·전용 소식 숨김·띠(버튼 유지)·잠긴 입력·‘✓ 팔로잉’·재팔로우 복원. 헤더 ‘팔로우’는 해제 상태(예전 팔로워)에서 테두리로 낮춤. 숨긴 전용 소식 자리에 빈 줄 없음. 답장 없이 끊은 사람은 처음 온 사람과 같은 화면.
- 11/05 AC ID: 새 AC-06-8(해제·되돌리기·재팔로우 복원·목록), AC-15-8(해제한 소비자는 본인 답장만, 전용 소식·타인 답장 안 보임, 답장 403). 기존 `test_AC_12_10_unfollow_hides_private_messages_and_blocks_reply`의 기대값을 새 규칙(`["n-2", "reply-2"]`)으로 바꿨다 — 전용 소식 숨김·403 검사는 그대로.
- 11/05 헤더는 기존 공용 `FollowButton`(체크 + 팔로잉, D-01)으로 바꿨다. RN-web에서 `flex: 0`만 주면 `flexBasis: 0%`가 남아 폭이 무시돼 `flexGrow/flexShrink 0 + flexBasis auto + width 104`로 둔다.
