소식방 헤더 '팔로잉'을 한 번 누르면 토스트 없이 해제되고, 팔로워 전용 소식과 내 답장이 함께 사라진다(평가자: "팔로우에 불이 들어오면 오히려 소식방에서 빠진다", 심각도 3). PM 결정(11/04): 확인 시트는 두지 않는다. 해제는 바로 되고, 토스트 '팔로우를 끊었어요 · 되돌리기'로 알리며, 소식방을 비우지 않고 내 답장은 흐리게 남기고, 다시 팔로우하면 그대로 돌아온다.

### 결정 사항
- 11/04 PM 결정: 확인 시트 없음(FEAT-06 4 "확인 없이" 유지). 토스트 누락은 버그(screens.md 토스트 쓰는 곳 '팔로우 해제', design README 팔로우 토글).
- 11/04 PM 결정: 해제해도 내 답장은 흐리게 남김, 팔로워 전용 방송은 숨김, 상단 띠 + 잠긴 입력, 다시 팔로우하면 그대로. 채팅 목록 흐린 줄이 기본, '숨기기'는 선택.
- 11/04 확인: 서버는 지금 해제한 소비자에게 내 답장을 주지 않는다(`server/app/messaging/service.py` `_room_rows` `replies.where(false())`), 채팅 목록 `rooms()`도 팔로우한 농가만 → 서버 변경 필요. 새 응답 필드는 없음(기존 `canReply`로 판정). 답장 행은 해제 때 지우지 않아 재팔로우 복원은 서버 변경 없음.
- 11/04 제안: '예전 팔로워' 판정은 "이 방에 내 답장이 있음"(새 필드 없음). 되돌리기 토스트는 4초. 다시 팔로우에는 토스트 없음. '팔로잉'에 체크 아이콘(README 기존 규칙).
