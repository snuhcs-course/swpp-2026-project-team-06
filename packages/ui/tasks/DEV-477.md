## DEV-477 앱에서 막히는 작은 곳 정리: 키보드에 가리는 시트

- 이슈: [DEV-477](https://linear.app/sswp6/issue/DEV-477) · GitHub #834
- 브랜치: `nemodleo/dev-477-unblock-small-native-gaps`
- 기능·인수 조건: SCR-29 송장 입력 시트, SCR-24 판매 조건 시트, 메시지 수정 시트
- 상태: 리뷰 중

### 목표
앱(iOS·Android)에서 `Sheet` 안 입력칸과 저장 버튼이 키보드에 가리지 않게 한다. 전체 기록은 `apps/producer/tasks/DEV-477.md`.

### 범위 (수정 허용 경로)
- `packages/ui/src/bars.tsx` (`Sheet`), `packages/ui/src/keyboard.tsx`(주석), `packages/ui/spec.md`

### 비범위 (건드리지 않음)
- `ChatThread.tsx`, `NewsRoom.tsx`(다른 이슈), Modal을 직접 쓰는 다른 부품, app.json

### 결정 사항
- 11/24 루트 `KeyboardRoot`는 Modal 창에 닿지 않는다. `Sheet`가 Modal 안을 `KeyboardRoot`로 감싼다. Android 15+ edge-to-edge에서는 RN Modal 창도 edge-to-edge라 adjustResize가 줄이지 않으므로 루트와 같은 `padding` 방식을 쓴다.
- 11/24 앱에서만 시트 `flexShrink: 1`, 겉 여백 위 `safe("top", 16)`. ScrollView `keyboardShouldPersistTaps="handled"`. 웹은 감싸지 않음.

- [x] Android 에뮬레이터 확인: Modal 위 키보드에서도 `keyboardDidShow`가 와서 `KeyboardRoot` 패딩이 들어감(송장 입력·판매 조건·메시지 수정), 첫 탭 저장 됨, 입력칸 없는 시트(나가기 확인·신청 내용·옵션과 수량) 모양 그대로
