## DEV-325 Make the product page load faster around the Brix section

- 이슈: [DEV-325](https://linear.app/sswp6/issue/DEV-325)
- 브랜치: `jangjinuite/dev-325-lighter-product-page-assets`
- 기능·인수 조건: AC-07-2(당도 표시), AC-SRC-7/9·AC-TPL-4/5/10(상세 장식), AC-06-6·AC-01-6·AC-14-4(로고) — 화면·동작은 바꾸지 않는다
- 상태: 진행 중

### 목표
생산자 피드백(11/15) "당도 부분에서 페이지 로딩이 버벅인다". 상품 상세의 당도 구역은 1254px PNG 두 장(당도계 1.14MB, 주황 배경 1.25MB)을 한꺼번에 받고 디코딩한다. 소제목 아이콘(36px 표시)·손 일러스트·사진 테두리·로고도 원본 PNG(0.8~1.8MB)를 그대로 받는다. 표시 크기에 맞춘 WebP 사본으로 바꿔 받는 양을 줄이고, 보이는 모습은 그대로 둔다.

### 범위 (수정 허용 경로)
- `packages/ui/tasks/DEV-325.md`
- `packages/ui/src/{BrixReading,IllustrationBackdrop,ModuleStory,BrandLogo}.tsx` — `require` 경로만
- `packages/ui/src/SourcePhoto.tsx` — 테두리 `require` 경로 한 줄만(사진 대체 로직은 다른 PR이 고친다)
- `packages/ui/assets/source/**/*.display.webp`, `packages/ui/assets/brand/*.display.webp` (새 파일)
- `packages/ui/assets/source/README.md`, `packages/ui/assets/brand/README.md`, `packages/ui/spec.md`

### 비범위 (건드리지 않음)
- 원본 PNG(출처 보존. 로고 원본은 spec.md DEV-85 절에 따라 변형 금지) — 그대로 두고 사본만 더한다
- `packages/ui/src/content.tsx` `Photo`, `SourcePhoto.tsx` 사진 대체 로직(다른 PR)
- 앱 코드에서 쓰지 않는 `source/icons/*.png`(e2e 업로드 파일로만 쓰임), `brand/logo-horizontal.png`
- 앱 아이콘·파비콘(`apps/*/assets`)

### 결정 사항
- 11/15 사본 크기 = 코드에서 가장 크게 그리는 크기 × 3(최대 3배 화면 밀도), 원본보다 크면 원본 크기. WebP `cwebp -q 82 -alpha_q 90`(알파 유지), 축소는 `cwebp -resize`.
- 11/15 파일 이름은 `<원본 이름>.display.webp`. 원본 옆에 두어 어느 원본에서 만들었는지 바로 보이게 한다. e2e가 테두리 주소에 `photo-frame`이 들어 있는지 보므로 이름 앞부분은 유지한다.
- 11/15 사진 테두리는 CSS `border-image`의 9% 9-slice라 비율을 바꾸지 않는다(정사각형 그대로).
