### 결정 사항
- 11/26 PM(Zahra): 사업 운영 전 테스트 단계라 7일 사전 고지 없이 배포일(2026-11-27)에 바로 시행. 처리 근거(계약 이행)·동의 항목은 그대로라 동의 버전(2026-11-20)은 올리지 않는다.
- 앱은 세션 녹화를 하지 않는다. 키는 EAS `production` 환경에만 넣어 테스트 빌드는 보내지 않는다.
- 앱에는 끄는 설정이 없어 처리방침에 "원하지 않으면 웹 화면 이용"을 거부 방법으로 적는다.
- 11/27 고침(PM Zahra): 원스토어 앱이 `internal` 프로필 APK(preview 채널, 소비자 v12·농가 v9, 현 확인)라 production 업데이트가 닿지 않는다. 키를 `preview` 환경에도 넣고 `eas update --channel preview`로 켠다. 처리방침 제6조의 "미리보기·테스트 빌드에서는 보내지 않음"을 "앱 마켓(원스토어 등)에 배포한 앱, 팀 테스트 기기 기록도 가지만 테스트 계정 기록은 분석에서 뺌"으로 고친다. 같은 날 고침이라 제14조 변경 기록·시행일은 그대로 둔다. 스토어 앱을 production 프로필 빌드로 바꾸면 `preview` 키를 지운다.
