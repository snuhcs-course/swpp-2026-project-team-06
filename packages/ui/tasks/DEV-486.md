## DEV-486 판매 조건 시트 예약 기간 블록 정리 — 공용 UI

- 이슈: [DEV-486](https://linear.app/sswp6/issue/DEV-486) · 본 작업 기록: `apps/producer/tasks/DEV-486.md`
- 브랜치: `jangjinuite/dev-486-tidy-sale-periods`
- 기능·인수 조건: FEAT-05 화면(동작 변경 없음)

### 목표
생산자 판매 조건 시트에서 토스트를 시트 위에 보이고, 기간 삭제를 휴지통 아이콘으로 바꾸는 데 필요한 공용 부품만 더한다.

### 범위 (수정 허용 경로)
- `packages/ui/src/bars.tsx`(`Sheet` `overlay`), `packages/ui/src/Icon.tsx`(`trash`)
- `packages/ui/spec.md`, `packages/ui/tasks/DEV-486.md`

### 비범위
다른 시트·토스트 동작(`overlay`를 넘기지 않으면 그대로).

### 결정 사항
- `Sheet`(RN Modal) 안에서는 앱 루트 `Toast`가 시트 뒤에 그려져 보이지 않는다. 시트 상자 밖, Modal 안 바탕 위에 겹쳐 그리는 `overlay` 자리를 둔다. iOS 화면 읽기는 `accessibilityViewIsModal` 상자 밖 형제를 건너뛸 수 있어 부르는 쪽이 iOS에서 같은 문구를 읽어 준다(생산자 composer).
- `trash`는 24px 선 1.75, 뚜껑·몸통·세로 두 줄.

### 완료 조건
- [x] `overlay`를 넘기지 않는 시트는 그대로
- [x] typecheck·생산자 e2e(판매 조건 시트 토스트) 통과
