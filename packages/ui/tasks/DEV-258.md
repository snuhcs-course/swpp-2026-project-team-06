### 결정 사항
- 11/08 박현 승인 D안: 상품명(H1) 바로 아래 둘째 줄 「원산지 <농가 입력값>」, `title` 28/36, 굵기 400, 색 #111111(상품명과 같음), 사이 4. 품절·판매 중지에도 같은 자리. '국산'을 화면이 자동으로 붙이지 않는다.
- 11/08 크기 근거: 상품명·현재 가격이 모두 28이라 원산지도 28 이상. 취소선 비교 가격(13)을 '처음 등록한 가격'으로 보는 해석은 쓰지 않는다.
- 11/08 원산지가 비어 있으면(공백만 포함) 줄을 숨긴다. 판매 요청(첫 공급 물량 승인 요청)·판매 중 저장은 이미 원산지를 필수로 막고 있었고(서버 missing_fields, Mock missing), 서버만 공백 문자열을 통과시키던 것을 막았다.
- 11/08 생산자 앱 안내: 원산지 칸 아래 둘째 줄 「구매자 화면에는 상품명 바로 아래 같은 크기로 보이고, 비어 있으면 판매 요청을 할 수 없어요.」 DEV-121 첫 줄 문구는 그대로(테스트가 정확히 검사함). 물량·판매 설정의 「먼저 입력해 주세요: 원산지」는 기존 그대로.
- 11/08 상품 카드 제외. 근거: 2호가목1)은 상품명·가격 기준으로 위치를 정하고 목록 화면을 따로 말하지 않으며, 농관원 통신판매 교육 자료도 상품 페이지 상단·상세 설명·상품정보 고시를 예로 든다. farmclub 카드에서는 옵션·수량을 고르거나 예약할 수 없다. 남는 위험: '제품이 화면에 표시되는 때부터'를 목록까지로 읽으면 카드도 대상이고, 그때는 카드 상품명·가격(22) 이상 크기가 필요하다. 후속 DEV-286(농관원 질의).
- 11/08 운영 데이터: 이미 게시된 상품 중 원산지가 빈 것이 있는지는 사람이 확인한다(PR 본문의 SELECT 초안). 에이전트는 운영 DB에 접근하지 않는다.
