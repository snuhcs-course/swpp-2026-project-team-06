## DEV-434 탈퇴 시트의 남는 줄을 소비자·생산자로 나누기

- 이슈: [DEV-434](https://linear.app/sswp6/issue/DEV-434) · GitHub #762
- 브랜치: `nemodleo/dev-434-split-withdraw-kept-line`
- 기능·인수 조건: FEAT-01 / AC-01-20(탈퇴 시트 문구), AC-01-36(계정 삭제 안내와 같은 문장)
- 상태: 리뷰 중

### 목표
탈퇴 확인 시트의 "농가·소비자에게는 ‘탈퇴한 회원’으로 보여요"는 생산자에게 사실과 다르다. 생산자가 탈퇴해도 농가 이름은 소비자의 지난 주문에 남는다(DEV-423 리뷰에서 확인). 앱별 문장으로 나눈다.

### 범위 (수정 허용 경로)
- `packages/ui/src/legalContent.ts`(`WITHDRAW_KEPT` 앱별, `WITHDRAWN_SEEN_AS`, `accountDeletionPage`가 같은 상수 사용), `packages/ui/src/WithdrawSheet.tsx`
- `scripts/test-legal.mjs`
- `docs/spec/functional/FEAT-01-login.md`, `docs/spec/screens.md`, `docs/spec/policy.md`, `docs/wiki/Requirements-and-Specifications.md`
- `docs/design/proposals/DEV-434/**`(전후 캡처), `packages/ui/spec.md`, `packages/ui/tasks/DEV-423.md`(남은 일 처리 표시), `packages/ui/tasks/DEV-434.md`

### 비범위 (건드리지 않음)
- 처리방침·약관 본문(시행일·버전 그대로), 계정 삭제 안내의 문장(같은 글자 그대로)
- 시트의 화면 구성·따옴표 모양, 앞부분(법으로 보관하는 기록 안내), 탈퇴 동작(AC-01-20)
- Figma v6 반영(후속 DEV-357)

### 결정 사항
- 11/22 문장(PM 박현 결정): 소비자 "농가에게는 ‘탈퇴한 회원’으로 보여요.", 생산자 "소비자의 지난 주문에는 농가 이름이 그대로 남아요." 앞부분과 화면 구성은 그대로.
- 11/22 문장 끝 부분을 `WITHDRAWN_SEEN_AS[role]` 하나로 두고 시트(`WITHDRAW_KEPT[role]`)와 계정 삭제 안내(`accountDeletionPage(role).kept`)가 같이 쓴다. 안내 페이지 글자는 바뀌지 않는다.
- 11/22 `policy.md` 계정 삭제 안내 절에도 시트와 같은 문장이라는 한 마디를 더했다(같은 사실을 가리키는 곳이라 함께 맞춤).
