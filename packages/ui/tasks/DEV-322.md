## DEV-322 Show a default product photo when the main photo is empty

- 이슈: [DEV-322](https://linear.app/sswp6/issue/DEV-322) · 상위 [DEV-323](https://linear.app/sswp6/issue/DEV-323) 생산자 파일럿 피드백(11/15)
- 관련: `docs/design/screens/ds.html` 사진 없을 때 자리 표시, `packages/ui/spec.md`(실제 사진과 설명용 그림 구분, 브랜드 원본 보존)

### 왜
- 상품 대표 사진이 없을 때 큰 사진 자리에도 작은 로고(최대 80px)만 떠서 비어 보인다. 사진 주소가 있는데 못 불러오면 빈 회색 면만 남는다(`Photo`에 `onError` 없음).
- PM 결정(11/15): 기본 사진 = 회색 배경 + 그레이스케일 로고.

### 범위 (수정 허용 경로)

- `packages/ui/src/content.tsx`(`Photo`만), `packages/ui/src/NewsRoom.tsx`·`Storefront.tsx`(소식 사진 `productFallback={false}`만), `packages/ui/assets/brand/product-fallback.webp`(새 파일), `packages/ui/assets/brand/README.md`, `packages/ui/spec.md`
- `docs/design/screens/ds.html`(자리 표시 설명 한 줄)

- 생산자 미리보기는 `apps/producer/tasks/DEV-322.md`

### 결정 사항
- 11/15 기본 사진 파일은 1080×1080 WebP(6.6KB): 면색 #F5F5F3 가운데에 `logo-grayscale.png`를 폭 42%·불투명도 55%. 브랜드 원본 PNG는 바꾸지 않는다.
- 11/15 높이 64 이하 상품 썸네일(생산자 목록 64, 소식방 선반 32·48, 농가 판매 품목 52, 현황 48)은 지금처럼 작은 로고. 그보다 큰 자리(상품 상세 300, 홈 카드 173, 생산자 미리보기 244 등)는 기본 사진을 `cover`로 채운다.
- 11/15 불러오기 실패한 주소는 상태로 기억해 자리 표시로 바꾸고, 주소가 바뀌면 다시 시도한다.
- 11/15 판매페이지(모듈형) 소개 사진 `SourcePhoto`는 고치지 않는다. 처음 Figma 시안 메모에 '사진이 없으면 사진 불러오는 중…이 계속 뜬다'고 적었으나 코드 확인 결과 틀렸다: 사진이 없는 모듈은 사진 칸 자체를 그리지 않고, '사진 불러오는 중…'은 생산자 편집기에서 비공개 사진을 받는 동안만 뜬다. 공개 사진을 못 불러오면 `StoryImage`가 이미 안내한다.
- 11/15 서버·API는 바꾸지 않는다(사진 없으면 `photo: null`).
- 11/15 scan-before-commit WARNING 반영: `Photo`의 `kind` 기본값이 `product`라 상품 사진이 아닌 자리(생산자 내 농가 대표 사진 180, 소식 사진)도 기본 사진으로 바뀔 뻔했다. `productFallback={false}`로 예전처럼 작은 로고를 쓰게 했다(농가·사람 자리 표시는 그대로라는 요구사항). 소식 사진은 못 불러오면 빈 회색 면 대신 작은 로고가 된다.
- 11/15 실패 주소는 마지막 하나만 기억한다. 다른 주소로 바뀌면 그 주소를 불러 본다.
