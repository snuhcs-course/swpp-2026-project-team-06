## DEV-299 처리방침 PostHog 보관 기간을 실제 설정(7년)에 맞추기

- 이슈: [DEV-299](https://linear.app/sswp6/issue/DEV-299) (DEV-122 후속, PR #490)
- 브랜치: `nemodleo/dev-299-posthog-retention-wording`
- 기능·규칙: N-05, R-16, policy.md 5장(이용 기록 줄)
- 상태: 리뷰 중

### 목표
처리방침 제6조 국외 이전 표의 PostHog 보유·이용 기간이 "1년(무료 요금제의 최대 보관 기간)"으로 적혀 실제 설정과 다르다. PostHog 설정은 그대로 두고 문구를 실제 보관 기준(이벤트 최대 7년, 세션 녹화 30일)에 맞춘다.

### 범위 (수정 허용 경로)
- `packages/ui/src/legalContent.ts`(제6조 PostHog 줄의 보유·이용 기간 한 칸)
- `scripts/test-legal.mjs`(DEV-122 테스트의 보관 기간 검사)
- `docs/spec/policy.md`(5장 이용 기록 줄, 변경 이력)
- `docs/wiki/Requirements-and-Specifications.md`(Legal pages 문단의 보관 기간)
- `packages/ui/tasks/DEV-299.md`

### 비범위 (건드리지 않음)
- PostHog 프로젝트 설정(보관 기간·IP 저장), `packages/analytics/**`
- 처리방침 시행일(2026-11-13), `CONSENT_VERSION`·`LEGAL_VERSION`, 제14조 2026-11-13 변경 문단
- ADR 0005·stack.md의 "PostHog Cloud(무료)" 표기(요금제 설명이고 보관 기간이 아님)

### 결정 사항
- 11/09 박현이 PostHog 설정 화면을 확인: 요금제 Pay-as-you-go(이용량은 무료 한도 안, 청구 0원), 이벤트 보관 Organization default(7 years), 세션 녹화 보관 30일, IP 저장함. 설정은 두고 문구를 고친다(박현 결정).
- 11/09 "PostHog의 보관 기준에 따라"로 쓰되 구체 기간(최대 7년, 30일)은 남긴다. 처리방침에는 구체 기간이 있어야 해서다.
- 11/09 수집 항목·동의 항목이 바뀌지 않고 처리방침이 아직 시행 전(11/13)이라 시행일·동의 버전·제14조 변경 문단(이미 "보유 기간을 구체적으로 적고"로 포괄)은 그대로 둔다.
