### 목표
시트 안 버튼으로 다른 화면으로 갈 때 시트가 새 화면 위에 남지 않게 한다. 지금은 `setX(false)`와 `router.push`를 같은 틱에 해서 RN `Modal`(slide)이 닫힘 애니메이션(웹 250ms, 창이 가려져 애니메이션이 멈추면 계속) 동안 새 화면 위에 그려진다. 모양·문구는 바꾸지 않는다.

### 결정 사항
- 11/05 방식: "이동하는 버튼은 애니메이션 없이 즉시 닫고 같은 틱에 이동". `onDismiss`를 기다리는 방식은 버린다 — RN-web `Modal`은 닫힘을 CSS `animationend`로 끝내서, 창이 가려지거나 애니메이션이 멈추면 `onDismiss`가 오지 않아 이동 자체가 막힌다. Android RN `Modal`은 `onDismiss`도 보장되지 않는다. 먼저 이동하고 시트를 두는 방식은 `Modal`이 문서 최상단 포털이라 스택 아래 화면의 시트가 그대로 보여 안 된다.
- 11/05 도우미 하나: `@farmclub/ui` `useSheetLeave()` → `{ instant, leave(close, go) }`. `leave`는 `instant`를 켜고 닫고 이동한다. `Sheet`는 `instant`면 `animationType="none"`이라 RN-web은 같은 커밋에 투명(opacity 0)으로 바뀌고 다음 효과에서 빠진다(iOS·Android도 애니메이션 없이 닫힘). 닫힌 뒤 효과에서 `instant`를 끄므로 다음에 열 때는 그대로 아래에서 올라온다. 순서(켜기 → 닫기 → 이동)는 import 없는 `sheetLeave.ts`에 두고 node 테스트로 확인한다.
- 11/05 옵션 시트 '주문서로'는 비로그인이면 이동 대신 관문 시트를 띄운다. 그때도 옵션 시트는 즉시 닫히고 관문 시트가 올라온다(전에는 두 시트가 겹쳐 움직였다). 모양 변화로 보지 않는다.
