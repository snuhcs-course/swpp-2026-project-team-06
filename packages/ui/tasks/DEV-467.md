### 결정 사항
- 11/24 방송(broadcastId 있는 메시지)만 카드로 그린다. 소비자 답장(내 답장 🔒 ‘농가만 봐요’, 생산자 화면의 팔로워 답장)은 지금 말풍선 그대로 둔다. 비공개 응답이 공개 댓글처럼 카드 밑에 붙어 보이지 않게 하려는 것.
- 11/24 카드 폭 = min(창 폭, 480) − 좌우 16×2. 사진: 1장 4:3, 2장 정사각형 두 칸(사이 2px). 3장 이상은 두 장씩 정사각형 줄, 홀수로 남은 마지막 한 장은 카드 폭 4:3(시안에 없는 경우라 가장 단순한 확장). 2장 이상이면 각 사진 오른쪽 아래 ‘i/N’.
- 11/24 소비자 ‘농가에 답장’은 입력칸에 포커스만 준다(비로그인은 로그인 안내, 답장할 수 없는 방은 비활성). 서버가 소비자 인용 답장을 막고(`send_room`의 ‘농가만 소식방 인용 답장’) 답장은 보낸 순간의 가장 최근 소식에 연결하므로, 시안처럼 고른 소식을 인용하면 서버 계약이 바뀐다 → PR 질문으로 남김.
- 11/24 생산자 반응 줄은 ‘읽음 N · 좋아요 N’(보조 14, 회색) 왼쪽, ‘답장 N ›’(보조 14, 주황 굵게, 터치 48) 오른쪽. 기존 접근성 이름(‘읽음 N, 좋아요 N’, ‘답장 N 모아 보기’)과 화면 글자 ‘읽음 N’은 유지해 기존 e2e 단언을 그대로 둔다. 소비자 반응 줄에는 숫자를 그리지 않는다(AC-15-3).
- 11/24 ‘답장 N ›’은 아이콘 없이 글자 한 덩어리로 둔다. 꺾쇠를 아이콘으로 떼면 시트 제목 ‘답장 N’과 같은 글자가 생겨 기존 e2e(AC-15-11 `getByText(/^답장 \d+$/)`)가 둘을 구별하지 못했다.
- 11/24 ‘농가에 답장’ 아이콘은 새 아이콘을 더하지 않고 `chat`을 쓴다(시안은 되돌리기 화살표).
- 11/24 카드 그림자는 웹 `boxShadow: 0 1px 2px rgba(17,17,17,.04)` + 앱 shadow*·elevation 1. 테두리 없음, 모서리 16.

- 11/24 (사용자 답) PR 질문 1 → 소비자 답장은 ‘농가에 답장’을 누른 소식에 연결한다(서버 `broadcastId` 선택 입력). 입력칸 위에 ‘소식에 답장 · 농가만 봐요’ 인용 줄과 취소를 보이고, 고르지 않고 보내면 지금처럼 가장 최근 소식.
- 11/24 (사용자 답) PR 질문 2 → 소비자 작성창 ‘+’로 비공개 사진 첨부(1:1과 같은 `PrivatePhotos`·저장, 3장). 내 답장 말풍선과 생산자 소식방·팬 답장 시트에 사진(눌러 크게). 영상은 비범위.
- 11/24 (사용자 답) PR 질문 3(아이콘)은 답 없음 → `chat` 그대로.

- 11/24 (사용자 피드백) 소비자 사진 첨부를 1:1 `PrivatePhotos` 대신 소식방 전용 작은 첨부(`usePhotoAttach` + `AttachedPhotoRow`, PrivatePhotos.tsx 새 export)로: ‘+’(늘 첨부, 토글 × 아님)가 숨긴 파일 칸을 바로 열고, 입력줄 위 72×72 썸네일 한 줄(모서리 8, 간격 8), 오른쪽 위 어두운 원 ×(보이는 24·누르는 48, ‘첨부 사진 N 삭제’), 개수는 12/16 회색 ‘1/3’. 1:1 모양은 그대로.

- 11/24 (pre-merge scan) 고른 소식이 지워지면(목록에서 사라지거나 서버 404 `REPLY_TARGET_GONE`) 고른 소식을 풀고 ‘삭제된 소식이에요. 최신 소식에 답장해 주세요’, 쓸 수 없는 사진(`ATTACHMENT_UNUSABLE`)은 사진만 빼고 안내, 쓴 글은 그대로. 소식방 답장 사진 접근성 이름 ‘답장 사진’(`PrivatePhoto` `label`, 1:1 기본값 그대로). `usePhotoAttach`·`AttachedPhotoRow`는 공개 export에서 뺌(NewsRoom 안에서만). `PrivatePhoto`와 썸네일의 불러오기·blob 정리는 `usePrivateImage` 하나로.
