- 11/09 ‘답변 확인 요청’은 말풍선 아래 글자 버튼으로만 바꾸고 문구·동작은 그대로(깃발 흐름은 DEV-296). Figma의 ‘농가에 확인 요청 ›’ 문구는 DEV-296에서 정한다.
- 11/09 묶음은 같은 보낸 사람·같은 분(시각 글자가 같음)·같은 날이면 한 묶음(카카오톡 방식). 아바타·이름은 묶음 첫 말풍선, 시각은 마지막 말풍선 옆.
- 11/09 읽음 표시는 이미 API에 있는 `thread.producerLastReadMessageId`/`consumerLastReadMessageId`로 내 마지막 읽힌 말풍선 옆에 ‘읽음’. 서버 변경 없음.
- 11/09 복사는 메뉴 항목으로 넣고, 답장이 없는 방(문의 대화방)에서도 길게 누르기로 복사만 열린다. 클립보드는 앱이 넘기는 `copy`(기존 expo-clipboard 도우미)를 쓴다. 의존성 추가 없음.
- 11/09 iOS 키보드: `KeyboardRoot`·`useKeyboardShown`을 Android 전용에서 앱(iOS·Android) 공통으로 넓힌다(RN 내장 KeyboardAvoidingView, 새 의존성 없음). 웹은 그대로.
- 11/09 사진 전체 화면은 RN `Modal` + `Image`로(새 의존성 없음). 누르는 칸은 사진 위에 겹친 형제로 둬서 사진의 img 역할이 보조기술에서 사라지지 않게 한다.
- 11/09 묶음 간격(4/16)을 행 안쪽 위 여백으로 넣고 `chatRowGeometry` 간격 인자를 0으로 넘긴다. 시스템 문구도 첫 행 안에 둬서 행 위치 계산이 그대로 맞는다.
- 11/09 날짜 알약 요일은 실제 달력 기준(2026-10-07은 수요일). Figma의 ‘10월 7일 화요일’은 자리 표시.
- 11/09 생산자 소식방 탭 이름은 Figma대로 ‘내 소식방’. 입력칸 안내는 ‘팔로워 N명에게 보내기’, 소비자 입력칸 안내는 ‘{농가명}에 답장’(접근성 이름 ‘농가에 답장’·‘모두에게 보낼 소식’은 그대로).
- 11/09 아래 고정 안내 ‘소식방 · 내 글은 농가만 봐요…’·‘소식방 · 모든 팔로워에게 보내요’는 지운다(내 말풍선 옆 ‘농가만 봐요’와 입력칸 안내로 충분, Figma 7:81·7:96). 생산자 본문 첫 시스템 안내 ‘보내는 소식은 모든 팔로워에게 보여요’는 남긴다(AC-12-12).
- 11/09 채팅 목록 시각은 한국 날짜 기준 ‘오전 8:30 / 어제 / 10월 2일’(`messageTime`). 홈 소식 카드도 같은 함수를 써서 같이 바뀐다.
