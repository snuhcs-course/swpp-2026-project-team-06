### 결정 사항
- 11/24 `privatePhotoBlob`은 응답을 조각으로 읽어 `new Blob(chunks)`로 합쳤다. Expo 57 앱은 전역 `fetch`가 expo/fetch라 `res.body.getReader()`가 있고, React Native의 Blob은 ArrayBuffer·Uint8Array로 만들 수 없어 여기서 늘 예외가 났다. `new Blob([new Uint8Array(0)])`가 되는지 한 번 재서, 안 되면 조각 읽기 없이 `res.blob()`으로 받는다(전체 시간 제한 120초만, 기존 '조각 읽기를 못 하는 환경' 길). 웹·Node는 그대로.
