### 목표
PM 추가 요청(11/15)으로 앱 첫 로딩을 가볍게 한다. 운영 웹 번들(`EXPO_PUBLIC_API_MOCK=0`)에 브라우저 Mock(시드 데이터·Mock 라우터, `packages/api/src/mock/**`)이 그대로 들어 있다. `client.ts`가 Mock을 맨 위에서 import하기 때문이다.

### 비범위

### 결정 사항
- 11/15 Mock은 `process.env.EXPO_PUBLIC_API_MOCK === "1" ? require("./mock") : null`로 불러온다. Expo가 빌드 때 이 값을 글자로 바꾸고 Metro가 운영 빌드에서 조건을 접어 `require`를 의존성에서 뺀다(Platform.OS 분기와 같은 방식). 조건을 `isMock` 같은 변수로 빼면 접히지 않으므로 식을 그 자리에 둔다. 브라우저 Mock 전송은 원래도 `EXPO_PUBLIC_API_MOCK=1`이고 공유 Mock 주소가 없을 때만 쓰여 동작은 같다. Mock 테스트 빌드(CommonJS)와 앱(Metro) 모두 `require`가 있어 모듈 안에서 `require` 타입만 선언한다.
