## DEV-327 Keep sold-out products on the consumer home and farm list with a sold-out label

- 이슈: [DEV-327](https://linear.app/sswp6/issue/DEV-327) · 주 기록 `server/tasks/DEV-327.md`
- 브랜치: `jangjinuite/dev-327-keep-sold-out-listed`
- 기능·인수 조건: FEAT-07 AC-07-3, FEAT-06, R-27
- 상태: 진행 중

### 왜
서버 `home()`·`farm_cards()`가 품절 상품을 홈 추천·농가 대표에 남기도록 바뀐다(주 기록 참고). Mock도 같은 규칙이어야 `npm run dev`·Mock 테스트가 서버와 같다.

### 범위 (수정 허용 경로)
- `packages/api/src/types.ts`(`FarmCard.featured.availability`)
- `packages/api/src/mock/derive.ts`(`farmCard`), `packages/api/src/mock/farms.ts`(`GET /api/home` 추천·히어로, 농가 정렬)
- `scripts/test-storefront.mjs`(AC-07-3 Mock 테스트)
- `packages/api/tasks/DEV-327.md`(이 파일)

### 비범위 (건드리지 않음)
- `packages/api/src/mock/sales.ts`(`salesState` 판정), `productPresentation.ts`(`productPrices`)

### 결정 사항
- 11/15 서버와 같은 규칙: 추천은 `AVAILABLE`·`TOTAL_SOLD_OUT`·`PERIOD_SOLD_OUT`만, 예약 가능 먼저(마감 임박순) 뒤에 품절(마감 임박순), 상위 6개. 대표는 첫 예약 가능 상품, 없으면 첫 품절 상품, `availability`를 싣는다. 농가 정렬은 `(대표 없음, 대표 품절, dDay)`.
- 11/15 Mock 히어로는 `p-house` 고정이었다. 서버처럼 `p-house`가 `AVAILABLE`일 때만 `productId`를 싣고 아니면 `null`로 맞춘다.
