### 결정 사항
- 11/10 (PM) 정지는 사유 필수. 출하 전 주문(입금 대기 `AWAITING_DEPOSIT`·예약 `RESERVED`·준비 `PREPARING`)이 하나라도 있으면 409 `FARM_HAS_OPEN_ORDERS`로 거부하고 주문 목록을 돌려준다. 계좌이체라 자동 환불하지 않는다(R-24 예외). `PENDING_PAYMENT`(입금 안내 전)는 돈·물량이 없고 소비자 목록에도 안 보여 막지 않는다. 대신 정지된 농가 주문은 입금 안내(`POST /api/orders/{id}/deposit`)를 404로 막는다(아래).
- 11/10 정지는 승인(`APPROVED`) 농가만. 정지 풀기는 운영자가 정지한 농가만 `APPROVED`로 되돌린다(상품 상태는 그대로라 바로 판매 재개). 탈퇴한 농가(`FARM_WITHDRAWN_REASON`)는 409 `FARM_WITHDRAWN`, 테스트로 숨긴 농가(`RETIRE_REASON`)는 409 `TEST_FARM_HIDDEN`으로 거부하고 `POST /admin/farms/{id}/restore`를 안내한다. 숨기기와 정지는 사유 문구로만 구분되므로 운영자 사유가 두 고정 문구와 같으면 400.
- 11/10 반려 → 확인 중 되돌리기 `POST /admin/producers/{farmId}/revert`(사유 필수). 신청 시각은 그대로 두고 결정 시각·반려 사유를 비운다.
- 11/10 이력은 마이그레이션 없이 `producer_decisions`에 `SUSPENDED`·`UNSUSPENDED`·`REVERTED`를 더하고, 숨김·복구는 `manager_events`(`test_farm.retire`·`restore`, 명령 `test_farm_retired`·`restored`)에서, 신청은 결정 행의 `application_at`과 지금 `applied_at`에서, 탈퇴는 `users.deleted_at`에서 모은다. 새 API `GET /admin/farms/{farmId}/history`(오래된 순). 기존 `GET /admin/producers/{farmId}/decisions`는 계약대로 승인·반려만 돌려준다.
- 11/10 동시성: 농가 행을 `FOR UPDATE`로 잠그고 상태를 다시 본다. 입금 안내는 농가 행을 `FOR SHARE`로 읽어, 정지와 입금 안내가 겹쳐도 정지된 농가에 입금 대기 주문이 생기지 않는다. 농가에는 version 열이 없어 낙관적 버전 대신 잠금 + 상태 검사 + 멱등 키(`run_manager_action`)를 쓴다.
- 11/10 활동 로그 `GET /admin/users/{userId}/activity`: 서버 기록(가입·동의·신청·결정·운영 이벤트·상품·공급 물량·주문·문의 메시지 시각, 본문 없음)과 PostHog 이벤트. PostHog는 `POSTHOG_PERSONAL_API_KEY`·`POSTHOG_PROJECT_ID`가 모두 있을 때만 HogQL 조회(5초, 최근 30일 50건). 없으면 `posthog.status = "disabled"`, 실패하면 `"unavailable"`이고 페이지는 200. 키는 로그·응답에 남기지 않는다. 호스트 `POSTHOG_HOST` 기본 `https://us.posthog.com`(앱 수집 호스트 `us.i.posthog.com`을 넣어도 조회 호스트로 바꾼다).
- 11/10 홈 건수 `GET /admin/home`: 가입 신청 대기, 공급 물량 대기, 답변 대기 문의, 열린 예외(`OPEN`·`FAILED`), 입금 기한 지남(입금했어요 + 기한 지남, `deposit-overdue`와 같은 정의). 신청·공급·문의는 계정 필터를 따른다(기본 실사용자).
- 11/10 계정 필터 `kind=real|test|all`, 기본 `real`: `GET /admin/users`·`/admin/producers`·`/admin/capacity-requests`·`/admin/support`. 테스트 = 시드 테스트(`is_test_account`) 또는 운영 검증(`ops_tester`). 행마다 `accountKind`(`REAL`·`SEED_TEST`·`OPS_TESTER`)와 `withdrawn`. 탈퇴 계정은 실사용자로 세고 표시만 한다. 지금 관리자 웹(사용자 '전체' 탭·가입 신청·공급 물량·문의함)은 `kind=all`을 보내도록 한 줄씩 고쳐 개편(DEV-308·309) 전까지 동작을 유지한다(스캔 지적 반영). 기본 실사용자 필터는 새 화면이 쓴다.
- 11/10 위험 등급: `server/app/admin/**`·`accounts/**`·`orders/**`·`core/config.py`를 바꾸므로 고위험.
