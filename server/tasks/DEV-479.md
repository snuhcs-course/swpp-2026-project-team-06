### 결정 사항
- 11/24 사용자 요청에 따라 상품별 공개 여부를 관리자 사용자 상세의 상품 카드에 추가한다.
- 승인 상태와 별도인 is_hidden(default false)을 저장한다. 숨겨도 승인·재고·가격·농가·다른 상품·기존 주문을 변경하지 않는다. 공개 복원은 기존 상품/농가 승인 조건을 우회하지 않는다.
- POST /admin/products/{id}/visibility: isHidden(bool), version(양의 정수), reason(공백 제외 1~500자), Idempotency-Key 필수. 상품 행 잠금과 버전 검사 후 플래그·버전·수정시각만 변경한다. 같은 상태 재지정은 현재 버전이면 성공(버전 불변), 같은 키는 처음 결과를 재사용한다.
- 숨긴 상품은 공개 카드·품종 검색·상세·AI 일반 상품 문맥에서 제외하고 새 주문을 404로 거부한다. 이미 만들어진 주문의 입금·배송·문의는 유지한다. 새 주문과 숨김은 같은 상품 잠금 아래 순서를 보장한다.
- UI는 기존 카드/버튼/입력 규격을 사용한다. 작은 버튼 → 카드 안 안내/필수 사유/확인·취소, 중복 클릭 차단, 실패 시 입력 유지, 버전 충돌 시 작은 새로고침 버튼을 제공한다.
- DEV-472와 겹치는 공개 선택자는 현재 main에서 독립 플래그 조건만 추가한다. 해당 PR 병합 전 순서를 정하고 최신 main에서 결합을 검증한다.
- Figma v6 반영은 후속 DEV-480.
