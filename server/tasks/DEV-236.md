## DEV-236 Vercel 기본 주소에서 리다이렉트 없이 동작(테스트용, PostHog 통계·녹화 한도 보호)

### 목표
PostHog 통계·세션 녹화(무료 2,500건)는 공식 도메인에서만 켜진다(DEV-125). 팀이 운영 화면을 Vercel 기본 주소(`farmclub-consumer.vercel.app`, `farmclub-producer.vercel.app`)에서 테스트할 수 있게, 그 주소가 공식 도메인으로 넘어가지 않고 그 안에서 동작하게 한다(PM 결정 11/05: "vercel 주소는 vercel 주소 안에서 이동").

### 결정 사항
- 11/05 리다이렉트 대신 같은 host 조건으로 `X-Robots-Tag: noindex, nofollow`를 붙인다(Vercel `headers`의 `has: [{type: host}]`). DEV-127의 이유 중 "검색엔진 중복"은 이 헤더로 막고, "로그인·API가 막힘"은 서버 보조 주소로 푼다. "카카오 비즈 앱 심사 혼동"은 서비스 대표 도메인(카카오 콘솔 사이트 도메인 첫 줄, 공유·OG·메일 주소)이 공식 도메인 그대로이고 vercel.app은 검색에 안 잡히는 테스트 주소라 판단했다. 심사에서 문제가 되면 카카오 콘솔에서 vercel.app 복귀 주소만 지우면 된다(로그인만 막히고 화면은 그대로).
- 11/05 서버 보조 주소는 앱별 설정 `CONSUMER_APP_ALT_URLS`·`PRODUCER_APP_ALT_URLS`(쉼표 구분, 기본 빈 값 = 기존 동작과 같음). 리스트 타입 대신 문자열로 둔 이유: pydantic-settings는 리스트를 JSON으로 읽어 Railway 변수에 `["https://…"]`를 넣어야 한다. 값마다 `http(s)://호스트[:포트]`(경로·`*` 없음)인지 시작 때 검사한다 — `*`가 들어가면 Starlette CORS가 모든 출처를 허용하기 때문이다.
- 11/05 `server/.env.example`에는 새 변수를 적지 않는다: spec-check가 `.env*` 경로를 읽지 않아 바꾸면 자동 검사가 INCOMPLETE가 되고 `check_table.py`가 통과하지 않는다. 변수 이름·형식은 `config.py` 주석, README Railway 변수표, ADR 0012 갱신 절에 둔다. `.env.example` 한 줄 추가는 사람이 따로 해도 된다(기본 빈 값이라 로컬 동작은 같다).
- 11/05 코드에 vercel.app 주소를 넣지 않는다. 운영 값은 사람이 Railway에 넣는다.
- 11/05 CORS 목록은 `install_cors(app, settings)`로 빼서 보조 주소 설정으로 새 앱을 만들어 preflight를 시험한다(`app.main`을 다시 import하지 않는다).
- 11/05 웹 카카오 인가 요청의 redirect_uri는 이미 접속 origin 기준이다(`apps/*/src/lib/kakao.ts` `kakaoRedirectUri` = `window.location.origin` + `/auth/kakao`). 앱 코드는 고칠 것이 없어 Mock 테스트로 vercel.app origin에서 vercel.app 복귀 주소가 나오는지만 고정한다.
- 11/05 같은 앱 안 이동에 절대 주소를 쓰는 곳은 없다(조사: `EXPO_PUBLIC_CONSUMER_URL`·`EXPO_PUBLIC_PRODUCER_URL`·`https://farmclub.kr` 기본값). 공식 도메인으로 나가는 곳은 모두 상대 앱 링크나 남에게 보내는 주소라 그대로 둔다(한계).

### 한계 (vercel.app에서 공식 도메인으로 나가는 곳)
- 소비자 내 정보의 "생산자 앱" 링크(`apps/consumer/src/app/(tabs)/me/index.tsx`, `EXPO_PUBLIC_PRODUCER_URL`) → `farm.farmclub.kr`
- 생산자 농가 화면의 소비자 미리보기(`apps/producer/src/app/(tabs)/farm/index.tsx`, `EXPO_PUBLIC_CONSUMER_URL`) → `farmclub.kr`
- 공유 링크(`shareUrl`, `SHARE_BASE_URL`)와 서버 공유 페이지(`/s/farms/<id>`)의 이동 대상(`CONSUMER_APP_URL`) → `farmclub.kr`. vercel.app의 `/s/*`도 서버 페이지를 프록시하므로 거기서 누르면 공식 도메인으로 간다.
- 이 주소를 vercel.app으로 바꾸려면 "지금 접속한 주소 계열"을 알아야 해서 판단이 필요하다(후속 결정).
- 같은 운영 서버·DB를 쓰므로 vercel.app에서 만든 주문·계정은 운영 데이터다.
