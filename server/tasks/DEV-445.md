### 결정 사항
- 11/24 기존 후보를 문장 단위로 추적하는 결정적 계획 입력을 만든다. 인용만으로 사실 완전성을 보장하지 않는다.
- 11/24 정리 호출은 기존 한 번·예약/정산 경계를 유지한다. 모듈별 역할과 일차 위치, 중복 근거 묶음을 입력에 명시한다. 기존 출력·검증·편집 계약을 유지한다.
- 11/24 고정 추출 결과를 사용하는 로컬 비교와 gold 진단을 추가하고 구버전·신버전을 같은 scorer로 비교한다. 지표 개선과 인간 편집 품질을 구분한다.
- 11/24 전체 gold 인수·사람 편집 평가 전에는 진단/프로토타입 결과만 보고한다. DEV-446~452 완료를 자동 주장하지 않는다.
- 11/24 v12 단일 계획 호출 비교는 개선을 입증하지 못했다(222/219 → 182/213, 첫 회 PDF timeout 포함). 원본 결과 보존. 다음 별도 실험은 후보를 자르지 않는 작은 작성 묶음을 각각 예약/정산하고 같은 검증 뒤 병합한다. 운영 기본으로 채택하지 않는다.
- 11/24 세 번째 실험은 source unit마다 명시적 배치/제외를 반환하는 구조화 계약이다. 모르는 ID·빠진 unit·빈 이유를 서버에서 거절한다. 이것도 의미상 사실 완전성을 인증하지 않으며 같은 기존 scorer/모델·$5 누적 한도를 유지한다.
- 11/24 실제 비교 화면에서 동일 상품 제목의 지역명 유무 변형이 hero에 반복되는 것을 확인했다. 숫자/예상·실측/부정이 없는 제목만, 단어 경계에서 긴 제목이 짧은 제목 전체로 끝날 때 긴 제목과 모든 인용을 보존한다. 다른 섹션·서로 다른 제목·조건은 건드리지 않는다. 고정 결과 양쪽에 같은 처리로 감사한다.
- 11/24 사용자가 세 가지 생성 실험 뒤 원문 감사를 먼저 선택했다. 51개 고유 중요 miss(17자료)를 추적했다. 원문 `12브릭 스`를 모델이 `12브릭스`로 정돈하면 기존 숫자 검증이 단위 없는 12로 읽어 거절하는 결함을 확인했다. 단위 정규식에서 브/릭/스 사이 공백만 허용하며 값·단위 종류·범위는 바꾸지 않는다. 캐시 버전을 source-refine-v11-source-audit로 올린다. 기존 scorer/gold는 유지하며 저장된 모델 출력 양쪽을 같은 새 검사로 재생한다.
