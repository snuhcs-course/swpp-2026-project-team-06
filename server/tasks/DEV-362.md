## DEV-362 Hide empty producer-opened chats from buyers and key the chat prefill by buyer

- 이슈: [DEV-362](https://linear.app/sswp6/issue/DEV-362) · 주 기록(이 파일) · GitHub #660
- 브랜치: `jangjinuite/dev-362-empty-producer-chat`
- 기능·인수 조건: FEAT-12 AC-12-18(한 줄 추가), M-04 · DEV-342(PR #648) 머지 전 검사에서 남은 후속
- 상태: 리뷰 중
- 함께 쓰는 이슈 파일: `packages/api/tasks/DEV-362.md`, `apps/producer/tasks/DEV-362.md`, `docs/spec/tasks/DEV-362.md`

### 목표
생산자가 입금 대기 주문의 ‘채팅하기’만 누르고 보내지 않으면 PRODUCER 대화 문맥만 남아, 팔로우하지 않은 구매자 채팅 목록에 빈 농가 대화(‘대화를 시작해 보세요’)가 생긴다. 메시지가 오가기 전에는 목록에 올리지 않는다.

### 범위 (수정 허용 경로)
- `server/app/messaging/service.py`(`consumer_chats`, 새 `_listed_without_follow`), `server/app/messaging/spec.md`(구현 결정 한 줄), `server/tests/test_deposit_code.py`, `server/tasks/DEV-362.md`

### 비범위 (건드리지 않음)
- 대화 열기·보내기 권한(`_consumer_thread`, `_has_inquiries`, `_may_send_without_order`, `assert_thread_access`) — 그대로(목록에서만 숨김)
- 팔로워의 목록 규칙, 생산자 쪽 목록(`producer_chats`) — 그대로
- `producer_start`가 문맥을 남기는 방식 — 그대로(문맥은 보내기 권한에 필요)

### 결정 사항
- 11/17 목록 조건: 팔로우했으면 그대로 보인다. 아니면 연결 주문(소비자 쪽 문맥·문의)이 있으면 보이고(소비자가 직접 연 결제 주문 대화는 빈 상태로도 보이던 그대로), 생산자 쪽 문맥만 있으면 그 대화에 메시지(`ThreadMessage`)가 하나라도 있을 때만 보인다. 메시지는 보낸 쪽을 가리지 않는다(생산자·소비자·AI 무엇이든 ‘대화가 오갔다’).
- 11/17 목록만 바꾼다: 숨긴 빈 대화도 주소로 열면 예전처럼 열린다(권한은 주문 문맥 기준). 이슈 범위가 목록이고, 빈 대화에는 볼 내용이 없으며, 권한은 보내기 경로(구매자 답장)와 묶여 있어 바꾸지 않는다.
