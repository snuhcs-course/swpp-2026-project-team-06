### 결정 사항 (구현 전)
- 서버와 Mock의 생산자 공통 주문 직렬화에서 DELIVERED·COMPLETED 수령인 이름을 고정 `○○○`으로, 전화·우편번호·주소·상세주소를 빈 문자열, 배송 메모를 null로 만든다. 이름 길이·첫 글자도 노출하지 않는다.
- 입금 전 가림은 기존 계약을 유지한다(입금 대조용 이름은 유지). 배송 전 유료 주문·소비자 본인 조회·운영자 조회·저장된 원본 데이터는 변경하지 않는다. 배송 완료 뒤 환불된 주문도 완료 시각이 있으면 가린다.
- UI에서만 숨기지 않고 API 응답을 가린다. 화면 구조·문구 변경 없이 기존 렌더러가 가려진 값을 표시한다.
- 후속 조사: 송장 수정의 멱등 응답도 배송 전 개인정보를 저장한다. `tracking` 응답은 캐시 결과의 송장·버전 등은 유지하되 현재 주문의 가림을 마지막에 적용한다. 캐시를 읽을 때도 현재 농가 소유를 확인한다. 이 범위 확장을 코드보다 먼저 기록한다.
- 첫 CI(44455786386) 서버 2106 passed / 1 skipped. integration 1/3의 기존 상품 상세 테스트는 실제 섹션 상세 상품에 블록 편집 버튼을 기대해 2회 실패했다(다른 shard 통과). CI의 화면·로그와 `NewProductComposer` 분기로 원인을 확인했다. 가림 코드와 관계없는 기존 테스트의 상품 조회는 블록 상세로, workspace 응답은 비composer로, 상품 초안 GET은 404(직접 반영 모드)로 명시한다. 버튼·힌트 검증은 유지한다.
- 이전 I3-PRODORD-05 FAIL은 보존하고, 새 커밋·로컬 DB로 재실행한 별도 증거를 남긴다.
- 운영 데이터 접근·배포·머지는 이번 작업 범위에 없다. 사람의 새 diff 검토 전 머지하지 않는다.
