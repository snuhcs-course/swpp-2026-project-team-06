- 11/05 PM 승인(제안서 추천안 A): 품종은 카드에 넣지 않고 검색할 때 따로 읽는다. 인수 조건은 기존 AC-06-2에 붙인다. 정규화는 하지 않는다.
- 11/05 PM 결정(PR #450 spec-code-review SC-001 뒤): 스펙 문장을 보강한다. AC-06-2 예시 “한라봉”은 시드에서 초안 상품이라 판매 중 품종(궁천조생)으로 바꾸고, 초안·승인 대기·반려·판매 종료 상품의 품종은 찾지 않고 판매 일시 중지 상품은 찾는다(R-27)고 FEAT-06 정상 흐름 3과 AC-06-2에 적는다. ia.md 한 줄, wiki 영문 요약도 같은 뜻으로. 판매 일시 중지 경우를 pytest·Mock 테스트에 더한다.
- 11/05 “판매 중”은 상품명 검색과 같은 집합: `status == "PUBLISHED"`이고 승인된 농가(`published_cards`와 같은 조건). 판매 일시 중지(`sales_paused`) 상품은 농가 페이지에 그대로 보이므로(R-27) 상품명 검색처럼 포함한다. DRAFT·PENDING_APPROVAL·REJECTED·CLOSED는 제외.
- 11/05 farms는 catalog 모델을 직접 읽지 않고 catalog service를 거치는 기존 경계를 지키려고 `catalog.published_varieties`를 추가한다(그래서 범위에 `catalog/service.py` 한 함수 추가).
