### 결정 사항
- 11/10 UAT 데이터는 `python -m app.core.seed_uat [--commit]`. 기본은 미리보기다. 한 트랜잭션에서 넣어 제약을 확인하고 넣을 목록을 출력한 뒤 롤백한다. `--commit`일 때만 그 트랜잭션을 커밋한다. 표지 `u-uat-c1`이 이미 있으면 거부한다. 모르는 옵션은 거부(retire_test_farm 패턴).
- 11/10 계정: 소비자 `u-uat-c1..c3`('UAT 소비자 N', 닉네임 'UAT소비자N', 가짜 연락처·배송지), 생산자 `u-uat-p1..p3`('UAT 생산자 N'). 농가 `f-uat-1`·`f-uat-2`(APPROVED, 상품 각 1~2개, 판매 중, 승인 물량), `f-uat-3`(PENDING). 모두 `is_test_account=True`. 이름은 실제 사람처럼 보이지 않게 'UAT …'.
- 11/10 상품 기간·받는 시기는 실행한 날(KST `today()`) 기준 상대 날짜로 만든다. 운영에 넣는 날짜를 미리 알 수 없고, 고정 날짜는 기간이 지나 '판매 종료'로 보일 수 있다.
- 11/10 상품 행은 `seed.seed_product`(upsert)를, 옵션·기간·가격·배정은 `seed`에서 나눈 `seed_options_and_stages`를, 문의방은 `ensure_support_thread`(승인 농가)·`ensure_consumer_support`(소비자)를 쓴다.
- 11/10 `TEST_ACCOUNTS`에 UAT ID를 뒤에 붙인다. 목록은 DB에 있는 테스트 계정만 돌려주므로 UAT를 넣지 않은 환경(로컬 시드·CI)은 그대로다.
- 11/10 ~~결정 필요~~ → **PM 결정(11/10): 승인 UAT 농가는 숨긴 상태로 넣는다.** `seed_uat`가 넣은 뒤 `retire_test_farm.retire_in`으로 f-uat-1·f-uat-2를 '테스트 농가 숨김'(SUSPENDED + RETIRE_REASON)으로 두고 감사 이벤트(`test_farm_retired`, via cli)를 남긴다. 확인 중 f-uat-3는 그대로. UAT 시작 때 관리자 웹 '다시 공개'나 `retire_test_farm --restore --commit`으로 연다. 공개된 동안 실제 소비자가 주문하면 다시 숨기기가 거부된다(DEV-93 조건). 2단계 기간이 실행일 + 34일에 끝나므로 UAT 직전에 넣는다.
- 11/10 운영 명령 안내는 운영 명령이 모여 있는 루트 `README.md` 'Server on Railway' 절에 둔다(`server/README.md`는 소스 분석 워커 배포 문서).

### 운영 runbook (사람이 실행)
1. DEV-304 정리(`app.admin.purge_except --keep …`, 머지 뒤 이름·옵션 재확인)를 먼저 끝낸다.
2. 넣기(숨김): 미리보기 `railway ssh --service farmclub-api -- .venv/bin/python -m app.core.seed_uat` → 출력(계정 6·농가 3·상품·기간, 승인 농가 숨김 안내)을 확인 → `… -m app.core.seed_uat --commit`.
   - 확인: 공개 `GET /api/farms`에 UAT 농가가 없다. 관리자 웹 사용자 목록(테스트 계정)에 UAT 6명(ops_tester 계정은 따로 더해질 수 있음), 농가 '숨김' 탭에 UAT 농가 1·2. 이때 UAT 생산자가 로그인하면 숨김 사유가 적힌 정지 안내를 본다.
3. UAT 시작: 관리자 웹 '숨김' 탭 '다시 공개' 또는 `… -m app.admin.retire_test_farm f-uat-1 --restore --commit`(f-uat-2도) → `GET /api/farms`에 보이는지 확인 → Railway `farmclub-api` 변수 `MOCK_LOGIN_ENABLED=true`(재배포). 평가 주소 `https://farmclub-consumer.vercel.app/login?evaluator=1`, `https://farmclub-producer.vercel.app/login?evaluator=1`.
4. UAT 끝: 두 농가를 다시 숨김(관리자 웹 또는 `retire_test_farm f-uat-N --commit`) → `MOCK_LOGIN_ENABLED=false`(재배포) → `GET /api/auth/test-accounts?app=consumer`가 404.
5. 정리: DEV-304 명령을 다시 실행해 실제 농가만 남긴다(`--keep <실제 생산자 ID> …` 미리보기 → `--commit`). UAT 계정은 `--keep`에 넣지 않는다.
