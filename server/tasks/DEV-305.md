- 주문·메시지 데이터(문의방 helper가 만드는 환영 메시지만)

### 결정 사항
- 11/10 UAT 데이터는 `python -m app.core.seed_uat [--commit]`. 기본은 미리보기다. 한 트랜잭션에서 넣어 제약을 확인하고 넣을 목록을 출력한 뒤 롤백한다. `--commit`일 때만 그 트랜잭션을 커밋한다. 표지 `u-uat-c1`이 이미 있으면 거부한다. 모르는 옵션은 거부(retire_test_farm 패턴).
- 11/10 계정: 소비자 `u-uat-c1..c3`('UAT 소비자 N', 닉네임 'UAT소비자N', 가짜 연락처·배송지), 생산자 `u-uat-p1..p3`('UAT 생산자 N'). 농가 `f-uat-1`·`f-uat-2`(APPROVED, 상품 각 1~2개, 판매 중, 승인 물량), `f-uat-3`(PENDING). 모두 `is_test_account=True`. 이름은 실제 사람처럼 보이지 않게 'UAT …'.
- 11/10 상품 기간·받는 시기는 실행한 날(KST `today()`) 기준 상대 날짜로 만든다. 운영에 넣는 날짜를 미리 알 수 없고, 고정 날짜는 기간이 지나 '판매 종료'로 보일 수 있다.
- 11/10 상품 행은 `seed.seed_product`(upsert)를, 옵션·기간·가격·배정은 `seed`에서 나눈 `seed_options_and_stages`를, 문의방은 `ensure_support_thread`(승인 농가)·`ensure_consumer_support`(소비자)를 쓴다.
- 11/10 `TEST_ACCOUNTS`에 UAT ID를 뒤에 붙인다. 목록은 DB에 있는 테스트 계정만 돌려주므로 UAT를 넣지 않은 환경(로컬 시드·CI)은 그대로다.
- 11/10 **결정 필요(진우)**: 승인 UAT 농가·상품은 넣는 순간부터 공개 목록에 보이고 실제 카카오 소비자도 주문할 수 있다(가짜 계좌 안내). runbook에 넣은 직후 `retire_test_farm`으로 숨기고 UAT 시작 때 `--restore`하는 선택지를 적었다. 노출을 감수할지, 숨김 단계를 필수로 할지 정해 주세요. 실제 소비자가 한 번 주문하면 `retire_test_farm`이 숨김을 거부한다(DEV-93 조건). 2단계 기간이 실행일 + 34일에 끝나므로 UAT 직전에 넣는다.
- 11/10 운영 명령 안내는 운영 명령이 모여 있는 루트 `README.md` 'Server on Railway' 절에 둔다(`server/README.md`는 소스 분석 워커 배포 문서).

### 운영 runbook (사람이 실행)
1. DEV-304 정리(`app.admin.purge_except --keep …`)를 먼저 끝낸다.
2. 미리보기: `railway ssh --service farmclub-api -- .venv/bin/python -m app.core.seed_uat`
3. 출력(계정 6·농가 3·상품·기간)을 확인한 뒤 넣기: `… -m app.core.seed_uat --commit`
4. 확인: 공개 API `GET /api/farms`에 'UAT 농가 1·2'가 보인다. 관리자 웹 사용자 목록(테스트 계정)에 UAT 6명이 있다(운영 검증 계정 ops_tester는 따로 더해질 수 있음).
   - (선택) 확인한 뒤 UAT 전까지 숨기기: `… -m app.admin.retire_test_farm f-uat-1 --commit`, `f-uat-2`도 같게. 숨기면 공개 목록에서 빠지는 것이 정상이다. UAT 시작 때 `--restore --commit`, 끝나면 다시 숨김.
5. UAT 켜기: Railway `farmclub-api` 변수 `MOCK_LOGIN_ENABLED=true` → 재배포. 평가 주소 `https://farmclub-consumer.vercel.app/login?evaluator=1`, `https://farmclub-producer.vercel.app/login?evaluator=1`.
6. UAT 끄기: `MOCK_LOGIN_ENABLED=false` → 재배포. `GET /api/auth/test-accounts?app=consumer`가 404인지 확인.
7. 정리(DEV-304 머지 뒤 명령 이름·옵션 재확인): DEV-304 명령을 다시 실행해 실제 농가만 남긴다(`--keep <실제 생산자 ID> …` 미리보기 → `--commit`). UAT 계정은 `--keep`에 넣지 않는다.
